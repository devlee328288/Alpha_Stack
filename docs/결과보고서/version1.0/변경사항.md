## 한 줄 요약

계획서 v6.0 이 강사님 양식 한 장에 부록을 붙인 문서라면, 이 보고서는 **같은 숫자로 쓴 장(章) 서술형 결과 보고서**입니다.

`docs/결과보고서/` 를 만들고 계획서와 같은 방식(빌더 → docx + html)으로 구웠습니다.

## 🔴 쓰면서 찾은 것

- **KOSPI200 상승 예측의 Precision 0.5415 는 평가구간 상승 비율 0.5460 의 0.99배다.** 상승이라고 말한 날만 골라도 아무 날이나
  고른 것과 같았다 — 기준선 대비 +26.78%p 만 보면 안 보이는 사실이라 5.3절에 적었다.
- **사전등록(ADR 0004)의 주 검정은 분류 정확도가 아니라 비용 차감 초과수익이었다.** 홀드아웃 백테스트가 없어 주 검정도
  결론 문장도 채우지 못했다 — 6.3절 · 9.2절.
- **KOSPI200 1위의 개발구간 ΔSharpe 중앙값 0.2332 는 SR*(N=100) 0.8115 보다 낮다** — 4.2절.
- **모델파트 v1.3 §2.2 는 아직 평가구간 최빈을 주 기준선으로 적고 있다.** 이 보고서는 ADR 0006 정의를 따르고, 부록 B 에
  그 차이만 적었다(모델 파트 문서는 건드리지 않음).
- **ruff 는 한글을 2칸으로 센다.** 파이썬 글자 수로 줄을 나누는 스크립트가 빈 리터럴 줄 175개를 만들며 제자리를 돌았다.
  표시 너비로 다시 나누고, 전후 docx 텍스트가 한 글자도 다르지 않은지 대조했다.
- **PR #286(강민석)의 `final_holdout_results/classification_report.txt` 는 표본 57건 · 정확도 0.3158 이다.** 공식 홀드아웃
  (478 · 23,567건)과 다른 실행이라 보고서에 넣지 않았다. PR 은 작성자가 취소를 요청했고 사용자가 처리한다.
