# 계획서 v2.0 → v2.1 — 무엇이 왜 바뀌었나

> **부록 I 의 그림이 사실과 반대로 읽히고 있었습니다.** 본표(9칸)는 건드리지
> 않았으므로 Minor 입니다.
>
> v2.0 2026-08-29 · v2.1 2026-08-29

---

## 1. 한 줄 요약

부록 I 의 [그림 2] 를 **계층아키텍처**(supply 문 하나)에서
**시스템아키텍처**(문 둘)로 바꾸고, 그 사실을 설명하는 문단을 더했습니다.

---

## 2. 왜 — 그림이 코드보다 뒤처져 있었다

[PR #10](https://github.com/devlee328288/Alpha_Stack/pull/10) 이 `supply/` 를
**문 하나에서 문 둘로** 갈랐습니다.

```
supply.price_series(as_of=...)   그 시점에 알 수 있었던 것만. 플래그 없음
supply.training_frame(...)       전 구간을 보고 정리매매·신규상장을 덜어낸다
```

그런데 계획서가 싣던 `계층아키텍처.mmd` 는 그 이전 그림입니다.

```
계층아키텍처.mmd:11
GATE{{"supply/ — as_of 정문 ..."}}      ← 문이 하나
```

**이 그림만 보면 정문이 정리매매 판정까지 하는 것처럼 읽히는데 정반대입니다.**
정리매매 판정은 *"이 뒤로 체결이 끊긴다"* 라서 그 시점에는 알 수 없는 사실이고,
`as_of` 정문이 그걸 계산하면 문이 지키려던 경계를 문이 스스로 넘습니다.

아키텍처 v1.2 가 이 문제 때문에 HTML 로 `시스템아키텍처.png` 를 새로 만들었지만,
**계획서는 여전히 옛 그림을 가리키고 있었습니다.**

---

## 3. 함께 고친 것 — `DIAGRAM_DIR` 이 옛 폴더를 보고 있었다

`scripts/build_project_plan.py` 의 `DIAGRAM_DIR` 이 `version1.1` 이었습니다.

⚠️ 다만 **이것만으로는 산출물이 하나도 바뀌지 않습니다.** v1.1 과 v1.2 의 같은 이름
그림 3장은 `.mmd` · `.png` 모두 **바이트까지 동일**하기 때문입니다(실측).
PR #11 이 v1.2 폴더로 복사만 했습니다.

경로를 최신 폴더로 옮긴 것은 **위생**입니다 — 옛 폴더를 가리키면 계획서만 조용히
낡는데, 그림은 아무도 다시 안 보기 때문에 틀린 줄 모른 채 발표까지 갑니다.

## 4. 실제로 바뀐 것

### 부록 I 본문

| | v2.0 | v2.1 |
|---|---|---|
| 설명 문단 | 1개 (시점정합 정문) | **2개** — 문이 둘인 이유를 더함 |
| [그림 2] | 계층아키텍처 (177.3 KB) | **시스템아키텍처 (489.8 KB)** |
| 캡션 | 계층 구조 — 시점정합 정문 | **시스템 구성 — supply 문 둘과 시점정합** |
| [그림 1] 일정간트 · [그림 3] 역할파이프라인 | | 그대로 |

더한 문단은 이렇습니다.

> 문은 둘이다. 예측 경로는 `as_of` 시점에 알 수 있었던 행만 주고, 학습 경로는 전
> 구간을 보고 정리매매·신규상장 구간을 덜어낸다. 정리매매 판정은 "이 뒤로 체결이
> 끊긴다" 라서 그 시점에는 알 수 없는 사실이기 때문이다. 손잡이로 켜고 끄면 언젠가
> 켜진 채로 예측에 들어가므로 이름으로 갈랐다 — 예측 코드가 학습용 문을 부르면
> 이름만으로 리뷰에 걸린다.

### 검증 — 의도한 것만 바뀌었나

본문을 덤프해 대조하니 **차이가 정확히 2줄**이었습니다(설명 문단 1 + 캡션 1).
docx 안의 이미지도 `image2.png` 만 교체되고 나머지 둘은 그대로입니다.

```
v2.0:  image1 142.2 KB · image2 177.3 KB · image3  82.4 KB
v2.1:  image1 142.2 KB · image2 489.8 KB · image3  82.4 KB
                          ^^^^^^^^^^^^^^ 계층 → 시스템
```

문단 수 64 → 65, 표는 8개로 그대로. 파일 크기는 411KB → 722KB 입니다.

## 5. 발표 자료와 그림이 같아졌다

부수 효과가 하나 있습니다. 킥오프 발표용 구성도와 계획서 부록의 그림이 **같은
그림**이 됐습니다. 발표에서 "계획서 부록 I 를 보시면" 이라고 말할 때 청중이 보는
그림과 손에 든 그림이 다르지 않습니다.

## 6. 안 바꾼 것

- **본표 9칸은 그대로입니다.** 그래서 Major 가 아니라 Minor 입니다.
- `계층아키텍처.mmd` 자체는 고치지 않았습니다. 그것은 아키텍처 v1.2 폴더의
  산출물이고, **옛 버전을 고치지 않는 것**이 `docs/` 규약입니다. 이 그림이 계속
  필요하면 아키텍처 v1.3 에서 문 둘을 반영해 다시 그립니다.
- [그림 3] 역할파이프라인은 v1.1 그대로입니다. **킥오프에서 역할이 확정되면** 그때
  고칩니다 — 지금 고치면 확정 전 추측을 그림으로 굳히는 일입니다.
