# 계획서 v1.0 → v2.0 — 무엇이 왜 바뀌었나

> v1.0 은 **팀원을 모집하던 시점**의 계획서이고, v2.0 은 **팀이 꾸려지고 자료를
> 실제로 재 본 뒤**의 계획서입니다. 그 둘 사이에 바뀐 것을 적습니다.
>
> v1.0 2026-08-24 · v2.0 2026-08-29

## 2. 가장 큰 변화 — "잘하겠다" 를 "이만큼이 한계다" 로 바꿨다

v1.0 의 주제 선정 이유는 *"예측력이 향상되는지 검증하고자"* 라고만 적었습니다.
**틀린 말은 아니지만 아무것도 약속하지 않습니다.**

v2.0 은 우리 자료로 직접 잰 숫자를 넣었습니다.

| 숫자 | 값 | 무슨 뜻인가 |
|---|---|---|
| 기준선 | **52.64%** | 아무 모델 없이 "항상 상승" 만 해도 이만큼 맞는다 |
| 유의 임계 | **54.99%** | 검증구간 1,217거래일에서 통계적으로 유의하려면 |
| 문헌 상한 | 55%대 | 국내외 문헌의 현실적 상한 |
| **이길 수 있는 폭** | **약 2%p** | 이게 이 프로젝트의 실제 크기다 |

그리고 그 좁은 폭이 얼마나 쉽게 사라지는지를 함께 적었습니다 — 레이블을
시가(t)→시가(t+5)로 **하루 어긋나게** 정렬해 봤더니 상관이 **정확히 10.0배**로
부풀었습니다(+0.1709 대 +0.0171). **에러는 나지 않습니다.**

이 한 문단이 v2.0 에서 가장 중요한 변화입니다. 계획서가 "무엇을 할 것인가" 만
말하는 문서에서 **"무엇이 우리를 속일 수 있는가" 까지 말하는 문서**가 됐습니다.

## 4. 착수 자산 수치를 정정했다

| | v1.0 | v2.0 |
|---|---|---|
| 국내 시세 | 780,484행 | **9,209,812행** (3,677종목 · 4,097거래일) |

v1.0 을 쓸 때는 개인 저장소의 일부만 세었습니다. 2010년부터 16년 전수로 다시
수집해 실측했습니다. **상장폐지 910종목을 포함**해 생존 편향을 막았다는 사실도
v2.0 에서 처음 적었습니다.

머신러닝 라이브러리가 하나도 없다는 v1.0 의 경고는 **그대로 유효합니다.**

## 5. 부록이 A~F 에서 A~I 로 늘었다

| | v1.0 | v2.0 |
|---|---|---|
| A | 필수/선택 범위 | 필수/선택 범위 |
| B | 역할·교차 검수 | 역할·교차 검수 |
| C | 2주 일정 | 2주 일정 |
| D | 착수 자산 | 착수 자산 |
| E | 3개 프로젝트 로드맵 | 🆕 **실측 근거** |
| F | **팀원 모집 (3명)** | 🆕 **QFRS 준수 현황** |
| G | — | 🆕 **킥오프에서 정할 것** |
| H | — | 로드맵 (E 에서 이동) |
| I | — | 🆕 **아키텍처** |

- **F(팀원 모집)는 삭제했습니다.** 팀이 꾸려졌으므로 존재 이유가 없어졌습니다.
- **E(실측 근거) 신설** — 본표에 들어간 숫자를 어디서 어떻게 쟀는지 대는 자리입니다.
  본표는 스캔되는 곳이라 근거까지 담으면 읽히지 않습니다.
- **F(QFRS 준수) 신설** — 금융 ML 연구의 재현성 표준 7개에 우리가 어디까지
  맞췄는지 자기 점검표입니다. Scopus 41편 감사에서 완전 준수가 0편이었던 표준입니다.
- **G(킥오프에서 정할 것) 신설** — 미결을 숨기지 않고 목록으로 냅니다.
  "정해진 척" 하는 것이 계획서에서 가장 비싼 거짓말입니다.
