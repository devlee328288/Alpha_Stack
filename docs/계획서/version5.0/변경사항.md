# 프로젝트 계획서 v4.1 → v5.0 — 종목 선별 기준을 실제 구현과 맞춘다

> 2026-09-08 · 정본은 [`scripts/build_project_plan.py`](../../../scripts/build_project_plan.py)

## 한 줄 요약

계획서가 말하던 `예측가능성 통계로 먼저 선별`을 폐기하고, 실제 모델 경로인 **매 거래일
업종 시가총액 상위 10개 × 업종별 KOSPI 보통주 시가총액 상위 5개**로 고쳤다.

## 왜 Major인가

부록의 숫자가 아니라 본표의 프로젝트 목표 ③과 분석 방법 ⑥이 바뀐다. 계획서 버전 규칙상
본표 변경은 Major이므로 v4.2가 아니라 v5.0으로 올린다.

## 바뀐 판단

- 업종과 종목은 현재 시점 고정 목록이 아니라 매 거래일 당시 시가총액으로 다시 고른다.
- 업종은 해당 날짜까지 알려진 최신 스냅샷만 사용한다.
- 후보 최대 50종목의 `p_down·p_neutral·p_up` 중 KOSPI200 예측 클래스에 해당하는 확률로
  순위를 만든다.
- 2주 일정에서는 별도의 종목별 예측가능성 사전 필터를 추가하지 않는다.

## 함께 고정한 모델 평가 원칙

최종 조합·모델은 ADR 0007에 따라 개발구간의 `기준선 대비 Accuracy → Macro F1 → 기준선
승리 폴드 수`로 고른다. 홀드아웃은 이 기준을 고정한 뒤 한 번만 평가한다.
