## 통합본을 채우는 법

1. **자기 구역 안에서만 고칩니다.** 구역은 `<!-- ═══ 신장환 3 · 피처 · 라벨 설계 ═══ -->` 같은 주석으로 시작하고 끝납니다. 여럿이 같은 파일을 고쳐도 구역이 다르면 git 이 알아서 합칩니다.
2. 채울 자리 슬라이드는 `class="slot todo"` 입니다. 내용을 넣으면 `todo` 를 지우고, 주장 문장(`thesis`)과 출처 줄(`foot`)을 자기 것으로 바꿉니다.
3. 레이아웃은 이미 쓰인 장을 복사해서 씁니다 — 막대 그림(`.bars`) · 표(`.inv`) · 세 칸(`.hand`) · 체크 목록(`.ticks`).
4. **숫자에는 잰 날짜와 출처를 붙입니다.** 슬라이드 아래 `foot` 줄이 그 자리입니다.
5. 발표 시간 가안은 목차 장에 있습니다(합계 18분). 바꾸면 목차 장의 시간도 함께 고칩니다.

## 보는 법

- 브라우저로 엽니다. `P` 키(또는 *발표 모드로 보기* 버튼)로 한 장씩 띄우고 `←` `→` 로 넘깁니다. 채울 자리가 몇 장 남았는지 머리에 표시됩니다.
- 인쇄해서 PDF 로 저장하면 슬라이드가 한 장에 한 쪽씩 나옵니다.
- PNG 가 필요하면 `node scripts/render_html.mjs <파일.html> <출력.png>` 로 굽습니다. **PNG 는 커밋하지 않습니다.**
