# 전처리 v1.1 → v1.2 변경사항 (2026-09-09)

> 정본은 [전처리 설계 명세서 v1.2](전처리-설계-명세서.md). 이 문서는 **무엇이 왜 바뀌었는지**만
> 적습니다.

## 한 줄

v1.1 이 만든 횡단면 네 단계를 오준영 님이 통제 실험으로 재셨고 **정확도가 1.58%p 떨어졌습니다**
([PR #210](https://github.com/devlee328288/Alpha_Stack/pull/210)). v1.2 는 *왜* 떨어졌는지를 실측으로
갈라 내고(변동성 **수준**이 라벨을 정하는데 날짜별 z-score 가 그 수준을 지운다), **우리 라벨에 맞는
전처리 후보 넷**을 설계합니다. 구현은 3차 세션입니다.

## 1. 가설이 실측이 됐다

v1.1 §5 는 *"라벨이 절대 기준이라서"* 를 **가설**로 적고 검증하지 않았습니다. v1.2 는 잽니다.

| 잰 것 | 값 |
|---|---:|
| `hv_20` 십분위 ↔ 비중립 비율 | **Spearman ρ = 1.0000** · 47.6% → 75.2% (1.58배) |
| 날짜별 평균 `hv_20` ↔ 그날 비중립 비율 | **ρ = 0.3244** (3,343일) |
| 날짜별 z-score 뒤 점이연 상관 | 0.1421 → **0.1248** (−12%) · 날짜별 평균 = 0 |
| 변동성 스케일 밴드(`c·σ`)에서 같은 관계 | **ρ = −1.0000** (뒤집힌다) |

**변동성 수준이 라벨의 절반을 설명하고, 횡단면 z-score 가 그 수준을 지웁니다.** 그리고 라벨을
de Prado 식 σ 스케일로 바꾸면 관계가 **반대**가 됩니다 — **라벨 정의가 전처리를 정합니다.**

## 3. 원칙이 바뀌었다 — "표준을 옮긴다" 에서 "라벨에서 역산한다" 로

| | v1.1 | v1.2 |
|---|---|---|
| 출발점 | 퀀트 표준(Barra·qlib) 네 단계 | **우리 라벨**(절대 ±2% · long-only) |
| 표준화 축 | 날짜 안(횡단면) | **시계열**(종목 자기 이력 · 인과적) 또는 없음 |
| 변동성 축 | 다른 피처와 같이 처리 | **손대지 않는다** — 라벨과 직접 연결된 수준 |
| 기본값 | ①② 켜짐 | **최종 경로에 아무것도 안 켠다**(#210) · 함수는 남긴다 |

**퀀트 표준이 틀린 게 아닙니다.** 표준은 *상대 목표*(그날 어느 종목이 나은가)와 *단위 제각각인
피처*를 전제하는데, 우리는 둘 다 아닙니다 — 라벨이 절대이고 피처가 이미 비율입니다. **표준을 옮길
때 전제를 같이 옮겼어야 했습니다.**

## 4. 설계 — 후보 넷 (3차 세션)

| | 이름 | 무엇 | 예상 |
|---|---|---|---|
| A | `winsorize_only` | 날짜별 MAD 3배만 · 표준화 없음 | #210 의 두 단계를 갈라 본다 |
| B | `ts_zscore_causal` | 종목별 250일 인과적 z | **유력** — 수준 보존 + 계수 안정 |
| C | `cs_zscore_plus_date_level` | v1.1 z + 날짜 평균·표준편차 복원 | §1 설명의 직접 검증 |
| D | `selective_vol_raw` | 변동성 축 원값 · 나머지만 횡단면 | 원칙 3 그대로 |

전부 조합 K LogReg 12폴드 공통 159,900행 위에서, [ADR 0007](../../decisions/0007-최종-모델-선정과-홀드아웃.md)
기준으로, **원값(+2.43%p · 10/12)을 넘어야 채택**합니다. 시행 누적 6 · Bonferroni 와 대응표본 t 를
함께 적습니다.

## 5. 팀 코드에 맞춘 것

오준영 님 [`scripts/run_stock_preprocessing_ablation.py`](../../../scripts/run_stock_preprocessing_ablation.py)
의 `build_preprocessed_dataset` 에 조건 사전을 끼우는 모양으로 설계했습니다. 신장환 님 `features/*.py`
는 손대지 않습니다. 라벨·선정 기준·진입 축은 그대로입니다. **내 파트만 잘되는 설계가 아니라
모델링이 그대로 돌릴 수 있는 설계**여야 한다는 팀장 지시입니다.
