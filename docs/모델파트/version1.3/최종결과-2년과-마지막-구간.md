**홀드아웃 기준선은 평가구간 자체의 최빈 클래스입니다** — 개별종목 0.3655 는 오준영 님 확인(2026-09-14 · PR #270).
KOSPI200 은 같은 정의로 공식 입력의 라벨 분포(데이터파트 v4.6 개봉 절차 §8.3)에서 계산했습니다.

| 기준선 | KOSPI200 | 개별종목 |
|---|---:|---:|
| ✅ **홀드아웃 기준선** — 평가구간 최빈 클래스(두 트랙 모두 상승) | 0.5460 (261 / 478) → 모델 **−11.55%p** | 0.3655 (8,614 / 23,567) → 모델 **+1.52%p** |
| 참고 — 학습구간 최빈 클래스(중립)를 평가 전체에 (개발구간 선정 방식) | 0.1653 | 0.2858 |
| 개발구간 기준선 (§1) | 0.3972 | 0.3969 — **다른 기간이라 직접 비교하지 않는다** |

🔴 KOSPI200 은 평가구간 상승이 **54.6%** 였는데 모델 정확도 0.4331 · 하락 재현율 0.1087 · MCC −0.0114 입니다 — 같은 기간 기준선을 넘지 못했습니다.
⚠️ 발표 통합본 04-3 의 *"정확도는 이겼지만 MCC 는 거의 0"* 은 비교한 기준선이 어느 기간인지 확인이 필요합니다(04-2 는 PR #270 에서 같은 기간 기준으로 고쳤다).
**결과를 보고 설정을 다시 고르지 않습니다**(ADR 0009) — 해석은 발표·보고서에 그대로 적습니다.

## 3. ② 마지막 한 구간 — ADR 0010

### 3.1 무엇을 바꿨나

개봉 뒤 모델 파트가 최종 목적을 다시 확인한 결과, 의도한 산출물은 *"개봉 자료의 대부분까지 포함해 한 번 학습하고 자료 끝의
마지막 5거래일 보유 구간 하나를 예측"* 이었습니다. 설정은 ADR 0009 그대로입니다.

| 규칙 | 값 |
|---|---|
| 날짜 | 코드에 고정하지 않는다 — 두 원본의 **마지막 공통 거래일 = T+6**, 6칸 앞 = T, 다음 날 = T+1 |
| 이번 실행 | T **20260824** → T+1 20260825 → T+6 **20260901** |
| 학습 | 청산일이 T 이하인 행만 — 마지막 목표 구간의 가격이 학습 라벨에 들어가지 않는다 |
| 경계 | 피처 함수 기본값은 계속 `20240901` 이후를 거부하고, 이 실행기만 개봉 기록을 확인한 뒤 `allow_unsealed=True` |
