# 최종 홀드아웃 실행기

> 담당: 오준영 · 상태: 개발구간 드라이런 완료, 실제 홀드아웃 미개봉

## 하는 일

`scripts/run_final_holdout.py`는 이미 선정된 KOSPI200 조합 C와 개별종목 조합 K만 학습한다.
후보 비교와 재선정 기능은 없다. 두 모델의 하락·중립·상승 확률과 실제 라벨을 남기고,
두 모델이 모두 상승으로 예측한 종목에 `buy_candidate=True`를 기록한다.

설정 정본은 `config/final_holdout_model.json`이다. 단일 class weight와 상승 임계값의 근거 및
승인 전 확인 사항은 ADR 0009에 기록한다.

## 개발구간 드라이런

```powershell
.venv/Scripts/python.exe scripts/prepare_final_holdout_dry_run.py `
  --output-dir data/raw/final_holdout_dry_run_inputs

.venv/Scripts/python.exe scripts/run_final_holdout.py `
  --mode dry-run `
  --index-dev data/raw/final_holdout_dry_run_inputs/index_dev.parquet `
  --index-holdout data/raw/final_holdout_dry_run_inputs/index_holdout.parquet `
  --stock-dev data/raw/final_holdout_dry_run_inputs/stock_dev.parquet `
  --stock-holdout data/raw/final_holdout_dry_run_inputs/stock_holdout.parquet `
  --output-dir data/raw/final_holdout_dry_run_result
```

준비기는 두 트랙의 마지막 공통 60거래일을 가짜 홀드아웃으로 떼고 그 직전 5거래일을
학습에서 버린다. 실제 홀드아웃 시작일 `20240901` 이후 날짜가 드라이런 입력에 있으면
실행기가 중단한다.

2026-09-11 실측 결과는 지수 60행, 개별종목 2,938행, 결합 2,938행, 매수 후보 520건이다.
이는 실행 연결을 확인한 숫자이지 모델의 최종 일반화 성능이 아니다.

## 공식 실행 계약

공식 실행에는 `--mode official`과 데이터 담당자의 개봉 승인 JSON이 필요하다. 승인 JSON은
다음 필드를 가진다.

```json
{
  "schema_version": 1,
  "authorized": true,
  "run_id": "팀이 정한 실행 ID",
  "holdout_start": "20240901",
  "config_sha256": "설정 canonical JSON의 SHA-256",
  "source_sha256": {
    "index_dev": "파일 SHA-256",
    "index_holdout": "파일 SHA-256",
    "stock_dev": "파일 SHA-256",
    "stock_holdout": "파일 SHA-256"
  }
}
```

승인 파일과 실제 입력 지문이 다르거나 결과 디렉터리가 이미 있으면 중단한다. 승인 JSON을
만들고 `reports/unseal.log`를 한 번만 기록하는 것은 데이터·개봉 통제 파트와 합의해야 한다.

## 출력

- `index_predictions.parquet`: 지수 실제값·예측·확률·상승 임계값
- `stock_predictions.parquet`: 날짜·종목·실제값·예측·확률
- `combined_predictions.parquet`: 지수 예측을 붙인 전 종목 결과와 `buy_candidate`
- `report.json`: 입력 경로·SHA-256, 설정 SHA-256, 행 수와 분류 지표

백테스트 원장 연결과 거래비용·Sharpe·MDD 계산은 강민석 담당 출력 계약과 이어야 한다.
