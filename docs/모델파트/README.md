> 규약 전문은 [docs/README.md](../README.md).

**모델 코드(`models/`)는 오준영님 파트이고, 이 폴더는 그 작업을 문서로 남기는 자리입니다**
(문서화는 이동원 담당). 코드에 관한 판단은 준영님 것이고, 여기에는 **자료로 잰 것**과
**팀이 합의한 것**을 적습니다.

| 버전 | 날짜 | 무엇이 담겼나 |
|---|---|---|
| [**version1.0**](version1.0/) ⭐ | 2026-09-01 | **X(독립변수) 조합 선정 검토.** 조합 A·B 재현(소수점까지 일치) · 기준 5개와 가설 4개를 개발구간 자료로 채점 · 조합 6안 × 모델 4종 성적표 · **하락 예측이 안 나오는 원인은 피처가 아니라 클래스 쏠림**(같은 피처로 모델만 바꿔 하락 Recall 0.0%→23.5%) |

## 이 폴더에 무엇을 넣나

| 넣는다 | 넣지 않는다 |
|---|---|
| 피처 조합·하이퍼파라미터의 **선정 근거와 실측** | 모델 코드 자체 (→ [`models/`](../../models/)) |
| 팀 합의가 필요한 논점과 그 결론 | 되돌릴 수 없는 결정 (→ [`decisions/`](../decisions/) ADR) |
| 실험을 **재현하는 방법** | 실험 출력 원본 (→ [`notebooks/`](../../notebooks/)) |
