## 다른 문서와 무엇이 다른가

`docs/` 에는 이미 문제정의·요구사항·시장조사·아키텍처·ERD 가 있습니다. 이 폴더는
그것들을 **요약하지 않습니다.** 저 문서들이 답하지 않는 것만 담습니다.

| 저 문서들이 답하는 것 | 이 폴더가 답하는 것 |
|---|---|
| **무엇을** 만드는가 (요구사항) | **왜 하필 이것인가** — 무엇을 검토했고 왜 버렸는가 |
| **어떻게** 만드는가 (아키텍처·ERD) | **무엇을 성공이라 부를 것인가** — 미리 못 박는다 |
| 근거 수치 (시장조사) | **무엇이 아직 정해지지 않았는가** — 누가 정해야 하는가 |

그래서 이 문서는 **읽고 나서 할 일이 생기는 문서**입니다. 팀원은 §10 에 답하고,
강사님은 §11 에 답합니다. (v1.0 에서는 각각 §9·§10 이었습니다.)
