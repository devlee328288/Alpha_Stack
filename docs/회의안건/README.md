## 왜 폴더로 나눴나

회의는 **날짜로 구분되는 사건**입니다. 지난 회의에서 이미 닫힌 안건이 이번 안건 문서에
그대로 남아 있으면, 읽는 사람이 *"이거 지난번에 정하지 않았나"* 를 매번 다시 떠올려야
합니다. 실제로 그 혼란이 있어서 2026-08-26 에 폴더로 갈랐습니다.

**한 회의 = 한 파일**입니다. 회의가 끝나면 그 파일을 `archive/` 로 내리고 다음 회의
파일을 새로 만듭니다. 옮긴 파일은 **고치지 않습니다** — 그날 무엇이 열려 있었는지가
기록이기 때문입니다.

## 무엇을 여기 두고 무엇을 안 두나

| | 여기 | [ADR](../decisions/) |
|---|---|---|
| 담는 것 | **아직 안 정해진 것** | **정해진 것** |
| 수명 | 정해지면 지운다 | 영구. 뒤집히면 새 ADR 이 대체한다 |
| 형식 | 체크리스트 | 배경·결정·결과 |

**정해지면 ADR 로 옮기고 여기서 지웁니다.** 양쪽에 다 남겨 두면 어느 쪽이 최신인지
알 수 없게 됩니다.
