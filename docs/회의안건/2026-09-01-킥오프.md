### A-2. 산업(섹터) 분류 기준 ⏰ **이게 정해져야 뉴스 수집이 시작됩니다**

뉴스는 **산업 단위로 수집**합니다 — 3,677 종목을 전수로 도는 것은 한도상 불가능하고,
종목 지정 검색은 그때그때 받습니다. 그러려면 *"산업이 무엇인가"* 가 먼저 정해져야 합니다.

- [ ] **선택지 셋**
      - (a) **KRX 업종 분류** — 우리가 이미 받는 자료 안에 있습니다. 추가 수집 0
      - (b) **GICS** — 국제 표준이라 설명이 쉽지만 매핑 표를 따로 구해야 합니다
      - (c) **직접 매핑** — KOSPI200 구성종목을 손으로 10~15개 묶음으로
- [ ] 몇 개 묶음으로 할 것인가? (뉴스 수집 비용이 여기에 비례합니다)

> 📌 (a)를 권합니다 — **추가 수집이 0**이고 이미 표 안에 있습니다.
> 다만 KRX 업종은 묶음이 잘게 쪼개져 있어 뉴스 검색어로 쓰기엔 그대로는 어렵습니다.
> **(a)로 받아서 (c)로 묶는** 절충이 현실적입니다.

### A-3. 화면 스택 — **문서끼리 어긋나 있습니다** 🔴

| 어디 | 무엇이라 적혀 있나 |

| [요구사항 F-17·F-27](../요구사항/version1.0/요구사항.md) | **정적 HTML 5화면.** `api/` 는 1차 범위 밖 |
| 데이터 파트 실무 | **Streamlit** — 수집 현황·버튼 수집은 정적 HTML 로 **원리적으로 불가능** |

- [ ] **한 문장으로 닫습니다.** 셋 중 하나:
      - (a) **전부 Streamlit** — 대시보드도 수집 화면도
      - (b) **성과 대시보드는 정적 HTML · 데이터 파트 운영 화면만 Streamlit** ← *현실적*
      - (c) 전부 정적 HTML — 수집 버튼을 포기한다
- [ ] 정해지면 **요구사항 F-17·F-27 을 같은 날 고칩니다** (문서가 어긋난 채 가면 안 됩니다)

> 📌 대시보드 담당은 **강민석**입니다. 이 결정의 주인이 강민석이라는 뜻입니다.

> `config.toml [theme]` 토큰 53개 · `st.components.v2` 의 `--st-*` CSS 변수.
