## 2. 버전 규약

### 폴더 하나 = 그 시점의 완결된 명세

```
docs/요구사항/
├─ version1.0/
│   └─ 요구사항.md          ← 그 시점의 전문(全文). 나중에 고치지 않는다
├─ version1.1/
│   ├─ 요구사항.md          ← 1.0 을 복사해서 고친 전문
│   └─ 변경사항.md          ← 1.0 → 1.1 에서 무엇이 왜 바뀌었나
└─ README.md                ← 버전 목록과 한 줄 요약
```

**옛 버전을 지우지 않습니다.** 지우면 발전 과정이 사라집니다.

### 언제 올리나

| 올림 | 기준 | 예 |
|---|---|---|
| **Major** (+1.0) | 결론이 뒤집힌다. 범위가 크게 바뀐다 | 예측 대상이 지수 → 종목으로 바뀜 |
| **Minor** (+0.1) | 항목이 추가·수정된다. 뼈대는 그대로 | 기능 3건 추가, 수치를 실측으로 교체 |

### 작업 중에는 올리지 않습니다

변경사항을 모아 두었다가 **기능·스프린트가 끝날 때 한 번에** 올립니다.
작업 도중 버전이 계속 늘면 어느 것이 정본인지 알 수 없어집니다.

### 링크는 검사합니다

```bash
python scripts/check_doc_links.py     # 깨진 링크가 있으면 exit 1
```

버전 폴더를 새로 팔 때마다 돌립니다. 상대 경로가 전부 바뀌므로
**사람 눈으로는 반드시 빠뜨립니다.**
