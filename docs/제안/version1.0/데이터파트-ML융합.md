# 데이터 파트에 ML/DL 을 정직하게 붙이는 방법

> 2026-08-29 · 회람용
> **질문**: 수집·정제·전처리·크롤링 담당이 수업에서 배운 ML/DL 을 자기 파트에 쓸 수 있는가?
> **답**: 쓸 수 있습니다. 다만 **"ML 을 쓰기 위한 ML"은 빼야** 설득력이 생깁니다.

---

## 판단 기준 하나

> **규칙 기반으로 5줄이면 되는 일에 모델을 쓰면 그건 실력이 아니라 장식입니다.**

그래서 아래 항목마다 **"규칙 기반 대조군"** 을 함께 둡니다.
ML 이 그 대조군을 못 이기면 **규칙을 씁니다.** 그 판단 과정 자체가 발표 재료입니다.

---

## ✅ 채택 — 규칙 대조군을 이기면 쓴다

### ① 시세 이상행 탐지 — Isolation Forest ⭐ 가장 추천

**무엇**: 920만 행에서 "이상한 행"을 찾습니다. 실제로 우리 데이터에 있는 것들:

| 유형 | 실측 |
|---|---|
| 정리매매 급락 | −30.5% 이하 1,224행 중 **1,197행(97.8%)** · 최저 −98.41% |
| 액면병합·감자 | +30.5% 초과 354행 · 최고 **+6,699,900%** (전일 종가 1원) |
| 시가=고가=저가=0 | 283,468행 |

**규칙 대조군**: 로버스트 z-score(중앙값/MAD) + 되돌림 필터
**ML**: `sklearn.ensemble.IsolationForest` — 다변량(가격·거래량·스프레드)을 함께 본다

```python
from sklearn.ensemble import IsolationForest   # 이미 설치돼 있다
```

**수업 연결**: `07-ml/` 의 앙상블·비지도학습. 신규 의존성 **0**.
**정직한 평가 방법**: 우리가 이미 아는 정답(정리매매 1,197행 · 액면병합 354행)을 **라벨로**
쓰면 정밀도/재현율을 실제로 잴 수 있습니다 — **"찾았다"가 아니라 "몇 % 찾았다"** 로 보고합니다.

**담당 이동원 · 1일**

### ② 결측·거래정지 패턴을 **피처로** 만든다

**무엇**: 결측을 채우지 않고, **"왜 비었는가"를 신호로** 씁니다.

```
is_suspended        거래정지일 (시장 캘린더엔 있는데 종목엔 없다)
days_since_trade    마지막 거래 이후 경과 거래일
is_liquidation      정리매매 구간 (소멸 종목 마지막 10거래일)
is_corporate_action |등락률| > 30.5% — 액면병합·감자 의심
```

> 🔴 **결측치 대체(KNNImputer·MICE·선형보간)는 하지 않습니다.** 시세에서 결측은
> "값을 모르는 것"이 아니라 **"거래가 없었다"** 는 사실입니다. 채우면 가짜 안정성이
> 생기고, 앞뒤 값을 참조하므로 **미래가 샙니다.**

**담당 이동원 · 0.5일** — 비용 대비 효과가 가장 큽니다

schema = DataFrameSchema({

### ④ 분포 드리프트 탐지 — PSI/KS + adversarial validation

**무엇**: 개발구간과 검증구간의 분포가 달라졌는지 잽니다. 우리 데이터엔 **실제로 단절이 있습니다**:

- **2015-06-15 가격제한폭 확대** — +15.5% 초과 건수가 2014년 17건 → 2015년 **2,072건**
- **2025-03-04 NXT 출범** — 거래량 일부가 다른 시장으로

**규칙 대조군**: KS 검정 · PSI
**ML**: adversarial validation — *"이 행이 개발구간인지 검증구간인지"* 를 분류기로 맞혀 봅니다.
**AUC 가 0.5 에 가까우면 두 구간이 구분 안 된다**는 뜻이고, 높으면 드리프트가 있다는 뜻입니다.

**수업 연결**: `07-ml/` ROC/AUC + `04-math-statistics/` KS 검정 — **둘 다 배운 것**입니다.
**담당 이동원 · 1일** — 발표에서 "우리는 분포 변화를 쟀다"로 말할 수 있습니다

### ⑤ (선택 범위) 뉴스 중복 제거 — MinHash LSH

같은 기사가 여러 매체에 뿌려집니다. 그대로 세면 **"많이 언급됐다"가 가짜**가 됩니다.

**규칙 대조군**: 제목 완전일치 + 자카드 유사도
**ML**: `datasketch` MinHash LSH — 근중복을 O(n) 에 가깝게 찾습니다
**한 단계 더**: 한국어 문장 임베딩(`ko-sroberta-multitask`) + HDBSCAN 으로 **"같은 사건"** 을 묶습니다

**담당 이동원 · 1일** (선택 범위가 열릴 때만)

### ⑥ (선택 범위) 기업명 → 종목코드 매핑 ⭐ 여기가 진짜 어렵습니다

*"현대차"* 가 **현대차 / 현대차2우B / 현대차증권** 중 무엇인지, *"한화"* 가
**한화 / 한화솔루션 / 한화에어로스페이스** 중 무엇인지 — 이게 뉴스 파이프라인의 실제 병목입니다.

**규칙 대조군**: 사전 + `RapidFuzz` 근사매칭 + 동음이의 규칙
**ML**: 한국어 뉴스 NER(`KPF/KPF-bert-ner`)로 기업명 후보를 먼저 뽑고 위 규칙에 넘김

> 여기서도 **규칙이 먼저**입니다. 상장사 이름 사전은 우리가 이미 갖고 있고(3,677종목),
> 대부분은 정확일치로 풀립니다. NER 은 사전에 없는 표현(약칭·구명칭)만 담당합니다.

**담당 이동원 · 1.5일**

### ⑦ ★ (선택 범위) 뉴스 관련성 분류기 — **여기가 데이터 파트의 진짜 ML**

**무엇**: *"이 기사가 이 종목의 주가와 관련 있는가"* 를 판정합니다.
종목명이 나온다고 관련 있는 게 아닙니다(광고·인사·스포츠 스폰서).

**정직한 3단계 — 이 순서가 핵심입니다**

```
1단계  약지도(weak supervision) 라벨 만들기
       규칙으로 대충 라벨 → 손으로 200건 검수
2단계  TF-IDF + LogisticRegression 기준선        ← 강사님이 수업에서 보여준 방법
3단계  KLUE-RoBERTa 파인튜닝                      ← 2단계를 못 이기면 버린다
```

**2단계를 반드시 먼저 합니다.** 3단계가 2단계를 못 이기면 **"딥러닝이 이기지 못했다"** 를
결과로 보고합니다 — 그게 정직하고, 발표에서 오히려 강합니다.

**수업 연결**: TF-IDF+LogReg 는 강사님 예제(`th01 .../routers/ml.py`)와 `08-dl/10·11` 에
Keras Embedding+LSTM 이 있습니다. **transformers 만 새로 배우면 됩니다.**

**담당 이동원 · 2일** (선택 범위)

## ❌ 기각 — "ML 을 쓰기 위한 ML"

| 무엇 | 왜 안 하나 |
|---|---|
| **시세 결측치 대체** (KNNImputer·MICE) | 시세의 결측은 모르는 값이 아니라 **거래가 없었다는 사실**이다. 채우면 미래가 샌다 |
| **크롤링 스케줄 ML 최적화** | 페이지 변경 주기를 모델로 예측 — 우리 수집량에서는 **`if` 문 세 줄**이면 된다 |
| **Seasonal Hybrid ESD** | 저장소가 오래됐고 계절성 가정이 일별 시세와 안 맞는다 |
| **PyOD 전체 도입** | Isolation Forest 하나면 충분하다. 비교군이 필요하면 sklearn 안의 LOF·One-Class SVM 으로 |
