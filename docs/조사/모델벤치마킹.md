## 2. 모델별 입력 규격 → 전처리 요구사항

| 모델 | 입력 형태 | 결측 처리 | 스케일링 | 시점 정합 | 실행처 |
|---|---|---|---|---|---|
| LightGBM | 표형 피처 + 라벨 | NaN 자체 처리 가능 | 불필요 | 재무·거시를 **접수일 기준 as-of join** | **로컬** (배포판이 GPU 빌드가 아니다) |
| Kronos | 종목별 연속 OHLCV 시퀀스 | 결측 봉 없는 연속 창 필요 | 토크나이저가 내장 처리 | **수정주가 필수** | zero-shot 로컬 가능 · fine-tune 은 **Colab Pro** |
| neuralforecast | long 형식 (unique_id, ds, y, 외생변수) | 결측 없는 시간 격자 필요 → 보간 규칙 필수 | 모델별 상이 | as-of join + 격자 정렬 | **Colab Pro** |

- lookback 창 길이(Kronos 최대 문맥 등)는 **아직 실측하지 않았다.** B 단계에서 공식
  구현 코드로 확인한 뒤 전처리 창 크기를 정한다.

## 3. 전처리 기법 후보

- **시계열 보간** — 수업(05-time-series) 규칙: 결측은 시계열 특성을 고려해 보간,
  lag 는 `shift(+)`, 타깃은 `shift(-)`.
- **분수 차분 (Fractional Differentiation)** — 1차 차분이 지워버리는 장기 기억을
  보존하면서 정상성을 확보한다 (López de Prado). 정상성 판정은 수업에서 배운
  **ADF 검정**으로 하고, 검정을 통과하는 최소 d 를 이진 탐색으로 찾는다.
  라이브러리(mlfinlab 등)는 라이선스가 불명확하므로 **재귀 가중치 공식을 직접
  구현**한다 (수십 줄).
- **MinHash LSH 중복 제거** — 뉴스 텍스트를 수집하게 되면 필수. 지금은 대상 없음.

## 7. GitHub·HF 대안데이터 수집 파이프라인 — 확장 설계 초안

수집·전처리·크롤링이 데이터 파트의 역할이므로, 확장 단계에서 실제로 만들 수 있는
형태로 초안을 남긴다. 지금 프로젝트의 예측 대상(KRX 350종·5일 지평)에 바로 붙는
지표는 아니고, **별도 검증 후 편입**하는 트랙이다.

### 7.1 무엇을 재나

| 지표 | 수집원 | 주기 | 대상 매핑 |
|---|---|---|---|
| 조직 저장소 활동 (커밋·병합 PR·이슈·Star 증가) | GitHub GraphQL | 주 1회 스냅샷 | KRX 상장사 중 공개 조직이 실재하는 곳 (네이버·카카오 등 — 매핑표를 먼저 만들어 개수부터 실측) |
| HF 모델 다운로드·파생 모델 수 | HF API (`models?author=`) | 주 1회 | 글로벌 AI 수요 프록시 → 반도체 섹터(삼성전자·SK하이닉스) 간접 신호 |
| 개발자 체류 기간 분포 | GraphQL (기여자 이력) | 월 1회 | 조직별 숙련 기여자 비율 |

### 7.2 수집 규약 (전 수집기 공통으로 채택할 것)

- **GraphQL 단발 쿼리**로 여러 저장소를 한 번에 — REST 반복 호출 금지 (이용약관
  준수 규칙과 정합). 이 조사 문서의 Stars·라이선스도 GraphQL 1회로 실측했다.
- **지수 백오프 + 지터** — 재시도 간격 `random(0, min(v_max, v_base·2^x))`.
  기존 수집기(ECOS·DART)에도 이식할 가치가 있다.
- 타임스탬프는 UTC 로 정규화한 뒤 **KST 15:30 장 마감에 as-of 정렬** — 재무 접수일
  정합과 같은 원칙이다.
- **봇 필터링** — Star 급증 구간은 저활동 계정 비율(팔로워 0 · 활동 이력 0)을 함께
  재고, 동시간대 록스텝 군집은 제외 표시한다. 필터 전/후 값을 둘 다 저장해
  필터의 효과 자체를 검증 가능하게 한다.

### 7.3 검증 게이트 (편입 전 통과 조건)

- 지표 시계열이 정상성 확보되는가 — ADF 검정, 필요시 분수 차분
- 개발구간 안에서 라벨과의 관계가 유의한가 — 수업 검정 도구(대응표본 t·ANOVA)로
- 굿하트 리스크 평가 — 조작 가능한 지표인지, 조작 흔적 필터가 있는지

## 8. Colab Pro 연결 규약 (요약)

전역 규약(하이브리드 실행 규약)을 따른다:

- **colab-mcp 는 stateless 실행기로만** 쓴다. 셀 편집은 유지되지 않음이 확인돼
  있으므로 (2026-07-27) 노트북을 Colab 에 구성하지 않는다.
- **로컬 `.py`/`.ipynb` 가 정본.** Colab 에는 실행할 코드만 던지고 출력을 회수해
  로컬 파일에 반영한다.
- 시작 시 확인: ① 실제 import 되는 `__version__` 으로 패키지 핀 대조 ② GPU 할당
  (`torch.cuda.is_available()`) ③ 한글 그래프면 `fonts-nanum`.
- 반출은 파생 산물만 (`data/interim/colab/`, gitignore). 원자료·자격증명 반출 금지.
