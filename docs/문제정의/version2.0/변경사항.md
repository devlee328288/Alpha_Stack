# 문제정의 v1.0 → v2.0 변경사항

> 2026-08-27 · [v1.0](../version1.0/문제정의.md) → [v2.0](문제정의.md) · **287줄 → 235줄**

**방향은 넓고 얕게 → 좁고 깊게** 입니다. 2주짜리 1차에 필요한 것만 남기고, 남긴 것은
숫자를 실측으로 바꿔 더 단단하게 했습니다.

| **홀드아웃 표본** | 1,230일 | **1,217일** | 실제 거래일을 세었다. 유의 임계 영향은 0.01%p |

> **낮은 기준선은 우리가 이기기 쉬워지는 쪽**입니다. 이 프로젝트의 취지와 정반대입니다.

## 5. 팀원 제안이 §2 를 건드렸습니다

4번째 팀원의 **1거래일 이진 분류** 제안 때문에 [§2 의 "왜 5일인가"](문제정의.md) 를
다시 계산했습니다. 결론은 **그대로 5일**이고, 오히려 근거가 단단해졌습니다 —
v1.0 의 62.72% 는 √5 근사와 전구간 평균이 섞인 값이었는데, 실측으로 다시 재니
**65.03%** 로 격차가 더 벌어졌습니다.

제안 중 **F1-score** 와 **확률보행·ARIMA 동기간 방향 적중률 비교**는 채택했습니다 →
[요구사항 v2.0](../../요구사항/version2.0/요구사항.md) F-14·F-15.
