# 데이터파트 v2.2 → v2.3 변경사항

> 2026-09-01 · **수집 문서를 두 갈래로 가르고, 손으로 받는 자리를 만들었다**

---

## 1. `직접수집_가이드.md` 가 실제로는 자동 수집 문서였다

v2.2 의 `직접수집_가이드.md` 는 이름과 내용이 어긋나 있었다. 이름은 "직접 수집"인데
내용은 **코드로 API 를 부르는 방법**이었다. 그래서 *"사람이 사이트에서 받는 법"* 을
찾는 사람이 이 문서를 열면 원하는 것이 없었다.

| v2.2 | v2.3 |
|---|---|
| `직접수집_가이드.md` (내용은 자동 수집) | [`자동수집_가이드.md`](자동수집_가이드.md) — 이름을 내용에 맞췄다 |
| — | [`직접수집_가이드.md`](직접수집_가이드.md) — **신설.** 브라우저에서 클릭해 받는 법 |

가르는 축은 **누가 하는가**다.

| | 자동 수집 | 직접 수집 |
|---|---|---|
| 누가 | 코드 | 사람 |
| 파일을 거치나 | 아니오 — 곧장 `krx_cache.db` | 예 — `data/manual/` |
| 예산 | `budget.try_spend()` | 사람이 누른 만큼 |

## 2. `data/manual/` 을 만들었다 — 한 폴더가 두 축을 받고 있었다

`data/inbox/README.md` 는 *"팀원이 건네준 파일을 놓는 자리"* 라고 적혀 있는데,
v2.2 가이드는 팀장이 손으로 받은 것도 **같은 곳**에 넣으라고 적어 두었다.
그래서 파일 하나를 보고 *"이게 누가 어디서 가져온 것인가"* 를 되짚을 수 없었다.

출처를 못 되짚으면 값이 우리 것과 다를 때 **누구에게 물어야 하는지**를 모른다.

```text
data/inbox/     팀원 3명이 HuggingFace 로 보낸 것   (기존)
data/manual/    팀장이 사이트에서 받아 온 것        (신설)
```

`.gitignore` 에 두 줄을 더했다. **별표 형태여야 한다** — 폴더째 무시하면 `!` 예외가
먹지 않아 README 를 살릴 수 없다(git 공식 문서: *"It is not possible to re-include a
file if a parent directory of that file is excluded."*).

```gitignore
data/manual/*
!data/manual/README.md
```

> 🔴 **이 두 줄이 없으면 PUBLIC 저장소로 샌다.** 전역 규칙(`*.csv`·`*.parquet`)은
> CSV·parquet 만 막는데, 직접 받는 것은 `.xlsx`·`.json`·`.zip`·`.xml` 이 많다.

### ⚠️ 표준 관례에는 없는 이름이다

Cookiecutter Data Science(`external` = 제3자 출처) · Kedro(가공 단계) ·
dbt `seeds`(정적/동적) · AWS 랜딩존(마스킹 필요성) · 메달리온(가공 단계) 다섯을
조사했지만 **"손으로 받았나"로 폴더를 가르는 표준은 없었다.** 관례는 전부 *취득 방법*이
아니라 *신뢰 경계*나 *가공 단계*로 나눈다.

우리가 이 축을 쓰는 이유는 우리 수집이 자동과 수동 두 갈래이기 때문이고, 그 사실을
[`data/manual/README.md`](../../../data/manual/README.md) 에 적어 두었다.
CCDS 의 `external` 을 쓰지 않은 이유는 그것이 *"출처"* 축이라 팀원이 준 파일도 논리상
external 이 되어 혼동이 재발하기 때문이다.

## 3. 검사기가 두 폴더를 훑고 `.json` 을 본다

`scripts/check_inbox.py` 를 고쳤다.

| | v2.2 | v2.3 |
|---|---|---|
| 훑는 곳 | `data/inbox/` 하나 | `data/inbox/` + `data/manual/` |
| 확장자 | `.csv .tsv .xlsx .xls .parquet` | **+ `.json`** |
| HF 캐시 | `rglob` 이 `data/inbox/_hf` 까지 훑었다 | 밑줄로 시작하는 폴더를 건너뛴다 |
| 출처 표시 | — | `data/manual/` 것은 `contributor="직접수집"` |

**`.json` 을 넣은 이유**: 직접 받는 것 중 ECOS·FRED·DART 화면 다운로드가 전부 JSON 이다.
없으면 파일을 넣고 검사를 돌려도 **아무 말 없이 0건**이 나온다 — 가장 나쁜 실패다.

**`.zip` 은 넣지 않았다.** 풀어서 넣어야 무엇이 들었는지 사람이 보고 판단한다.

**`origin` 은 그대로 `'local'` 이다.** `inbox_batch.origin` 에 `CHECK (origin IN
('local','huggingface'))` 가 걸려 있고 SQLite 는 CHECK 를 `ALTER` 로 못 고친다 —
표 재작성 + 마이그레이션 한 칸이 든다. 제약 없는 `contributor` 칸으로 같은 구별이
되므로 그만한 값이 아니다.

## 4. 조사한 출처 20여 곳 중 새로 알아낸 것

[직접수집_가이드](직접수집_가이드.md)에 전부 적었고, 여기에는 **계획을 바꾸는 것**만 남긴다.

### 🔴 KRX 데이터마켓플레이스가 로그인 필수가 됐다 (2025-12-27)

네이버·카카오 간편가입이 되고 조회는 여전히 무료다. **우리 자동 수집 코드는 영향이
없다** — 우리는 화면이 아니라 공식 OpenAPI(`data-dbg.krx.co.kr/svc/apis`)를 쓴다.
실측으로 확인했다: 20260826 KOSPI 944종 정상 수신.

> pykrx 등이 쓰는 화면 엔드포인트(`getJsonData.cmd`)는 세션 쿠키를 받은 뒤에도
> HTTP 400 이다. 그쪽 경로를 쓰는 코드가 있으면 깨진다.

### ✅ 공공데이터포털이 재배포 가능한 유일한 시세·재무 출처다

우리 저장소는 PUBLIC 이고 KRX 약관 제12조가 재배포를 금지한다. 그런데
**금융위원회_주식시세정보(15094808)** 와 **기업 재무정보(15043459)** 는
이용허락범위가 **제한 없음**이다 — 발표자료에 값을 실을 수 있는 유일한 경로다.

> ⚠️ 형제 데이터셋인 **지수시세정보(15094807)는 2020-01-01 부터**다.
> 우리 지수 19.5만 행은 2010년부터라 **대체하지 못한다.**
> 이걸 모르고 갈아끼웠으면 10년치를 잃었다.

### 🔴 우리에게 통째로 없는 축 — 상장폐지 이력

우리 3,677종은 **살아남은 종목만**이다. 생존편향이 그대로 들어가 있다.
KIND 는 **로그인 없이** 상장폐지 이력을 EXCEL 로 준다.

### ⚠️ FRED 가 이 PC 에서 안 열린다

타임아웃이다. 미국 금리·VIX 를 거시 피처로 붙일 계획이면 다른 경로가 필요하다.
