## 2. 수업이 말한 것 — 09단원 1장 · 02단원 4장

강사님 자료가 금융 데이터의 함정을 **세 가지**로 듭니다
(`learning/09-finance-ml-dl/1.금융머신러닝.ipynb`).

### 2.1 룩어헤드 편향 (Look-ahead Bias)

> 백테스팅할 때 그 시점에서는 알 수 없었던 미래 정보를 활용해서 성과가 비현실적으로
> 좋게 나오는 오류
>
> - 1분기 실적(3월 31일까지)을 4월 1일부터 반영 → 실제 발표는 4~5월
> - **당일 종가로 당일 매매** → 종가는 장 마감 후 확정되므로 **다음 거래일**에 매매

### 2.2 생존 편향 (Survivorship Bias)

> 상장폐지·인수합병으로 사라진 회사를 **포함해서** 테스트해야 한다.
> 2015년 코스피 종목으로 테스트해야 하는데 지금 남아 있는 종목만 쓰면 그 사이
> 상장폐지된 부실기업이 전부 빠져 결과가 부풀려진다.

### 2.3 통화 기준

원화·달러 기준을 섞지 않는다. 환율에도 룩어헤드·정상성 문제가 있다.

### 2.4 결측치 — 시계열 특성을 고려한 보간

> 시계열 데이터의 추세·계절성을 반영한 보간법 고려 (예: ARIMA 기반)

일반 전처리(`02-preprocessing/4`)는 `dropna` · `fillna` · `replace` 로 결측을 다루고,
**NaN 이 아닌 `0`·`"-"`·`"?"` 로 들어온 결측**을 `np.nan` 으로 바꾸라고 합니다.

### 2.5 🔴 수업에 **없는** 것 — 이상치 처리

`2.금융데이터전처리.ipynb` 는 결측을 `isnull().sum()` 으로 세는 데서 멈춥니다.
윈저화·트리밍·MAD 같은 이상치 처리가 나오지 않습니다. **그래서 §4 를 외부 관행으로

## 4. 이상치 — 수업에 없어서 외부 관행으로 채웁니다

### 4.1 조사한 것

| 방법 | 흔한 임계값 | 어디서 쓰나 |
|---|---|---|
| 윈저화 (winsorize) | **5/95 백분위** (펀더멘털) · 1/99 (연구) | MSCI Quality 지수 방법론 · 팩터 구성 |
| MAD 수정 z-점수 | `0.6745·(x−중앙값)/MAD`, **\|z\|>3** | 두꺼운 꼬리에 강건 |
| 3-시그마 절단 | ±3σ | Barra USE4 — **자료 오류 제거** 단계 |
| 순위화 (rank) | — | 횡단면 팩터 구성의 기본 |

출처: MSCI Quality Index Methodology · Barra USE4 Methodology Notes(2011) ·
scipy `mstats.winsorize` · zipline `pipeline.factors` · Lopez de Prado,
*Advances in Financial Machine Learning*.

### 4.2 🔴 그런데 우리는 가격을 자르지 않습니다

윈저화는 **횡단면 팩터**에 씁니다 — 같은 날 여러 종목의 값을 나란히 놓고 꼬리를
자르는 것입니다. 우리 `daily_price` 는 **원자료**라 자르면 안 됩니다. 이유 셋:

1. **잘린 값은 되돌릴 수 없습니다.** 원자료를 고치면 나중에 "진짜였다"는 것을 알아도
   복원할 방법이 없습니다.
2. **극단이 대부분 진짜입니다.** 아래 §4.3 이 그 증거입니다.
3. **자르면 결함이 숨습니다.** 감자 미조정 17자리는 극단이라서 눈에 띄었습니다.
   미리 잘라 두었다면 영영 못 찾았을 것입니다.

**그래서 우리 규약은 이렇습니다.**

| 층 | 이상치를 어떻게 하나 |
|---|---|
| 수집 (`ingest/`) | **아무것도 자르지 않는다.** 받은 그대로 담는다 |
| 검사 (`scripts/verify_*`) | 극단을 **세고 원인으로 가른다.** 설명 안 되면 붉게 띄운다 |
| 공급 (`supply/`) | 설명 안 되는 날에 **표시(flag)를 붙여** 내보낸다 |
| 피처 (`features/`) | 여기서 자른다 — **수익률·피처 단계**, 횡단면 윈저화 |

## 5. 결측 — 0 과 NaN 은 다릅니다

### 5.1 실측

| 칸 | 결측 | 0 인 행 | 뜻 |
|---|---:|---:|---|
| `open`·`high`·`low` | 0 | **284,107 (3.08%)** | 체결이 없던 날 (거래정지) |
| `close` | 0 | 0 | 정지 중에도 잔존종가가 있다 |
| `volume` | 0 | 283,982 (3.08%) | 거래 없음 |
| `adj_open`·`adj_high`·`adj_low` | **284,107 (3.08%)** | — | 원가격이 0 이라 배율을 못 곱한다 |
| `adj_close` | 0 | 0 | — |

**같은 3.08% 가 원가격에서는 `0`, 수정주가에서는 `NaN` 입니다.** 이건 의도된 것입니다 —
`0` 은 KRX 가 준 그대로이고, `NaN` 은 *"이 날은 값이 없다"* 를 우리가 밝힌 것입니다.

### 5.2 🔴 팀원이 지켜야 할 것

```python
# 이러면 안 됩니다 — "그 날 0원" 이 됩니다
df["adj_open"].fillna(0)

# NaN 은 참입니다. 빈 값 판정은 pd.isna 로
if pd.isna(x): ...           # ✅
if not x: ...                # ❌ NaN 은 False 가 아닙니다
```

앞으로 채우기(forward-fill)를 쓸 거라면 **거래정지·상장폐지를 넘어 채우지 않도록**
`limit` 을 두어야 합니다. 정지 구간을 직전 가격으로 메우면 그 기간 변동성이 0 이 되고,
정지가 풀린 날 점프가 통째로 하루에 몰립니다.

> 신장환님이 `features/indicators.py` 의 RSI 결측 델타를 **`nan` 으로 정직하게 전파**하도록
> 고치셨습니다(PR #81). 그 방향이 이 규약과 같습니다.

### 6.2 왜 놓쳤나 — 액면가로 판정했기 때문입니다

**액면분할·병합은 액면가가 같이 바뀝니다.** 10:1 병합이면 액면가 500원 → 5,000원.
그래서 액면가를 대조하면 잡힙니다.

**그런데 감자는 액면가가 그대로입니다.** 주식수만 줄고 액면가는 유지됩니다.
실제 기사도 그렇게 씁니다 — *"보통주 10주를 **동일 액면가**의 1주로 병합하는 무상감자"*
(케이피엠테크, 2026-08). 우리가 찾은 042040 케이피엠테크 20260626 건과 같은 사건입니다.

처음 만든 검사는 이 축을 안 봤습니다. 219건이 전부 "설명 안 됨"으로 쏟아졌고
그 안에 진짜 결함이 묻혔습니다.

### 6.6 🆕 관문이 셋이 됐습니다 (2026-09-05 · v3.6)

전 종목 3,677종으로 넓히자 관문 둘이 못 막는 자리가 나왔습니다 — **인적분할을 감자로
오인**해 과거 803행을 1.567배로 부풀린 자리입니다(삼양제넥스 003940 · 2013-03-25).

| 관문 | 무엇을 묻나 | 임계 |
|---|---|---|
| ① | 원가격이 계수만큼 실제로 튀었나 | `CA_PRICE_TOLERANCE` 0.30 |
| ② | FDR 이 그것을 안 폈나 | `CA_SCALE_TOLERANCE` 0.10 |
| 🆕 ③ | **FDR 이 이미 KRX 기준가만큼 폈나** | `CA_BASIS_TOLERANCE` 0.10 |

③이 필요한 이유는 **KRX 가 조정한 폭 자체가 작은 사건**이 있기 때문입니다. 인적분할은
주식수가 줄어도 가격이 거의 안 움직여서, FDR 이 제대로 폈는데도 ②의 창(±0.10) 안에
들어옵니다.

**결정적 증거**는 FDR 이 정지일에 주는 값이었습니다.

```
20130322  원문 종가 68,900 → FDR 70,500      ← KRX 기준가를 준다
FDR 이 편 폭  1.023222
KRX 기준가비  1.023222                        ← 여섯 자리까지 같다
```

FDR 은 사건을 알고 KRX 기준가만큼 정확히 폈습니다. **틀린 것은 FDR 도 관문도 아니라 우리
계수**였습니다 — 재개일이라 상장주식수 배율에서 얻는데, 인적분할에는 그 값이 안 맞습니다.

#### 임계는 재고 나서 적었습니다

발동한 **22자리 전부**에서 세 후보 지표를 쟀습니다.

| 지표 | 오검출 자리 | 가장 가까운 정상 자리 | 판정 |
|---|---:|---:|---|
| ① `\|보정후\|` | 0.2774 | 0.2831 | 🔴 **못 가른다** — 정상 쪽이 더 의심스럽다 |
| ② `\|보정후 − KRX\|` | 0.3838 | 0.2831 | 여유 1.36배 — 조이면 진짜 감자를 잃는다 |
| ③ `\|실제 ÷ 기준가비 − 1\|` | **0.0000** | **0.5000** | ✅ **틈이 비었다** |

임계를 낮은 쪽(0.10)에 붙였습니다. **조정을 놓치면 수익률이 틀리지만, 없는 조정을 만들면
멀쩡한 과거 전체를 망칩니다.**

⚠️ `기준가비 != 1` 조건이 함께 필요합니다 — **감자인데 KRX 등락률이 `0.00%` 인 자리가
실재**합니다(참엔지니어링 2026-05-11). 그 조건이 없으면 진짜 감자를 놓칩니다.

#### 남는 한계

- **자본변동 당일 하루는 여전히 부정확합니다.** 다음날부터는 정확합니다.
- **FDR 이 조정을 하루 일찍 놓는 자리**가 둘 있습니다(티이엠씨 2023-12-28 ·
  폰드그룹 2025-12-30). 우리가 만든 것이 아니라 FDR 원값의 성질입니다.

#### `verify_base_info` §9 임계는 2배를 유지합니다

1.5배로 내릴지 검토했는데, 계수가 `1.5~2.0`(또는 그 역수) 구간인 발동 자리가 **삼양제넥스
하나이고 그것이 감자가 아닙니다.** 내리면 오경보만 하나 늘어납니다.

### 7.1 반출 전에 검증기를 전수로 돌린다

HF 업로드 스크립트가 `verify_*` 를 먼저 돌리고, **하나라도 붉으면 올리지 않습니다.**
"고쳤다"와 "나갔다"는 다릅니다 — 2026-09-03 에 이미 한 번 겪었습니다.

안 봐도 결함을 알 수 있게 합니다.

### 7.3 축이 둘이면 표본도 둘로 넓힌다

검사를 쓸 때마다 **"이 검사가 안 보는 축은 무엇인가"** 를 주석으로 적습니다.
오늘 두 번 다 그 질문을 안 해서 틀렸습니다.
