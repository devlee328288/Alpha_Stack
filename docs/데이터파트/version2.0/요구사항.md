## 1. 공통 규칙 D-00 ~ D-04 — ✅ **전부 구현됐습니다**

> **v1.0 에서는 "만들 것"이었습니다.** 2026-08-26 에 다섯 건 모두 코드로 섰습니다
> (PR #4 · #5). 이 절은 이제 **명세가 아니라 계약**입니다 — 뒤에 오는 출처는 여기에 맞춰야 합니다.

| ID | 규칙 | 어디에 섰나 | 상태 |
|---|---|---|---|
| **D-00** | **Point-in-Time** — `as_of` 없이는 과거를 못 본다 | `supply/` (228줄) | ✅ **정문 신설.** `supply/` 밖에서 `ingest.store` 를 import 하면 **테스트가 실패**한다 |
| **D-01** | **원본 보존 · 정규화 분리** | `common/raw_store.py` · `scripts/renormalize.py` | ✅ 응답 원문을 그대로 남기고 **재호출 없이 재정규화**한다. 지수·종목 **둘 다**. 재정규화가 **수집 시각을 건드리지 않는다** |
| **D-02** | **수집 대장 · 워터마크** | `ingest/store/collect_log.py` | ✅ 안 받은 이유를 **넷으로 가른다** — 0건(휴장) · 한도소진 · 범위밖 · 실패 |
| **D-03** | **`robots.txt` 실행 시점 확인** | `common/robots.py` (`protego==0.6.2`) | ✅ **4xx=허용 / 5xx·네트워크오류=전면차단** (RFC 9309). 24시간 캐시. ⚠️ **부르는 수집기가 아직 0건** |
| **D-04** | **호출 예산 관리** | `common/budget.py` | ✅ 80% 경고 · 100% 정상종료. **네트워크로 나가는 자리에서** 센다(재시도분 누락 방지) |

### 이 계약이 뜻하는 것

- **새 수집기는 이 다섯을 쓰는 것이 기본값입니다.** 안 쓰면 그게 예외이고 이유를 적어야 합니다.
- **`as_of` 는 `supply/` 정문에만 강제됩니다.** `ingest`·`store` 는 내부 계층이라
  `as_of` 를 받지 않습니다. 경계를 코드가 지킵니다.
- **한도 소진은 실패가 아닙니다.** 재시도 횟수를 먹지 않고, 예산이 풀리면 다시 받습니다.

> 🔴 **D-03 은 섰지만 아직 쓰이지 않습니다.** 크롤러 자체가 없어서
> `robots.require()` 호출처가 0건입니다. D-20~D-23 을 만들 때 **반드시 통과시킵니다.**

## 2. Must — 수집기 (`ingest/`)

### 2.1 이미 서 있는 출처

| ID | 기능 | 수용 기준 |
|---|---|---|
| **D-10** | **거래일 캘린더 · 품질 게이트** (팀 F-03 이관) | 품질검사 실행 → `reports/data_quality.json`. 누락 거래일이 0건이거나 **그 날짜가 전부 열거**된다. 실패 시 `exit 1`. ⚠️ **`scripts/check_data.py` 가 없다** — 실재는 `check_index_data.py`. 이름을 맞춰야 한다 |
| **D-11** | **일 1회 증분 배치** — 시세·지수·공시·통계 | 한 번 실행으로 4종이 워터마크 이후만 받는다. **두 번 연속 실행 시 두 번째는 신규 0건**. 소요 시간과 호출 수를 로그로. **대장(D-02)을 읽어 무엇을 건너뛸지 정한다** |
| **D-12** | **DART point-in-time 적재** | 모든 행에 접수일이 `known_at` 으로 들어간다. 접수일 없는 응답은 **적재 거부**. `as_of` 조회 테스트 통과. ⚠️ **접수일은 `list.json` 조인으로 얻는다** — `rcept_no[:8]` 슬라이싱은 4,800건 중 3건이 어긋났고 **둘은 미래를 3일 먼저 본다** |
| **D-13** | **통계 3종(ECOS·FRED·KOSIS) 정규화 통일** | 세 출처가 `(date, series_id, value, known_at)` **같은 스키마**로 들어온다. 출처별 컬럼명이 바깥으로 새지 않는다 |

### 2.2 새로 만드는 출처

| ID | 기능 | 수용 기준 |
|---|---|---|
| **D-20** | **뉴스 수집기** (네이버 검색 API) | `(제목, 요약, 링크, 발행시각, 산업/종목, 수집시각)` 저장. **본문 전문은 저장하지 않는다.** `<b>` 태그·HTML entity 제거를 테스트로 확인. **산업(섹터) 단위로 수집**하고 종목 지정 검색은 요청 시점에 |
| **D-21** | **커뮤니티 수집기** — 카페글 (네이버 검색 API) | 뉴스와 **같은 쿼터를 나눠 쓴다**는 사실이 예산에 반영된다. 합계가 25,000 을 넘지 않음을 테스트. ⚠️ **카페글 응답에는 `pubDate` 가 없다** — 뉴스와 스키마를 따로 잡는다 |
| **D-23** | **동영상 수집기** (YouTube Data API v3) | **`search.list` 를 호출하는 코드가 없다**(grep 확인). `channels.list` → `uploads` 재생목록 → `playlistItems.list` → `videos` 통계 경로만. 메타데이터만 저장, **영상·자막 원문은 저장하지 않는다**. ⚠️ 영상 게시시각은 `contentDetails.videoPublishedAt` — `snippet.publishedAt` 은 *"재생목록에 추가된 시각"* 이다 |

> 🔴 **D-22(종목토론방)는 삭제됐습니다.** `robots.txt` 원문을 확인하니 허용 규칙이
> 전부 `User-agent: yeti`(네이버 자체 크롤러) 그룹 소속이고, 제3자 봇이 매칭되는
> `User-agent: *` 그룹은 **`Disallow: /` 전면 불허**입니다. → **수집 범위 4종 → 3종**

> 🔴 **D-20·D-21·D-23 은 백테스트에 쓸 수 없습니다.** 네이버 API 는 1,000건 창이라
> **과거 소급이 불가능**합니다. 이 3종은 **오늘부터 앞으로 누적**되고 용도는 **시연과 2차**입니다.
>
> **수용 기준에 포함**: 이 3종을 조회하는 함수가 `2026-09-01` 이전 구간을 요청받으면
> **빈 결과와 함께 경고**를 남긴다. 조용히 빈 배열을 주지 않는다.

## 6. 품질 게이트 — `reports/data_quality.json`

| 항목 | 내용 |
|---|---|
| `coverage` | 출처별 (시작일, 종료일, 거래일 수, 기대 거래일 수) |
| `missing_dates` | **날짜 배열.** 개수만 적지 않는다 |
| `zero_row_days` | "받아 봤더니 0건"인 날 — 공백이 아니다 |
| `duplicates` | (테이블, 키, 건수) |
| `null_violations` | `known_at` 이 비어 적재 거부된 건수 |
| `ohlc_violations` | `low <= open,close <= high` 위반 행 |
| `outliers` | 일 변동 ±30% 초과 등. **버리지 않고 열거만** 한다 |
| `quota_usage` | 출처별 (사용, 한도, 비율) — 예산(D-04)에서 그대로 |
| `generated_at_kst` | 생성 시각 |

**`exit 1` 조건**: `missing_dates` 가 비어 있지 않은데 **열거되지 않은 경우**,
또는 `null_violations > 0`.

> ⚠️ **이상치를 자동으로 버리지 않습니다.** 2020-03 코로나 급락은 이상치처럼 보이지만
> 실제 사건입니다. 버리면 우리 자료가 현실과 달라집니다. **열거하고 사람이 봅니다.**
