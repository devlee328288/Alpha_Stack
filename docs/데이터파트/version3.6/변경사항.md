## 1. 🔴 관문이 둘로는 부족했다 — 인적분할을 감자로 오인했다

### 무엇이 일어났나

| | 09-04 (v3.5) | 오늘 첫 적재 | 관문 ③ 뒤 |
|---|---:|---:|---:|
| 돌린 범위 | **16종** (`--codes`) | 3,677종 | 3,677종 |
| ca_fix 행 | 43,778 | 46,966 | **46,163** |
| ca_fix 종목 | 16 | 21 | **20** |

전 종목으로 넓히자 다섯이 늘었습니다 — `33637L` 솔루스첨단소재2우B · `101970`
우양에이치씨 · `472850` 폰드그룹 · `425040` 티이엠씨, 그리고 **`003940` 삼양제넥스**.

앞의 넷은 그 날 수정등락이 KRX 등락률과 **소수점까지 일치**합니다. 삼양제넥스만
어긋났습니다.

```
003940 삼양제넥스 2013-03-25
  보정 후 그날 수정등락  -27.74%
  KRX 등락률            +10.64%     ← 부호까지 다르다
  영향 범위             과거 803행이 1.567배로 부풀었다
```

### 왜 그랬나 — 계수가 틀렸다

거래정지 사흘 뒤 재개일이라 계수를 **상장주식수 배율**에서 얻습니다.

| | 값 |
|---|---|
| 상장주식수 | 2,985,917 → 1,905,907 (**0.6383배**) → 계수 **1.5667** |
| KRX 기준가 | 70,500 — 직전 종가 68,900 의 **1.0232배**뿐 |

감자였다면 기준가가 `68,900 × 1.5667 ≈ 108,000` 이어야 합니다. **인적분할입니다** —
회사가 쪼개져 주식수가 줄었을 뿐 남은 주식의 가치는 그대로입니다.

### 관문 둘이 다 통과했다

```
관문 ①  |1.1321 / 1.5667 - 1| = 0.2774  <= 0.30   ← 0.026 차이로 들어왔다
관문 ②  |1.0232 - 1|          = 0.0232  <= 0.10   ← FDR 이 편 폭이 작았다
```

🔴 **관문 ①이 견주는 대상이 잘못돼 있었습니다.** `원가격비/계수 - 1` 은 *보정한 뒤 그 날의
수정등락 그 자체*인데, 관문은 그것을 **0** 과 견줍니다. 정답은 0 이 아니라 KRX 등락률입니다 —
감자일에도 주가는 움직입니다.

## 2. 무엇으로 갈랐나 — FDR 은 정지일에 KRX 기준가를 준다

결정적 증거가 원문에 있었습니다.

```
20130320  원문 종가 68,900 → FDR 70,500
20130321  원문 종가 68,900 → FDR 70,500
20130322  원문 종가 68,900 → FDR 70,500     ← 기준가를 준다
```

FDR 이 편 폭 `1.023222` 와 KRX 기준가비 `70,500/68,900 = 1.023222` 가 **소수 여섯 자리까지
같습니다.** FDR 은 이 사건을 알고 KRX 기준가만큼 정확히 폈습니다. 인적분할이니 그게 맞는
조정이고, **틀린 것은 FDR 도 관문도 아니라 우리 계수**였습니다.

## 3. 임계는 재고 나서 적었다

관문이 실제로 발동한 **22자리 전부**에서 세 후보 지표를 쟀습니다.

| 지표 | 삼양제넥스 | 가장 가까운 정상 자리 | 판정 |
|---|---:|---:|---|
| ① `\|보정후\|` | 0.2774 | **0.2831** (004555 대우송도개발1우) | 🔴 **못 가른다** — 정상 쪽이 더 의심스럽다 |
| ② `\|보정후 − KRX\|` | 0.3838 | 0.2831 (004555) | 여유 1.36배 — 조이면 진짜 감자를 잃는다 |
| ③ `\|실제 ÷ 기준가비 − 1\|` | **0.0000** | **0.5000** (009415 태영건설우) | ✅ **틈이 비었다** |

①로는 **아예 못 가릅니다** — 삼양제넥스가 정상 자리보다 오히려 덜 의심스럽게 나옵니다.
②도 여유가 1.36배뿐이라, 임계를 조이면 `004555`(진짜 감자인데 거래정지 중이라 기준가가
무의미한 자리)를 먼저 잃습니다.

③은 0.0000 과 0.5000 사이가 **통째로 비어 있습니다.** 임계를 낮은 쪽에 붙여 `0.10` 으로
뒀습니다 — 정상 자리를 잃는 것이 오검출보다 비싸기 때문입니다. **조정을 놓치면 수익률이
틀리지만, 없는 조정을 만들면 멀쩡한 과거 전체를 망칩니다.**

### 관문 ③ (신설)

`ingest/store/adj_price.py::_fix_unadjusted_actions`

```python
# ③ FDR 이 이미 KRX 기준가만큼 폈나 — 그러면 틀린 것은 계수다.
기준가비 = Fraction(int(종가 - 전일대비), int(앞종가))
if 기준가비 != 1 and abs(float(실제 / 기준가비) - 1) <= CA_BASIS_TOLERANCE:
    continue
```

`기준가비 != 1` 조건이 필요합니다 — KRX 가 기준가를 안 바꾼 날에는 대조할 것이 없고,
**감자인데 등락률이 `0.00%` 인 자리가 실재**합니다(참엔지니어링 2026-05-11). 그 조건이
없으면 진짜 감자를 놓칩니다. 시험으로 박아 뒀습니다.

- 시험 **3건 추가** (1,129 → **1,132 passed** · 3 xfailed)
- ruff **0** (내 파트)

## 6. `verify_base_info` §9 임계는 2배로 둔다 (검토 완료)

§9 는 "주식수가 **2배 이상** 변한 자리"만 봅니다. 1.5배로 내릴지 검토했는데, 오늘 답이
나왔습니다.

계수가 `1.5~2.0`(또는 그 역수) 구간인 발동 자리를 전부 세니 **삼양제넥스 1.5667 하나이고,
그것이 감자가 아닙니다.** 임계를 내리면 오경보만 하나 늘어납니다. **2배를 유지합니다.**
