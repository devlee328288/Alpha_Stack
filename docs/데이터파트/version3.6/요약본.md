## 팀원은 이렇게 씁니다

- **학습 자료**: HF `alphastack-krx-dev` — 수익률·라벨은 `adj_close`, 시가총액만 `close`
- **재무**: `financial/` 또는 `alphastack-dart` 의 **pit/** 만 (bulk/ 는 접수일이 없어 학습 금지)
- **신원**: `identity/` — `crno` 로 종목 ↔ 법인 ↔ 재무를 잇는다 · 외국기업 `0000000000000` 은 먼저 거른다
- **공시 감성**: `text/` — 넣어도 안 오른다는 실측이 카드에 있다 · `report_nm` 은 피처가 아니다
- **키**: `python scripts/check_keys.py --live` · [가이드](API키_발급_가이드.md)
- **코드로 조회**: `supply.index_series(as_of=...)` — `as_of` 없이는 안 열립니다

## 조심할 것 세 가지

1. **p 값이 아니라 효과크기를 본다** — 126만 행에서 p < 1e-300 은 아무것도 말해 주지 않는다
2. **스크래치로 고친 것은 고쳐진 것이 아니다** — DB 가 맞아도 만든 방법이 없으면 다시 깔 때 돌아온다
3. **계수를 믿기 전에 원가격으로 검산한다** — 인적분할·출자전환은 주식수가 크게 움직여도 가격이 연속이다
4. **텍스트 피처는 "언제 적혔나"가 새는지 본다** — 제목 속 연월이 시장 국면을 가리킨다
