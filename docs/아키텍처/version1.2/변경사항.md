# 아키텍처 v1.1 → v1.2 변경사항

> 2026-08-29 · 품질 게이트(PR #9) · 시세 공급 정문(PR #10) 이후 · 킥오프(9/1) 발표 준비

---

## 왜 올렸나

두 가지가 겹쳤습니다.

**① 코드가 그림보다 앞서 나갔습니다.** v1.1 을 쓴 뒤 같은 날 PR 두 건이 들어왔습니다.

- PR #9 — 품질 게이트(`scripts/check_data.py` · `common/corporate_actions.py`)
- PR #10 — 시세 공급 정문(`supply.price_series`)과 **학습 전용 경로**(`training_frame`)

특히 PR #10 은 `supply/` 를 **문 하나에서 문 둘로** 바꿨습니다. v1.1 그림에는 그 구분이
없어서, 그림만 보면 정문이 정리매매 판정까지 하는 것처럼 읽힙니다. **정반대입니다.**

**② 발표용 그림이 필요했습니다.** 기존 `.mmd` 3장은 *"무엇이 무엇으로 흐르나"* 를 그리는
데는 맞지만, **카드 안에 부제와 배지를 넣는 자유 배치**를 표현할 수 없습니다. 킥오프에서
팀·교수님께 보여 줄 그림은 그 설명이 그림 안에 들어 있어야 합니다.

## 무엇이 바뀌었나

### ① 발표용 구성도 2장을 HTML 로 새로 그렸다 ★

| 파일 | 무엇 |
|---|---|
| [시스템아키텍처.html](시스템아키텍처.html) · [.png](시스템아키텍처.png) | **최종 목표 구성 전체.** 지금 서 있는 것과 계획을 실선·점선으로 가름 |
| [AI에이전트구성.html](AI에이전트구성.html) · [.png](AI에이전트구성.png) | **제안**. 킥오프 안건이며 아직 결정된 것이 아님 |

**HTML 이 정본이고 PNG 는 거기서 굽습니다.**

```bash
node scripts/render_html.mjs docs/아키텍처/version1.2/시스템아키텍처.html
node scripts/render_html.mjs docs/아키텍처/version1.2/AI에이전트구성.html
```

PNG 만 커밋하면 이력에 바이너리 덩어리만 쌓이고 **무엇이 달라졌는지 아무도 못 읽습니다.**
HTML 을 정본으로 두면 `git diff` 에 그대로 보입니다. `.mmd` 를 정본으로 두는 이유와 같습니다.

> ⚠️ **`.mmd` 3장을 버리지 않았습니다.** 계층 아키텍처처럼 흐름이 전부인 그림은 mermaid 가
> 더 짧고 고치기 쉽습니다. 새 HTML 2장은 **발표용**이고, 둘은 목적이 다릅니다.

### ② 그림에 "서 있는 것"과 "계획"을 표시했다 ★

v1.1 그림은 전부 같은 선으로 그려져 있어서, 보는 사람이 `features/`·`models/` 가
이미 있는 줄 압니다. **실제로는 `__init__.py` 뿐입니다** (각각 35줄·34줄).

v1.2 는 실선 = 서 있는 것, 점선 = 계획으로 가릅니다. 실측:

```
서 있는 것   common 2,668 · ingest 7,546 · supply 591 · evaluation 848
             timeseries 2,063 · scripts 3,107 · tests 4,016
뼈대만       api 28 · features 35 · models 34
비어 있음    pipelines
없음         CI · Streamlit 코드
```

전체 구성을 그리되 **그림이 사실보다 앞서지 않게** 하는 것이 목적입니다.

### ③ `supply/` 가 문 하나에서 문 둘이 됐다 ★

```
supply.price_series(as_of=…)      그 시점에 알 수 있었던 것만. 플래그를 붙이지 않는다
supply.training_frame(…)          학습 전용 — 여기서만 미래를 본다
```

정리매매 판정은 *"이 뒤로 체결이 끊긴다"* 를 보고 정해집니다. 즉 **그 시점에는 알 수 없는
사실**입니다. `as_of` 정문이 그걸 계산해 행을 덜어내면, 문이 지키려던 경계를 문이 스스로
넘습니다. 그래서 손잡이가 아니라 **이름**으로 갈랐습니다.

### ④ 품질 게이트를 그림에 넣었다

자동화 띠에 `증분 수집 → 품질 게이트 → reports/data_quality.json → 학습·평가` 를 그렸습니다.
게이트는 **설명되지 않는 값에만** 걸립니다 — 가격제한폭 밖 2,080행을 정리매매·거래정지·
자본변동·신규상장으로 설명하고 **잔여 0**입니다.

## 아직 그림에 없는 것

- **역할별 파이프라인·일정 간트**(`.mmd` 2장)는 v1.1 그대로입니다. 킥오프에서 역할이
  확정되면 그때 함께 고칩니다 — 지금 고치면 **확정 전 추측을 그림으로 굳히는 일**입니다.
- **CI 가 없습니다.** `.github/workflows` 가 비어 있어서 품질 게이트를 사람이 손으로
  돌립니다. 그림의 자동화 띠는 그 사실대로 "배치는 계획" 이라고 적었습니다.
