① 저장소를 직접 부르지 않는다

features · models · evaluation 이 ingest 를 import 하면 테스트가 실패한다. 규칙을 문서에만 적으면 급할 때 지나가고, 지나간 코드는 티가 안 난다.

② evaluation 은 models 를 모른다

받는 것은 positions · returns 배열 둘뿐이다. 1차 LightGBM 이든 2차 자산배분 규칙이든 같은 함수가 돈다.

③ 게이트는 설명되지 않는 값에만 건다

가격제한폭 밖 2,080행을 정리매매·거래정지·자본변동·신규상장으로 설명하고 잔여 0. 첫날부터 빨간불이면 팀이 게이트를 끈다.
