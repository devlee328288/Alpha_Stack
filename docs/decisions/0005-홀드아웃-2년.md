# ADR 0005: 최종 홀드아웃을 최근 2년으로 둔다

- 상태: 승인
- 결정일: 2026-09-02
- 관련 논의: GitHub 이슈 #63

## 맥락

기존 홀드아웃은 `20210901`부터 시작해 약 5년이었다. 공시 접수일 기준으로 재무를
정렬하면 전체 662,933행 중 개발구간에 300,991행(45.4%)만 남고, 최신 학습 가능
재무도 FY2020에 그쳤다. 반면 홀드아웃을 지나치게 줄이면 최종 평가가 단일 시장 국면과
적은 시계열 표본에 좌우될 수 있다.

## 결정

`evaluation.horizon.HOLDOUT_START`를 `20240901`로 변경한다.

- 개발구간: `bas_dd < 20240901`
- 봉인구간: `bas_dd >= 20240901`
- 모델 선택에는 개발구간의 워크포워드 결과만 사용한다.
- 봉인구간은 피처·모델·가중치·임계값이 확정된 뒤 최종 평가에서만 사용한다.
- 미래 5거래일 라벨이 경계를 넘지 않도록 모델 입력에서 경계 직전 5거래일을 비운다.

모델 노트북은 `supply.model_data.holdout_safe_frame`이 반환한 데이터만 사용한다. 입력
파일에 봉인구간이 섞여 있으면 함수가 봉인구간과 경계 직전 레이블 지평을 제거한다.

## 결과

이슈 #63의 실측 기준으로 재무 개발구간은 498,059행(75.1%), FY2023까지 늘어난다.
최근 약 2년은 최종 홀드아웃으로 유지한다. 기존 모델 결과는 과거 경계에서 얻은 실험
기록으로 남으며, 새 개발 데이터가 공급된 뒤 전부 다시 실행해야 한다.

`scripts/export_team_dataset.py`의 개발 종료일은 홀드아웃 시작일 하루 전으로 자동
계산한다. 따라서 경계 상수와 반출 종료일이 서로 다른 연도에 남는 문제를 막는다.
