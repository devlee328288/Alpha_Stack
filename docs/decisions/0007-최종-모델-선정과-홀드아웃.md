# ADR 0007: 최종 모델 선정 기준과 홀드아웃 사용 횟수를 고정한다

- 상태: 승인
- 결정일: 2026-09-08
- 관련 논의: GitHub 이슈 #166 · #168

## 맥락

개별종목 조합 A~H와 모델 4종을 같은 날짜·종목 표본에서 비교했다. 기존 조화평균은
Accuracy·Macro F1·하락 Recall을 같은 비중으로 합친다. 그러나 현재 매매 정책은 상승
예측만 매수하고 중립·하락 예측에는 현금을 보유하는 `{0, +1}` 정책이다. 하락 Recall이
높은 모델을 최종 선택하면 실제 포지션을 만들지 않는 예측에 가점을 주게 된다.

또한 32개 후보를 비교했으므로 개발구간 최고점을 그대로 일반화 성능으로 해석할 수 없다.
홀드아웃 결과를 본 뒤 피처·모델·class weight를 다시 고르면 봉인 구간도 개발구간이 된다.

## 결정

class weight는 각 외부 학습구간 안의 60거래일 검증·gap 5에서 기존 조화평균으로 고른다.
그 선택을 포함해 만들어진 외부 OOS 결과로 최종 조합·모델을 다음 순서로 고정한다.

1. 모델 Accuracy − 외부 학습구간 최빈 클래스 기준선 Accuracy의 평균
2. Macro F1
3. 12개 외부 폴드 중 학습 최빈 기준선을 이긴 폴드 수
4. 모두 같을 때만 조합명·모델명 순으로 재현 가능한 순서를 만든다

하락 Recall과 기존 3지표 조화평균은 진단값으로 계속 보고하지만 최종 선택에는 쓰지 않는다.
검증구간 최빈 클래스 비율은 정답을 본 oracle 통계이므로 선택 기준으로 사용하지 않는다.

홀드아웃은 위 규칙으로 후보 하나를 고정한 뒤 정확히 한 번 평가한다. 홀드아웃 결과로 피처,
모델, class weight, 중립대 또는 동률 기준을 다시 고르지 않는다. 바꿔야 한다면 이번 결과를
최종 결과로 기록하고 다음 실험으로 분리한다.

## 결과

- 개발구간 결과에는 선정 순서와 기준선 승리 폴드 수를 함께 남긴다.
- A~H 32개 후보 각각의 12폴드 Accuracy를 같은 폴드의 학습 최빈 기준선과 짝지어 단측
  Wilcoxon signed-rank 검정을 하고, 32회 전체에 Holm 보정을 적용했다.
- 유의수준 0.05에서 보정 뒤 유의한 후보는 0개였다. 가장 작은 원 p-value는 조합 D
  XGBoost의 `0.0171`이었지만 Holm 보정 뒤 `0.5469`였다. 최종 선택된 조합 A
  LogisticRegression은 원 p-value `0.0320`, 보정 p-value `0.9915`였다.
- 후보당 폴드가 12개뿐이고 expanding 학습창이 서로 겹치므로 검정력이 제한되고 폴드가
  완전히 독립이라는 보장도 없다. 이 결과는 모델 우위가 입증됐다는 주장을 막는 진단이며,
  사전등록한 최종 선정 순서를 사후에 바꾸는 기준으로 사용하지 않는다.
- 향후 공매도 등으로 포지션 정책을 `{-1, 0, +1}`로 바꾸면 별도 ADR에서 선택 기준도 다시
  결정한다. 이 ADR을 조용히 수정하지 않는다.
