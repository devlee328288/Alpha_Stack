# ADR 0010: 개봉 자료의 마지막 T+1→T+6 구간을 최종 평가한다

- 상태: 승인
- 결정일: 2026-09-11
- 결정: 오준영(모델링)
- 선행 기록: `reports/unseal.log` 2026-09-11 16:18:48 KST
- 대체하는 실행 해석: ADR 0009의 홀드아웃 전체 별도 평가 경로

## 맥락

기존 실행기는 `20240901` 이전 개발구간만 학습하고 그 이후 약 2년 전체를 별도 평가구간으로
사용하도록 구현돼 있었다. 개봉 뒤 최종 목적을 다시 확인한 결과, 의도한 산출물은 개봉 자료의
대부분까지 포함해 모델을 한 번 학습하고 자료 끝의 마지막 5거래일 보유 구간 하나를 예측하는
것이었다.

이 결정은 홀드아웃 개봉 뒤 실행 해석을 바꾸는 것이다. 따라서 이 결과를 ADR 0004·0009에서
사전등록한 “2년 전체의 확증적 홀드아웃 평가”라고 부르지 않는다. **개봉 후 목적을 바로잡은
마지막 한 구간 최종 운영 평가**로 보고한다. 모델·피처·class weight·지수 상승 임계값은
ADR 0009의 확정값을 그대로 사용하며 결과를 보고 다시 고르지 않는다.

## 결정

HF 원본 `full/index_price_dev.parquet`와 `full/daily_price_dev.parquet`의 실제 공통 거래일을
읽는다. 날짜를 코드에 고정하지 않고 마지막 공통 거래일을 `T+6`, 그 거래일 목록에서 6칸
앞의 날짜를 판단일 `T`, 바로 다음 날짜를 진입일 `T+1`로 정한다.

- 피처 계산은 개봉된 전체 원본을 허용한다.
- 학습은 최종 판단 시점에 이미 정답을 알 수 있는 행만 사용한다.
  - KOSPI200: 라벨 청산 위치가 판단일 이하인 행
  - 개별종목: `exit_bas_dd <= T`인 행
- `T`행은 학습하지 않고 최종 예측·평가에만 사용한다.
- KOSPI200은 조합 C LogisticRegression, 개별종목은 조합 K LogisticRegression만 실행한다.
- 두 예측이 모두 상승인 종목만 `buy_candidate=True`로 기록한다.

개발 실험의 기존 봉인은 유지한다. 피처 생성 함수의 기본값은 계속 `20240901` 이후를 거부하고,
개봉 기록을 확인하는 `scripts/run_final_window.py`만 `allow_unsealed=True`를 명시한다. 이것은
홀드아웃 차단을 조용히 없애 기존 실험을 오염시키지 않으면서, 개봉 후 최종 실행에서만 전체
자료를 사용하기 위한 경계다.

## 결과

- 실제 마지막 날짜가 바뀌어도 판단일·진입일·청산일이 거래일 기준으로 자동 계산된다.
- 마지막 목표 구간 `T+1~T+6`의 가격을 사용하는 라벨은 학습에 들어가지 않는다.
- 기존 2년 전체 홀드아웃 결과와 직접 비교하거나 확증적 결과라고 주장하지 않는다.
- 결과에는 원본 두 파일, 설정, 개봉 기록의 SHA-256과 세 날짜를 남긴다.
