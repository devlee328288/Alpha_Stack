# ADR 0006: 개별종목 중립대와 평가 기준선을 정한다

- 상태: 승인
- 결정일: 2026-09-07
- 관련 논의: GitHub 이슈 #158

## 맥락

KOSPI200은 5거래일 수익률 `±1.0%`를 중립대로 사용하지만 개별종목 라벨의 중립대는
코드의 `STOCK_NEUTRAL_BAND = 0.02`로만 존재하고 결정 근거가 없었다. 같은 T+1
`adj_open` 진입, T+6 `adj_open` 청산 기준으로 측정한 개별종목 후보의 수익률 표준편차와
평균절대수익률은 KOSPI200의 약 2.1배였다. 이에 따라 지수 중립대를 변동성에 비례시키면
약 `±2.1~2.2%`가 된다.

`±1.75%`에서는 세 클래스 비율이 더 균등해지지만, 클래스 균형과 낮은 정확도 기준선을
목적으로 라벨을 바꾸면 모델 성능을 확인한 뒤 목표를 조정하는 문제가 생길 수 있다.

기존 보고서는 전체 OOS 정답에서 가장 많은 클래스를 찾은 단일 정확도를 기준선으로
기록했다. 이 값은 검증 정답 분포를 미리 본 사후 통계이므로 실제 예측 시점에 사용할 수
있는 비교 기준선과 구분해야 한다.

## 결정

개별종목의 5거래일 라벨은 다음과 같이 유지한다.

- 수익률 `> +2.0%`: 상승
- 수익률 `< -2.0%`: 하락
- 나머지: 중립
- 수익률은 T+1 `adj_open` 진입과 T+6 `adj_open` 청산으로 계산한다.

각 외부 워크포워드 폴드에는 다음 값을 함께 기록한다.

1. 학습구간 최빈 클래스를 검증구간 전체에 예측한 정확도
2. 모델 정확도에서 위 기준선 정확도를 뺀 값
3. 검증구간의 클래스별 비율
4. 검증구간 최빈 클래스 비율은 `oracle` 사후 참고값으로 명시

학습 클래스가 정확히 동률이면 검증 정답을 보지 않고 `중립 → 하락 → 상승`의 고정된
순서로 선택한다. Top-K 종목 랭킹의 무작위 기준선은 전체 개발기간의 고정 비율이 아니라
KOSPI200과 개별종목의 공통 OOS에서 지수 예측 방향별 평가 후보를 기준으로 계산한다.

## 결과

- 후보군, 피처 조합 A~F, 모델 4종, class weight 및 워크포워드 규칙은 바뀌지 않는다.
- 기존 모델 예측은 유지하고, 저장된 분할과 라벨로 기준선만 다시 계산할 수 있다.
- 향후 중립대를 바꾸려면 별도 ADR을 작성하고 개별종목 라벨, class weight, 모델 비교와
  랭킹을 모두 다시 평가한다.
- `validation_majority_oracle_accuracy`는 분포 설명용이며 모델 우위 판정에 사용하지 않는다.
