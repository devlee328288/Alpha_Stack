# ADR 0009: 최종 홀드아웃 단일 실행 설정을 봉인한다

- 상태: 승인
- 결정일: 2026-09-11
- 승인: 오준영(모델링)
- 관련 논의: GitHub 이슈 #240 · ADR 0007

## 맥락

ADR 0007은 개발구간의 각 외부 폴드 안에서 class weight를 고르고 그 OOS 결과로 최종
조합과 모델을 선택했다. 그 결과 KOSPI200은 조합 C LogisticRegression, 개별종목은 조합 K
LogisticRegression으로 고정됐다.

하지만 실제 홀드아웃은 외부 폴드가 하나뿐이다. 전체 개발구간으로 한 번 학습하려면 폴드마다
달랐던 class weight와 KOSPI200 상승 임계값을 단일 값으로 바꾸는 규칙이 개봉 전에 필요하다.
이 값을 홀드아웃 결과를 본 뒤 정하면 홀드아웃이 다시 개발구간이 된다.

## 결정

`config/final_holdout_model.json`을 개봉 전 단일 설정 정본으로 둔다.

| 항목 | 확정값 | 개발구간 근거 |
|---|---|---|
| KOSPI200 | 조합 C LogisticRegression | long-only 100후보 1위 |
| KOSPI200 class weight | `balanced` | 12개 외부 폴드 중 8개에서 선택 |
| KOSPI200 상승 임계값 | `0.3375` | 12개 외부 폴드 선택값의 중앙값 |
| 개별종목 | 조합 K LogisticRegression | ADR 0007 순위 1위 |
| 개별종목 class weight | `balanced` | 12개 외부 폴드 전부에서 선택 |

설정 파일의 canonical JSON SHA-256을 실행 결과에 기록한다. 공식 실행은 데이터 담당자가 만든
개봉 승인 JSON에 같은 설정 지문과 입력 파일 네 개의 SHA-256이 있을 때만 허용한다. 결과
디렉터리가 이미 있으면 덮어쓰지 않는다.

세 값은 GitHub 이슈 #240에서 확인한 뒤 승인했다. 실제 `20240901~` 데이터로 공식 실행하기
전까지는 근거를 남기고 새 ADR로 변경할 수 있다. 홀드아웃을 한 번이라도 개봉한 뒤에는 결과와
무관하게 이 값들을 바꾸지 않는다.

## 결과

- 모델 실행기는 후보 비교나 재선정을 하지 않고 C/K 두 모델만 학습한다.
- KOSPI200과 개별종목이 모두 상승으로 예측된 행에만 `buy_candidate=True`를 기록한다.
- class weight나 임계값을 바꾸려면 홀드아웃 개봉 전에 이 ADR과 설정 파일을 함께 검토한다.
- 개봉 후에는 값이 기대와 달라도 설정을 바꾸지 않고 그대로 최종 결과로 기록한다.

## 후속 연동 확인

- [x] KOSPI200 임계값을 폴드 중앙값 `0.3375`로 고정한다.
- [x] 두 트랙의 class weight를 폴드 최빈값 `balanced`로 고정한다.
- [ ] 이동원 담당 개봉 승인 JSON의 필드와 SHA-256 계약이 맞는다.
- [ ] 강민석 담당 백테스트가 `combined_predictions.parquet` 계약을 받을 수 있다.
