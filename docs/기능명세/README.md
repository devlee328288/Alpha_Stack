## 무엇을 넣지 않았나

- **API 엔드포인트 명세** — 1차는 로컬 파일로 끝내므로 엔드포인트가 없습니다
- **ERD** — [erd/](../erd/) 가 정본입니다. 여기서 되풀이하면 두 곳이 갈라집니다
- **다른 파트의 내부 구현** — 담당자가 따로 있고, 제가 상세히 쓰면 어긋납니다
