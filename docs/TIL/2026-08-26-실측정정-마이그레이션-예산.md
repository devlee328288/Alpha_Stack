## 1. 무엇을 했나

수집 공통 규칙을 세우려고 앉았는데, **착수 전에 확인한 외부 사양이 문서와 달랐습니다.**
그래서 규칙을 세우기 전에 바로잡는 일이 먼저가 됐습니다.

- `robots.txt` 재확인 → 종목토론방 수집(D-22)을 **Won't** 로 내림
- 네이버 검색 API **신규 발급 중단**(2026-07-30) 확인 — 우리 키는 이전 발급분이라 사용 가능
- DART `rcept_no[:8]` 편법을 4,800건으로 검증 → **3건이 미래를 3일 먼저** 봄 → 조인 채택
- `PRAGMA user_version` 마이그레이션 (테스트 11개)
- 호출 예산 — 80% 경고 · 100% 정상종료 · `mark_exhausted` (테스트 13개)
- 아이디어 문서 v1.0 (기능 중심 + 통계 검정 5단계)

## 2. 왜 했나

이미 900만 행이 든 1.65GB DB 에 **표를 얹을 방법이 없었습니다.** 스키마를 만드는 길이
`CREATE TABLE IF NOT EXISTS` 하나뿐이라 칸을 추가할 수가 없었고, 지우고 다시 만들면
16년치 백필을 다시 받아야 했습니다.

호출 예산은 그다음 문제였습니다. 한도를 **서버가 거절해서 아는 게 아니라 우리가 미리
세서** 알아야 백필이 중간에 통째로 막히지 않습니다.

## 3. 어떻게 했나 — 고른 것과 버린 것

**alembic 을 버렸습니다.** alembic 이 SQLite 에 주는 것은 batch(move-and-copy) 모드인데,
우리에게 필요한 `ADD COLUMN` 은 그럴 필요가 없습니다. 900만 행으로 직접 쟀습니다.

| 연산 | 시간 |
|---|---|
| `ADD COLUMN NOT NULL DEFAULT 0` | **0.16ms** |
| `ADD COLUMN` + CHECK 제약 | **5,088ms** (약 3만 배) |
| `DROP COLUMN` | **19,163ms** |

`ADD COLUMN` 이 공짜인 이유는 SQLite 가 스키마 텍스트만 고치고 행은 건드리지 않기
때문입니다. 즉 alembic 은 **우리가 쓰지 않을 비싼 경로를 위한 의존성**이었습니다.

**예산 카운터를 파일이 아니라 DB 에 뒀습니다.** 야간 배치와 화면의 즉시수집 버튼이 따로
도는데 모듈 전역 변수로 세면 각자 0 부터 시작해 한도를 두 배로 씁니다.
`(출처, KST 날짜)` 를 키로 삼아 **자정 리셋 코드 자체를 없앴습니다** — 날짜가 바뀌면
그냥 다른 행이라 0 부터 셉니다. 잊어버릴 수가 없습니다.

## 4. 어떻게 확인했나

**마이그레이션 원자성** — 통설과 반대라 테스트로 잠갔습니다. *"`user_version` 은 헤더
값이라 트랜잭션 밖"* 이라고들 하는데 **실제로는 `ROLLBACK` 과 함께 되돌아갑니다.**
두 번째 문장에서 일부러 터지는 마이그레이션을 넣고 첫 문장이 만든 표까지 사라지는지
확인했습니다.

**DART 접수번호 편법** — 정기공시 4,800건을 실제로 호출해 대조했습니다. 3건(0.062%)이
어긋났고 **그중 둘은 실제 접수일보다 3일 이른 방향** — 아직 공개 안 된 정보를 사흘 먼저
아는 셈입니다. 0.062% 라 넘어갈 수도 있었지만, 방향이 **누수 쪽**이라 버렸습니다.

## 6. 배운 것

**문서에 "조사로 확정"이라 적힌 것이 틀릴 수 있습니다.** 직전 커밋에 *"robots.txt 한 줄이
커뮤니티 수집 설계를 통째로 정했다"* 고 적었는데, 그 한 줄을 잘못 읽었습니다.
`robots.txt` 는 **그룹 단위로** 읽어야 하고 어느 `User-agent` 그룹 소속인지가 전부입니다.

**표준 라이브러리가 안전한 쪽으로 틀리지 않을 수 있습니다.** `urllib.robotparser` 는
명시적 `Disallow` 인 URL 에 `can_fetch()` 가 **True** 를 돌려줍니다(와일드카드를 `%2A` 로
퍼센트 인코딩해 버림). 차단 가드가 반대 방향으로 틀리면 없느니만 못합니다 — **안전하다는
착각을 주기 때문**입니다.

**주석이 문서 ID 를 가리키면 아무 정보도 못 줍니다.** 리뷰에서 지적을 받아 `D-02` 같은
표기를 전부 걷어내고 그게 무엇인지 직접 쓰도록 고쳤습니다. 문서와 코드가 갈라지면
ID 는 죽은 링크가 됩니다.
