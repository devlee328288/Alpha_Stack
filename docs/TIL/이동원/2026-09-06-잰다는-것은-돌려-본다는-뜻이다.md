## 오전에 "잰다" 고 한 것이 실은 "읽는다" 였다

오전 TIL 에서 PR 본문을 코드로 재서 여섯 군데가 다르다고 적었다. 그 문서에 `trade_log` 를
**23칸**이라 썼다. 코드를 읽고 정규식으로 딕셔너리 키를 세었다 — `"[a-z_]+":` 패턴이다.
`action = "hold"` 같은 줄은 안 잡힐 테니 정확할 거라 믿었다.

오후에 검증기를 만들면서 `run_backtest()` 를 **실제로 돌려** 칸을 셌다. **22칸**이었다.
정규식이 무엇을 하나 더 잡았는지는 끝내 못 찾았다 — 찾을 필요도 없었다. 돌려 본 결과가
정답이고, 읽어서 센 것은 처음부터 추정이었다. 문서 네 곳을 고쳤다.

**코드를 읽는 것은 재는 것이 아니다.** 눈으로 세는 순간 그것은 실측이 아니라 해석이다.

## 돌려 보니 세 개가 더 나왔다

읽기만 했으면 영영 몰랐을 것들이다.

**첫째, 같은 파일로 두 번 돌리면 원장이 다르다.** `trade_log` 가 1,985행이었다가 1,898행이
됐다. 예측 함수가 `np.random.seed(hash(base_date) % 2**32)` 로 시드를 잡는데, 파이썬 `hash()`
는 프로세스마다 무작위화된다. 세 번 따로 실행해 세 값이 나왔고 `PYTHONHASHSEED=0` 이면
고정됐다. `run_id` 를 붙여 추적성을 만든 PR 인데, 그 `run_id` 로 원장을 다시 만들 수가 없다.
지금은 랜덤 예측이라 숫자에 뜻이 없지만, "재현된다" 는 전제가 조용히 깨져 있었다.

**둘째, 선언된 환경에서는 모듈이 열리지 않는다.** README 가 정본이라 적은 `.venv` 로
`import backtest.backtest_strategies` 를 하면 `ModuleNotFoundError: datasets`. `pyproject.toml`
이 `datasets` 를 일부러 안 넣었기 때문이다(74행 — "parquet 은 pandas 로 읽으면 된다").
강민석 님 로컬에는 있으니 그쪽에선 안 걸린다. 그리고 이 세션의 anaconda 파이썬에서는
반대로 `datasets` 가 **있는데 깨진다** — pandas dist-info 가 둘이라 `importlib.metadata` 가
None 을 준다. 지난 세션 메모 그대로였다: *설치된 버전 ≠ import 되는 버전.*

**셋째, 이전 세션의 1,157 이 어느 파이썬에서 나온 숫자인지 몰랐다.** `.venv` 로 수집하면
1,136 + 오류 1(`FinanceDataReader` 없음). anaconda 로는 1,160. 기준선 숫자를 적어 두면서
**어느 환경인지를 안 적었다.** 오늘부터 적는다.

## 검증기는 백테스트 코드를 import 하지 않게 만들었다

원장은 강민석 님 것이고 검증기는 내 것이다. 검증기가 `backtest/` 를 import 하면 그쪽 환경
문제가 내 파트로 넘어온다. 그래서 검증기는 **DataFrame 만** 받는다. 종단 시험에서만
`datasets` 가 없거나 깨졌을 때 빈 대역을 `sys.modules` 에 끼워 `run_backtest` 를 읽는다 —
업로드 경로는 안 부르니 대역이 실제로 쓰일 일은 없다. `.venv` 와 anaconda 양쪽에서 33건이
같이 통과한다.

## 잡아야 할 것을 잡는지도 돌려 봤다

홀드아웃 엿보기는 두 갈래다. 예측일 자체가 봉인 안인 것은 누구나 잡는다. 놓치기 쉬운 것은
**예측일은 8월 26일인데 실현수익률이 9월 2일 종가로 계산된** 행이다. 날짜만 보면 깨끗하고
값이 봉인 구간을 봤다. 종가 축을 넣어 t+5 를 되짚어야 보인다. 봉인선을 넘겨 30거래일을
돌리니 예측일 위반 14행, 엿보기 15행 — 하나가 더 나온다. 그 하나가 바로 8월 26일이다.

## 배운 것

1. **세는 것도 실측이다.** 읽어서 센 숫자는 문서에 적기 전에 돌려서 다시 센다.
2. **재현되지 않는 랜덤은 랜덤이 아니라 결함이다.** `hash()` 는 시드가 아니다.
3. **기준선 숫자에는 환경을 붙인다.** "1,157 passed" 는 "anaconda 3.x · 1,157 passed" 여야 한다.
4. **남의 파트 코드에 기대지 않는 시험을 먼저 만든다.** 계약은 DataFrame 으로 받고, 종단은
   대역으로 격리한다. 그래야 그쪽 환경이 깨져도 내 시험은 그 사실을 **보고**하지 같이 죽지 않는다.
