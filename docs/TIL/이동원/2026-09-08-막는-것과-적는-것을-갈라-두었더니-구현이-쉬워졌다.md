# 막는 것과 적는 것을 갈라 두었더니 구현이 쉬워졌다

> 2026-09-08 · 이동원 · 설계 [데이터파트 v3.9](../../데이터파트/version3.9/데이터_품질_원장_설계.md) ·
> 이슈 [#168](https://github.com/devlee328288/Alpha_Stack/issues/168) · 로드맵 ⑯

## 설계에서 정한 한 줄이 구현 내내 결정을 대신했다

어제 설계에 이렇게 적었다.

> 원장은 **막지 않고 적는다** — 막는 것은 지금처럼 게이트가 한다.

구현하며 판단이 갈릴 때마다 이 한 줄이 답을 줬다.

| 갈림길 | 이 원칙이 정한 답 |
|---|---|
| 붉으면 예외를 던질까 | 아니다. 값으로 돌려준다 |
| 반출을 무를까 | 아니다. 반출본은 이미 만들어졌다 |
| 원장 생성이 실패하면 | 알리고 넘어간다. 반출본 자체는 정상이다 |
| 카드에 붉은 것을 숨길까 | 붉게 적는다. 숨기지 않는 것이 목적이다 |

`try/except` 로 감싸 놓고 *"반출본 자체는 정상이다 — MANIFEST·PROFILE 은 위에서
기록됐다"* 를 출력하게 한 것도 같은 이유다. **원장이 못 만들어졌다고 반출이 무너지면,
원장이 게이트가 되어 버린다.**

## 실측이 판정식을 뒤집었다 — 정지일은 종가로 못 잡는다

첫 판을 이렇게 썼다.

```python
거래없음 = daily["volume"].eq(0) & daily["close"].eq(0)
```

09-07 반출본으로 돌리니 **정지행이 0** 이었다. 설계에는 231,808행이라고 적어 두었는데.

세어 보니:

| | 행 수 |
|---|---:|
| 반출본 전체 | 7,888,945 |
| `close == 0` | **0** |
| `volume == 0` | **231,684** |
| `close` 최솟값 | **1** |

**KRX 는 거래정지일에도 종가 칸에 직전 가격을 그대로 실어 보낸다.** 0으로 오는 것은
시·고·저가와 거래량이지 종가가 아니다. `close == 0` 을 함께 걸면 한 건도 안 걸린다.

설계 문서에는 *"정지일(zero-OHLC)"* 이라고 적어 두었는데, 그 O·H·L 에 C 는 없었다.
**약어를 풀어 쓰지 않으면 다음 사람이 C까지 0이라고 읽는다** — 내가 그랬다.

## 09-07 손실측을 재현했다 — 그게 이 원장의 첫 시험이었다

설계 §2 에 손으로 잰 값을 적어 두고 *"구현하면 같은 값이 나와야 한다"* 고 썼다.

| 지표 | 설계에 적은 값 | 원장이 낸 값 |
|---|---|---|
| `is_adj_suspect` 총 | 1,353 | **1,353** ✅ |
| chain | 119 | 117 + 2(`chain+ca_fix`) = **119** ✅ |
| fdr | 1,234 | 1,193 + 41(`fdr+ca_fix`) = **1,234** ✅ |
| `index_price` 두 축 | 196,272 | 196,272 ✅ |
| 시장별 거래일 수 | 각 4,105 | 각 4,105 ✅ |
| `text_signal` 키 | 18,600 | 18,600 ✅ |

`ca_fix` 가 붙은 갈래까지 자동으로 나뉜 것은 덤이었다. 손으로 셀 때는 두 갈래로만
봤는데 실제로는 넷이다.

**손으로 잰 값을 문서에 적어 두는 것이 구현의 시험이 된다.** 값이 안 맞으면 둘 중
하나가 틀린 것이고, 이번에는 그게 판정식이었다.

## 시험이 사고를 재현하게 썼다

v3.8 에서 `index_price` 40,324행이 덮였다. 합계는 **오히려 늘어서** 못 잡았다.
시험을 이렇게 썼다.

```python
def test_행_수만_세면_덮어쓰기를_못_잡는다(반출폴더):
    """이 시험이 없으면 "합계로 충분하지 않나" 로 되돌아간다."""
```

인메모리 sqlite 에 같은 이름 업종지수를 두 시장에 넣고, 한쪽을 지운 상태를 만들어
두 축의 값이 갈리는지 본다. **왜 합계로 안 되는지**를 시험이 설명하게 했다.

## 신장환 님 한 줄이 카드를 바꿨다

이슈 [#168](https://github.com/devlee328288/Alpha_Stack/issues/168) 에 이렇게 남겨 주셨다.

> `is_extreme_return` 은 걸러내는 용도가 아니라 "실제 이벤트이니 남겨야 한다" 는
> 플래그인데, **이름만 보고 거꾸로 필터링할 위험이 있습니다.**

맞는 지적이라 카드에 표와 경고를 넣고, 복사해 쓸 한 줄을 박아 두었다.

```python
df = df[~df["is_adj_suspect"]]        # 걸러야 하는 것은 이것 하나뿐입니다
```

그리고 그것을 **시험으로 고정**했다 — 카드에서 이 줄이 빠지면 시험이 깨진다.

```python
assert "df[~df[\"is_adj_suspect\"]]" in 카드
```

**이름이 뜻을 배반하는 칸은 문서 한 줄로 못 막는다.** 파일에 싣고, 카드에 적고,
시험으로 잠가야 한다.
