# 이름으로 종류를 판정하면, 이름이 바뀌는 동안만 틀린다

2026-09-03 · 이동원

---

## 무엇을 했나

우선주 판별을 KRX 종목기본정보(`KIND_STKCERT_TP_NM`)로 바꿨다. 그동안은
**종목명이 '우' 로 끝나는지**로 추측하고 있었다.

```python
n.endswith("우") or "우B" in n or "우(전환)" in n or n.endswith("우C")
```

이걸 고친 건 오준영님이 #92 에서 직접 요청했기 때문이다 — 모델 파트가
"KOSPI **보통주** 시가총액 상위 50종목" 을 후보로 쓰기로 했는데, 그 '보통주' 를
우리가 이름으로 짐작하고 있었다.

## 🔴 오늘 배운 것 — 틀린 게 아니라 **가끔** 틀렸다

먼저 오늘(20260901) 유가 943종으로 정본과 이름 추측을 맞대 봤다.

```
어긋난 종목: 0건
```

**추측이 맞았다.** 여기서 멈췄다면 "고칠 필요 없네" 로 끝났을 것이다.
어제 배운 것(*표본은 통과를 증명하지 못한다*)이 있어 세 시장 × 세 날짜로 넓혔다.

```
KOSPI  20260901   943행 · 어긋남 0
KOSPI  20200102   916행 · 어긋남 1   ← 여기
KOSPI  20150102   899행 · 어긋남 1
KOSDAQ 20260901 1,822행 · 어긋남 3
KOSDAQ 20200102 1,408행 · 어긋남 1
KOSDAQ 20150102 1,065행 · 어긋남 1
```

일곱 종목이 나왔다. **이름이 '우' 로 끝나는 보통주** 들이다.

    미래에셋대우 · 연우 · 동우 · 신우 · 성우 · 에코글로우 · 이오플로우

그중 `006800` 을 시세와 맞춰 보니 이렇다.

```
20150102  대우증권      →  추측 '보통주'  ✅ 맞음
20200102  미래에셋대우   →  추측 '우선주'  ❌ 틀림   (코스피 시총 48위)
20240830  미래에셋증권   →  추측 '보통주'  ✅ 맞음
```

**같은 종목인데 이름이 바뀌는 구간에만 규칙이 깨진다.** 그리고 하필 그 구간에
시총 48위여서, 준영님이 쓰려던 상위 50 후보에서 **조용히 빠진다.**

이게 오늘 얻은 문장이다.

> 이름에서 성질을 읽는 규칙은, 이름이 바뀌는 동안만 틀린다.
> 그 구간은 짧고, 그래서 어느 하루를 집어 봐도 잘 안 걸린다.

## 그 다음 — 이번엔 반대 방향을 의심했다

정본을 쓰기로 했는데, 그 정본이 **오늘 스냅샷이면 더 나쁜 문제**가 생긴다.
2026년에 확인한 값을 2015년에 적용하는 건 미래참조다. 준영님도 #92 에서 정확히
그 걱정을 적었다("2026년에 확인한 업종을 2015년에도 같았다고 적용하면…").

그래서 물어보기 전에 재 봤다. 같은 엔드포인트를 세 날짜로 부르니:

| | 유가 | 2015에만 있는 종목 | 상장주식수가 다른 종목 |
|---|---:|---:|---:|
| 20150102 | 899 | — | — |
| 20260901 | 943 | **159종**(폐지) | **534 / 740** |

**값까지 그날 것이었다.** 2015년 값을 2015년에 직접 물어볼 수 있다는 뜻이라,
걱정하던 문제가 아예 안 생긴다. 물어보기 전에 재길 잘했다.

## 작은 것 둘

**하나.** `daily_price` 에 **KONEX 가 한 행도 없다** (KOSPI 1,251종 · KOSDAQ 2,448종뿐).
모르고 세 시장을 다 받으려 했는데 호출이 12,306 → 8,204 로 줄었다. 예산 10,000/일
안에 들어와서 **오늘 안에 시작할 수 있게 됐다.** "안 쓰는 걸 안 받는다" 가
성능이 아니라 **가능·불가능**을 갈랐다.

**둘.** `excluded()` 가 제외 사유를 안 붙이고 있었다.

```python
lambda k: k if k else "기본정보를 못 이었다"
```

pandas 가 못 이은 칸을 `None` 이 아니라 `NaN` 으로 만드는데,
**`bool(float('nan'))` 은 `True`** 다. 그래서 `else` 로 안 가고 `NaN` 이 그대로 남았다.
테스트가 잡았다 — `TypeError: argument of type 'float' is not iterable`.

빈 값 판정을 `if k else` 로 쓰면 pandas 에서는 조용히 틀린다. `pd.isna` 로 묻는다.

## 남는 생각

어제는 *"표본이 통과시킨 것을 전량이 잡았다"* 였고, 오늘은 한 발 더 갔다.

전량으로 봐도 **오늘 하루**만 보면 0건이었다. 걸린 건 **시간축으로 넓혔을 때**다.
자료에 축이 둘(종목 × 날짜)이면 표본도 두 축으로 넓혀야 한다. 한 축만 전량으로
훑고 "전수 검증했다" 고 말하면, 그건 여전히 표본이다.
