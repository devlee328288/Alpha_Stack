# 핵심코드 — 버전 목록

> 최신 버전 폴더가 정본입니다. 옛 버전은 **발전 과정의 기록**이라 지우지 않습니다.
> 규약 전문은 [docs/README.md](../README.md).

## 이 폴더는 무엇인가

**코드를 안 열어 본 팀원이 줄 단위로 따라 읽을 수 있는 해설**입니다. 신설 이유
(2026-09-02 팀 결정):

- 코드 파일의 주석·독스트링은 이미 '왜'를 설명하고 있지만, 발표·리뷰 때 필요한
  것은 **기능 하나를 처음부터 끝까지 따라가는 이야기**입니다. 그건 코드 안 주석이
  담을 수 없는 형태라 문서로 만듭니다.
- 파트를 가리지 않습니다 — 데이터·피처·모델·평가 전부. **문서화는 문서 담당(이동원)
  몫이되, 남의 파트 코드는 건드리지 않고 참고만 합니다.** 코드 자체의 정본과
  수정 권한은 각 파트 담당에게 있습니다.
- **버전업 때마다 그 버전에서 바뀐 기능의 핵심코드 문서를 함께 갱신**합니다.
  코드가 바뀌었는데 해설이 낡으면, 해설이 없는 것보다 나쁩니다.
