# 06 · 검토·발견 — 남의 결과를 다시 재 본 기록

01~05 는 **파이프라인 단계**를 따라갑니다. 이 폴더는 단계가 아니라 **성격**이 다릅니다.

> 누군가의 결과가 이상해 보일 때, **먼저 그대로 재현하고 나서** 무엇이 달랐는지 잽니다.

재현되지 않는 지적은 오해일 때가 많고, 재현된 지적은 반박하기 어렵습니다.
그래서 이 폴더의 노트북은 **항상 재현부터 시작합니다.**

## 규칙

1. **재현이 먼저입니다.** 원래 숫자를 그대로 낼 수 있어야 그다음 이야기가 성립합니다.
   설정을 못 맞추면 "못 맞췄다"고 적습니다.
2. **남의 파트 코드는 고치지 않습니다.** 재는 것과 고치는 것은 다릅니다
   (→ [AGENTS.md](../../AGENTS.md)). 고쳐야 할 것은 이슈로 알립니다.
3. **실행한 채로 커밋합니다.** 출력 없는 노트북은 재현의 증거가 되지 않습니다.
4. 결론은 `docs/` 의 해당 파트 폴더에 문서로 남기고, 노트북은 **그 문서의 부록**입니다.
