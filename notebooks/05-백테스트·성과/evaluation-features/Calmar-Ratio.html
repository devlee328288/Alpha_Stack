📉 Calmar Ratio (칼마 비율)

칼마 비율(Calmar Ratio)은 1991년 Terry W. Young이 개발한 지표로, 연평균 복리 수익률(CAGR)을 전체 기간 중 가장 큰 최대 낙폭(Maximum Drawdown, MDD)으로 나누어, "최악의 손실(MDD) 대비 연간 수익률이 얼마나 효율적인가"를 측정합니다.

스털링 비율(Sterling Ratio)이 상위 여러 개의 MDD 평균을 사용하는 반면, 칼마 비율은 단 하나의 최대 MDD만을 분모로 사용하여 더 보수적이고 극단적인 하락 위험에 민감하게 반응합니다. 따라서 레버리지 전략이나 변동성이 큰 자산의 평가에 자주 활용됩니다.

📐 Calmar Ratio 기본 수식

Calmar Ratio = ( Annualized Return (CAGR) ) / Max Drawdown (MDD)
(단, MDD는 절댓값(양수)으로 변환하여 사용)

📐 세부 계산 수식

Calmar Ratio = [ (1 + Rtotal) (1 / Y) − 1 ] / [ max t ∈ [0, T] ( (Vpeak − Vtrough) / Vpeak ) ]
※ Rtotal = 전체 누적 수익률, Y = 투자 기간(년), Vpeak = 고점 가치, Vtrough = 저점 가치

🔍 변수(Variables) 상세 설명

변수명 기호 상세 설명 및 입력값
칼마 비율 Calmar Ratio 결과값 최대 낙폭 대비 연간 수익률. 단위가 없는(무차원) 수치이며, 값이 클수록 극한의 하락장에서도 우수한 수익 방어력을 의미합니다.
연간 수익률 (CAGR) Rannual 입력값 투자 기간 동안의 연평균 복리 수익률 (Compound Annual Growth Rate).
공식: (1 + Rtotal)(1/Y) − 1
최대 낙폭 (MDD) Max Drawdown 입력값 전체 분석 기간 중 가장 큰 단일 낙폭 (고점 대비 최대 하락률).
🔹 일반적으로 음수(-)로 표시되나, 분모에는 절댓값(양수)을 사용합니다.
※ Sterling Ratio와의 핵심 차이점: 평균이 아닌 최대값 1개만 사용합니다.
누적 총 수익률 Rtotal 입력값 전체 투자 기간 동안의 최종 누적 수익률.
예: 100 → 180이면 0.8 (80%)
투자 기간(년) Y 옵션 분석 기간의 총 연수 (소수점 가능).
예: 2년 6개월 → 2.5년
고점 가치 Vpeak 입력값 MDD 발생 구간에서의 최고 자산 가치.
저점 가치 Vtrough 입력값 MDD 발생 구간에서의 최저 자산 가치.

🧮 계산 예시 (Example)

📌 예시 상황 (3년 투자 기간)

  • 초기 자산: 100 → 최종 자산: 157.6 (누적 수익률 57.6%)
  • 투자 기간: 3년
  • 발생한 MDD 목록 (하락률): -12%, -8%, -15%, -5%, -10%
  • 👉 전체 기간 중 최대 MDD = -15% (절댓값: 0.15)

👉 1) 연간 수익률 (CAGR) 계산
Rannual = (1 + 0.576)(1/3) − 1 = (1.576)0.333 − 1 ≈ 1.164 − 1 = 0.164 (16.4%)

👉 2) Calmar Ratio 계산
Calmar = 0.164 / 0.15 = 1.093

✅ 해석: 이 포트폴리오는 최대 낙폭(MDD) 1%당 연간 약 1.09%의 수익을 창출하고 있습니다.
(동일한 데이터로 계산한 Sterling Ratio는 1.33이었으며, 최대 MDD 하나만 사용한 Calmar가 더 보수적인 값을 보입니다.)

📈 Calmar Ratio 해석 가이드

  • 🔴 Calmar < 0.5 : 최대 낙폭 대비 수익률이 매우 낮음 (투자 매력 부족).
  • 🟡 0.5 ≤ Calmar < 1.0 : 보통 수준 (최대 낙폭 관리가 평범).
  • 🟢 1.0 ≤ Calmar < 2.0 : 양호한 수준 (최악의 하락장에서도 준수한 방어력).
  • ⭐ Calmar ≥ 2.0 : 매우 우수한 수준 (극한 하락장에서도 뛰어난 수익 방어).
  • 🚀 Calmar ≥ 3.0 : 최상위 수준 (전설적인 헤지펀드급의 MDD 관리 능력).

⚠️ 칼마 비율은 단일 최대 낙폭에 의존하므로, 한 번의 극단적 이벤트(예: 2008년 금융위기)가 있을 경우 다른 지표들에 비해 값이 급격히 낮아지는 특성이 있습니다.

📊 Sterling Ratio vs Calmar Ratio 비교

구분 Sterling Ratio Calmar Ratio
분모 (위험) 상위 3~5개 MDD의 평균 전체 기간 중 단일 최대 MDD
특징 이상치(Outlier)에 덜 민감 이상치(Outlier)에 매우 민감 (보수적)
적합한 전략 다양한 하락 구간이 있는 장기 전략 레버리지 / 극한 손실 방지가 중요한 전략
수치 경향 일반적으로 Calmar보다 높음 일반적으로 Sterling보다 낮음 (더 엄격)

⚠️ Calmar Ratio 한계 및 주의사항

  • 단일 사건에 과도하게 민감: 단 한 번의 큰 하락(예: 코로나 팬데믹)이 지표를 수년간 왜곡할 수 있습니다.
  • 투자 기간에 따른 왜곡: 투자 기간이 짧을수록 MDD가 상대적으로 작게 측정되어 Calmar가 과대평가될 위험이 있습니다.
  • 수익률 산출 방식의 차이: CAGR 대신 산술 평균 수익률을 사용하면 결과가 달라지므로, 반드시 CAGR(복리)을 사용해야 합니다.
  • MDD는 과거 지표: 미래의 최대 낙폭을 예측하지 못하며, 변동성이 급변하는 시장에서는 과거 MDD가 무의미해질 수 있습니다.

📚 Calmar Ratio 주요 활용 분야

  • 레버리지 ETF / 파생상품 전략: 레버리지 배율이 높을수록 MDD가 커지므로, Calmar로 위험 통제.
  • CTA / 추세 추종 전략: 급격한 추세 반전 시의 대규모 손실 가능성 평가.
  • 은퇴자금 / 연기금: 원금 손실을 절대적으로 피해야 하는 자금의 스트레스 테스트.
  • 헤지펀드 벤치마킹: 유명 헤지펀드 지표인 'Calmar Ratio'는 업계 표준으로 통용됨.
