📉 Sortino Ratio (소르티노 지수)

소르티노 지수(Sortino Ratio)는 1991년 프랭크 소르티노(Frank A. Sortino)가 제안한 지표로, 하방 변동성(Downside Deviation, σd)만을 위험으로 간주하여 위험(하락 위험) 1단위당 초과 수익률을 측정합니다.

샤프 지수는 상승 변동성(좋은 변동성)까지 위험(분모)에 포함시켜 좋은 성과를 과소평가하는 경향이 있는 반면, 소르티노 지수는 목표 수익률(MAR) 미달 시점의 변동성만 분모에 반영하여, 실질적인 하방 리스크 대비 성과를 더 정확히 평가할 수 있습니다.

📐 Sortino Ratio 기본 수식

Sortino Ratio = ( Rp − MAR ) / σd
(단, MAR = Minimum Acceptable Return, 최소 요구 수익률)

📐 하방 변동성(Downside Deviation) 세부 수식

σd = √ ( 1 / N × Σ t=1 N min ( 0 , Rt − MAR ) 2 )
※ Rt는 각 시점(t)의 수익률, min(0, ...)은 음수(하락)만 취함.

📐 연환산(Annualized) Sortino Ratio 수식

Sortinoannual = √N × ( Rp − MAR ) / σd
(여기서 N은 1년 동안의 기간 수: 일간=252, 주간=52, 월간=12)

🔍 변수(Variables) 상세 설명

변수명 기호 상세 설명 및 입력값
소르티노 지수 Sortino Ratio 결과값 하방 위험 대비 초과 수익률. 단위가 없는(무차원) 수치이며, 값이 클수록 하락장에서의 방어력과 효율이 우수함을 의미합니다.
포트폴리오 수익률 Rp 입력값 분석 기간 동안의 평균 수익률 (또는 기대 수익률).
샤프 지수와 동일하게 수익률 시계열의 산술 평균을 사용합니다.
최소 요구 수익률 MAR 입력값 투자자가 목표로 하는 최소한의 기준 수익률 (Threshold).
🔹 일반적 설정: 0% (원금 보호 기준) 또는 무위험 수익률(Rf)
🔹 고급 설정: 물가상승률, 벤치마크 수익률, 또는 개인 목표 수익률 등
※ MAR을 0%로 설정하면, 마이너스 수익만 하방 위험으로 간주합니다.
하방 편차 σd (Downside Deviation) 중간값/입력값 MAR을 하회한 수익률(음수)들만 추려서 계산한 표준편차.
즉, 하락 구간의 변동성만을 측정합니다.
※ 분모가 작을수록(하방 변동성이 낮을수록) 소르티노 지수가 높아집니다.
시점별 수익률 Rt 입력값 분석 기간 내 각 시점(일/월/주)의 수익률 데이터.
하방 편차 계산에 사용되는 원시 데이터입니다.
전체 관측치 수 N 옵션 분석에 사용된 전체 데이터 포인트 수.
연환산 시에는 1년 기준 기간 수(252, 52, 12)로 대체됩니다.

🧮 계산 예시 (Example)

📌 예시 상황 (월간 데이터, MAR = 0%)

  • 월간 평균 포트폴리오 수익률 (Rp): 1.2% (0.012)
  • 최소 요구 수익률 (MAR): 0% (0.00)
  • 월간 수익률 데이터: +3%, +1%, -2%, +4%, -5%, +2% (6개월)

👉 1) 하방 편차 (σd) 계산
음수(하락) 구간만 추출: -2%, -5%
σd = √[ ( (-0.02)² + (-0.05)² ) / 6 ] = √[ (0.0004 + 0.0025) / 6 ] = √(0.0029/6) = √0.000483 ≈ 0.0220 (2.20%)

👉 2) Sortino Ratio 계산
Sortino = (0.012 − 0.00) / 0.0220 = 0.012 / 0.0220 ≈ 0.545

✅ 해석: 이 포트폴리오는 하방 위험(하락 변동성) 1단위당 약 0.545의 초과 수익을 창출하고 있습니다.

📈 Sortino Ratio 해석 가이드

  • 🔴 Sortino < 0 : MAR보다 수익률이 낮음 (투자 매력 없음).
  • 🟡 0 ≤ Sortino < 0.5 : 보통 수준 (하방 위험 관리가 평범).
  • 🟢 0.5 ≤ Sortino < 1.0 : 양호한 수준 (하락장 방어력 우수).
  • ⭐ Sortino ≥ 1.0 : 매우 우수한 수준 (탁월한 하방 리스크 대비 성과).
  • 🚀 Sortino ≥ 2.0 : 최상위 수준 (극도로 안정적인 하방 변동성 대비 고수익).

⚠️ 샤프 지수보다 Sortino 지수가 높은 경우는 상승 변동성이 컸음을 의미하며, 이는 해당 전략이 상승장에서의 변동성(좋은 변동성)이 컸다는 뜻입니다.

⚠️ Sortino Ratio 한계 및 주의사항

  • MAR 설정에 민감: MAR을 0%로 하느냐, 무위험수익률로 하느냐에 따라 값이 크게 달라집니다.
  • 하방 변동성만 고려: 상승 변동성은 완전히 무시하므로, 상승 랠리에서의 기회 비용을 반영하지 않습니다.
  • 과거 지표일 뿐: 미래의 하방 위험을 보장하지 않습니다.
  • 정규 분포 가정 없음: 샤프 지수와 달리 정규성을 가정하지 않으므로, 비대칭적 수익률 분포에 더 적합합니다.

📚 Sortino Ratio 주요 활용 분야

  • 헤지펀드 / 대체투자 평가: 하방 리스크가 중요한 전략(예: 롱-숏, CTA)에 적합.
  • 은퇴자금 / 연금 포트폴리오: 원금 보호가 중요한 투자자에게 적합.
  • 하방 보호 전략(옵션 헷지 등): 손실 제한 전략의 효율성 평가.
  • 샤프 지수와 함께 비교 분석: 상승 변동성 vs 하방 변동성의 비율을 파악 가능.
