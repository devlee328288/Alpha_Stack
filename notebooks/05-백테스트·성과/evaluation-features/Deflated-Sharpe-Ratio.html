📉 Deflated Sharpe Ratio (디플레이티드 샤프 비율)

디플레이티드 샤프 비율(Deflated Sharpe Ratio, DSR)은 David H. Bailey와 Marcos López de Prado가 2014년에 제안한 지표로[reference:2], 수많은 백테스트 중에서 가장 높은 샤프 비율을 선택할 때 발생하는 선택 편향(Selection Bias)과 다중 검정(Multiple Testing) 문제를 교정한 통계적 검정 지표입니다[reference:3][reference:4].

일반적인 샤프 비율은 "하나의 전략만 테스트했다"는 가정하에 계산됩니다. 하지만 실제 퀀트 투자에서는 수백~수천 개의 파라미터 조합을 테스트한 후 가장 높은 샤프 비율을 보인 전략을 선택하는 것이 일반적입니다. 이때 "우연히" 가장 높은 샤프 비율이 나올 확률을 고려하지 않으면, 데이터 마이닝(Data Mining)으로 인해 과대평가된 성과를 진짜 실력(Alpha)으로 오인할 위험이 있습니다[reference:5].

DSR은 이러한 문제를 해결하기 위해 Probabilistic Sharpe Ratio (PSR)의 개념을 확장하여, 귀무가설(무능력, No Skill) 하에서 기대할 수 있는 최대 샤프 비율을 벤치마크로 삼아 관측된 최고 샤프 비율을 "디플레이트(Deflate)"합니다[reference:6][reference:7].

💡 핵심 개념: 다중 검정 문제 (Multiple Testing Problem)

하나의 전략을 테스트하여 샤프 비율 2.0이 나왔다면 이는 강력한 Alpha의 증거입니다. 하지만 1,000개의 전략을 테스트하고 그중 가장 높은 샤프 비율을 선택했다면, 샤프 비율 2.0은 순수한 랜덤 노이즈에서 기대할 수 있는 최대값에 불과할 수 있습니다[reference:8].

👉 무능력(No Skill) 가정 하에서 N개의 독립적 시행 중 기대되는 최대 샤프 비율
E[max(SR̂)] ≈ √(2 ln N) × (1 − γ / (2 ln N)) + γ / √(2 ln N)
(여기서 γ ≈ 0.5772는 오일러-마스케로니 상수, N은 시행 횟수)[reference:9]

예를 들어, N=1,000이라면 무작위 노이즈만으로도 약 3.7의 샤프 비율이 기대될 수 있습니다. 따라서 단순히 높은 샤프 비율만으로는 진짜 실력인지 우연인지 판단할 수 없습니다.

📐 Deflated Sharpe Ratio (DSR) 기본 수식

DSR = PŜR [ SR* ] = Z ( ( SR̂* − SR0 ) √ (T − 1) / √ ( 1 − γ̂3 · SR̂* + ((γ̂4 − 1) / 4) · SR̂*2 ) )
(단, Z(·)는 표준 정규 분포의 CDF, SR0는 귀무가설 하의 기대 최대 샤프 비율)[reference:10][reference:11]

📐 귀무가설 하 기대 최대 샤프 비율 (SR0)

SR0 = √ Var( { SR̂n } ) × ( (1 − γ) · Z−1[1 − 1/N] + γ · Z−1[1 − 1/(N · e)] )
※ γ ≈ 0.5772 (오일러-마스케로니 상수), e ≈ 2.71828 (오일러 상수), N = 백테스트된 전략(시행)의 수, Z−1 = 표준 정규 분포의 역 CDF[reference:12][reference:13]

🔍 변수(Variables) 상세 설명

변수명 기호 상세 설명 및 입력값
디플레이티드 샤프 비율 DSR 결과값 0 ~ 1 사이의 확률값으로, 관측된 최고 샤프 비율이 다중 검정을 고려했을 때도 진짜 실력(Alpha)일 확률을 의미합니다[reference:14].
🔹 DSR ≥ 0.95 : 95% 신뢰 수준에서 유의미한 Alpha 존재
🔹 DSR < 0.95 : 우연(데이터 마이닝)에 의한 결과일 가능성 높음
관측된 최고 샤프 비율 SR̂* 입력값 N개의 백테스트 중 가장 높은(최대) 샤프 비율.
일반적으로 연율화(Annualized)된 샤프 비율을 사용합니다[reference:15].
귀무가설 하 기대 최대 샤프 SR0 중간값 실력(Alpha)이 전혀 없는 상태에서 N번의 독립적 시행 중 기대되는 최대 샤프 비율.
🔹 N(시행 횟수)이 클수록 SR0도 커집니다.
※ DSR은 이 값을 벤치마크(분모)로 삼아 관측된 샤프를 "디플레이트"합니다[reference:16].
백테스트 시행 횟수 N 입력값 실제로 백테스트(시뮬레이션)한 전략/파라미터 조합의 총 개수.
🔹 파라미터 최적화, 여러 전략 백테스트 등 모든 시행 횟수를 포함해야 합니다[reference:17].
※ N이 클수록 DSR은 더 엄격해집니다(더 낮은 값이 나옴).
수익률 관측치 수 T 입력값 수익률 시계열의 데이터 포인트 수 (예: 일간 수익률 252개).
T−1은 자유도(Degrees of Freedom)를 의미합니다[reference:18].
※ T가 클수록(데이터가 많을수록) DSR이 높아지는 경향이 있습니다.
왜도 (Skewness) γ̂3 입력값 수익률 분포의 비대칭도.
🔹 γ̂3 > 0 : 우측으로 긴 꼬리 (큰 수익이 드물게 발생)
🔹 γ̂3 < 0 : 좌측으로 긴 꼬리 (큰 손실이 드물게 발생)[reference:19]
첨도 (Kurtosis) γ̂4 입력값 수익률 분포의 꼬리 두께 (뾰족한 정도).
🔹 정규 분포의 첨도는 3입니다.
🔹 γ̂4 > 3 : 정규 분포보다 두꺼운 꼬리 (극단값 발생 빈도 높음)[reference:20]
※ 왜도와 첨도는 비정규 수익률을 반영하기 위해 DSR에 포함됩니다[reference:21].
표준 정규 CDF Z(·) 함수 표준 정규 분포의 누적 분포 함수(Cumulative Distribution Function).
계산된 Z-점수를 확률값(0~1)으로 변환합니다[reference:22].
오일러-마스케로니 상수 γ 상수 ≈ 0.5772156649...
극한값 이론(Extreme Value Theory)에서 기대 최대값을 계산할 때 사용됩니다[reference:23].

🧮 계산 예시 (Example)

📌 예시 상황

  • 백테스트 시행 횟수 (N): 500 (500개의 파라미터 조합 테스트)
  • 관측된 최고 샤프 비율 (SR̂*): 2.5 (연율화)
  • 수익률 관측치 수 (T): 252 (일간, 1년치 데이터)
  • 왜도 (γ̂3): -0.5 (약간의 좌측 꼬리)
  • 첨도 (γ̂4): 4.2 (정규 분포보다 두꺼운 꼬리)

👉 1) 귀무가설 하 기대 최대 샤프 비율 (SR0) 계산
SR0 ≈ √(2 × ln(500)) × (1 − 0.5772/(2 × ln(500))) + 0.5772/√(2 × ln(500))
≈ √(12.44) × (1 − 0.5772/12.44) + 0.5772/3.527
≈ 3.527 × (1 − 0.0464) + 0.1637 ≈ 3.527 × 0.9536 + 0.1637 ≈ 3.526
※ 즉, 실력이 전혀 없어도 500번의 시행 중 약 3.53의 샤프 비율이 우연히 나올 수 있습니다.

👉 2) Z-점수 계산
Z = (2.5 − 3.526) × √(252 − 1) / √(1 − (−0.5)×2.5 + (4.2−1)/4 × 2.5²)
= (−1.026) × √251 / √(1 + 1.25 + 0.8 × 6.25)
= (−1.026) × 15.843 / √(1 + 1.25 + 5.0) = −16.255 / √7.25
= −16.255 / 2.692 ≈ −6.04

👉 3) DSR (확률값) 계산
DSR = Z(−6.04) ≈ 0.0000000015 (≈ 0%)

✅ 해석: 관측된 샤프 비율 2.5는 500번의 백테스트를 고려할 때 순수한 우연으로 설명될 수 있는 수준입니다. DSR이 0.95(95%)에 한참 못 미치므로, 이 전략의 성과는 데이터 마이닝의 결과일 가능성이 매우 높습니다.

📈 Deflated Sharpe Ratio 해석 가이드

  • 🔴 DSR < 0.90 : 90% 신뢰 수준에서도 유의미하지 않음 — 우연(데이터 마이닝)일 가능성 매우 높음.
  • 🟡 0.90 ≤ DSR < 0.95 : 90% 신뢰 수준에서는 유의하나, 95% 기준에는 미달.
  • 🟢 DSR ≥ 0.95 : 95% 신뢰 수준에서 유의미한 Alpha — 다중 검정을 고려해도 진짜 실력일 가능성 높음[reference:24].
  • ⭐ DSR ≥ 0.99 : 매우 강력한 증거 — 백테스트 과적합(Overfitting)의 위험이 거의 없음.

⚠️ DSR은 확률값(0~1)이므로 일반적인 샤프 비율처럼 "클수록 좋다"기보다는 임계값(보통 0.95)을 넘는지가 중요합니다.

🔗 Probabilistic Sharpe Ratio (PSR)와의 관계

Probabilistic Sharpe Ratio (PSR)는 관측된 샤프 비율이 특정 벤치마크 샤프 비율(SR*)을 초과할 확률을 계산합니다[reference:25].

PŜR[SR*] = Z[ (SR̂ − SR*) × √(T−1) / √(1 − γ̂3·SR̂ + (γ̂4−1)/4 · SR̂²) ]

Deflated Sharpe Ratio는 PSR의 특수한 경우로, 벤치마크 SR*를 귀무가설 하의 기대 최대 샤프 비율(SR0)로 설정한 것입니다[reference:26][reference:27].

즉, DSR = PSR[SR0]이며, "N번의 백테스트 중 최고 성과가 우연히 나올 수 있는 수준을 고려했을 때, 관측된 성과가 진짜일 확률"을 묻는 것입니다.

⚠️ Deflated Sharpe Ratio 한계 및 주의사항

  • N(시행 횟수)의 정의가 모호: 실제로는 독립적인 시행의 수를 알아야 하지만, 파라미터 간 상관관계가 높은 경우 유효 시행 횟수(Effective N)를 추정해야 합니다[reference:28].
  • 정규 분포 가정에 의존: PSR과 마찬가지로 근사적 정규성을 가정하지만, 극단적인 수익률 분포에서는 정확도가 떨어질 수 있습니다[reference:29].
  • 과거 데이터에만 의존: DSR은 과거 백테스트 결과를 기반으로 하므로, 미래 성과를 보장하지 않습니다.
  • 계산의 복잡성: 왜도, 첨도, 극한값 이론을 활용하므로 일반 투자자가 직접 계산하기는 어렵습니다.
  • 학계 내 논란: 일부 학자들은 DSR의 이론적 기반에 대해 근본적인 문제를 제기하기도 합니다[reference:30].

📚 Deflated Sharpe Ratio 주요 활용 분야

  • 퀀트 전략 백테스트 검증: 수백~수천 개의 파라미터 조합 중 과적합(Overfitting)된 전략을 걸러내는 최종 관문(Gate)[reference:31].
  • 헤지펀드 / 운용사 성과 평가: 데이터 마이닝으로 포장된 성과와 진짜 Alpha를 구분.
  • 머신러닝 기반 투자 전략: 하이퍼파라미터 최적화 과정에서 발생하는 선택 편향 교정.
  • 학술 연구: 백테스트 결과의 통계적 유의성을 입증하는 도구로 활용.
