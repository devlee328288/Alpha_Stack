📉 MDD (Maximum Drawdown) 지표

MDD는 최대 낙폭이라고도 불리며, 투자 자산이나 포트폴리오가 특정 기간 동안 고점(Peak) 대비 저점(Trough)까지 하락한 최대 폭을 백분율(%)로 나타낸 하방 위험(Downside Risk) 지표입니다.

MDD는 "가장 나쁜 상황에서 얼마나 잃을 수 있는가?"를 알려주므로, 투자 전략의 리스크 관리와 심리적 안정성을 평가하는 데 핵심적인 지표로 활용됩니다.

📐 MDD 수식 (두 가지 동치 표현)

① 가격(Price) 기준
MDD = max t ∈ [0, T] ( (Vpeak − Vt) / Vpeak )
= (Vtrough − Vpeak) / Vpeak

② 누적 수익률(Cumulative Return) 기준 (동치)
MDD = max t ∈ [0, T] ( (MaxCRt − CRt) / (1 + MaxCRt) )
(단, MaxCRt = 시점 t까지의 누적 수익률 최고점, CRt = 시점 t의 현재 누적 수익률)

🔍 변수(Variables) 상세 설명

변수명 기호 설명
최대 낙폭 MDD 결과값 전체 기간 동안 발생한 최대 손실률. 0 ~ 1 (또는 0% ~ 100%) 사이의 값으로 표현되며, 음수로 표시하기도 함.
※ 값이 클수록 위험이 큰 전략
시점 t 인덱스 분석 대상 기간 내의 특정 시점 (일, 월, 분기 등).
전체 기간 [0, T] 범위 MDD를 계산할 전체 분석 기간. 시작(0)부터 종료(T)까지.
고점 가치 Vpeak 입력값 특정 기간 동안의 최고 자산 가치 (Peak).
현재(저점) 가치 Vt 또는 Vtrough 입력값 고점 이후 특정 시점 또는 최저 자산 가치 (Trough).
누적 수익률 (현재) CRt 입력값 시점 t까지의 누적 수익률.
예: 기준가 100 → 150이면 CR = 0.5 (50%)
누적 수익률 최고점 MaxCRt 입력값 시점 t까지의 누적 수익률 중 가장 높은 값 (고점).
※ CR 기준 MDD 공식의 분모에 해당

🧮 계산 예시 (두 공식의 동치 확인)

📌 예시 상황 (구간별 자산가치 및 누적 수익률)

구간 자산가치 (V) 누적 수익률 (CR) 비고
시작 100 0.00 기준점
고점 (Peak) 150 +0.50 MaxCR = 0.50
하락 후 저점 (Trough) 90 -0.10 현재 시점의 CR

👉 ① 가격 기준 MDD 계산
MDD = (Vpeak − Vtrough) / Vpeak
= (150 − 90) / 150 = 60 / 150 = 0.4 ( = 40% )

👉 ② 누적 수익률(CR) 기준 MDD 계산 (동치 확인)
MDD = (MaxCR − CRt) / (1 + MaxCR)
= (0.50 − (-0.10)) / (1 + 0.50) = 0.60 / 1.50 = 0.4 ( = 40% )

✅ 두 공식의 결과가 완전히 일치합니다 (-40% = -0.4, 40% = 0.4).
즉, CR 기준 공식은 가격 기준 공식을 초기 투자금(100)으로 나누어 준 것과 동일하며, 고점 대비 현재 하락률을 정확히 측정합니다.

💡 해석: 이 포트폴리오는 분석 기간 동안 최대 40%의 손실을 경험한 적이 있습니다.

📌 누적 수익률(CR) 기준 MDD가 헷갈리지 않는 이유

  • CR은 "원금 대비 증가율"을 나타냅니다.
    예: CR = +0.50 → 원금(1) 대비 1.5배가 된 상태 (고점).
    CR = -0.10 → 원금 대비 0.9배가 된 상태 (저점).
  • 분모 (1 + MaxCR)는 고점 시점의 절대 가치(배율)을 의미합니다.
    즉, 고점을 1(100%)로 재조정(리베이싱)하여 현재 가치가 고점 대비 얼마나 떨어졌는지를 계산합니다.
  • 위 예시에서 고점(1.5배)과 저점(0.9배)의 차이(0.6)를 고점 배율(1.5)로 나누면 0.4 (40% 하락)이 나옵니다.
  • 따라서 CR 기준 공식은 절대 가격을 몰라도 누적 수익률만으로도 MDD를 정확히 계산할 수 있는 동치 표현입니다.

⚠️ MDD 해석 시 주의사항

  • MDD는 과거 데이터 기반이며, 미래 손실을 보장하지 않습니다.
  • 회복에 필요한 수익률: -50% 손실을 만회하려면 +100%의 수익이 필요합니다.
  • MDD가 낮을수록 안정적인 전략으로 평가되지만, 수익률과의 균형을 고려해야 합니다.
  • MDD는 샤프지수(Sharpe Ratio), 칼마비율(Calmar Ratio) 등 다른 지표와 함께 종합적으로 활용됩니다.

📚 MDD가 활용되는 분야

  • 퀀트 투자 / 백테스트: 전략의 위험-수익 프로파일 평가
  • 헤지펀드 성과평가: 하방 리스크 측정
  • 자산 배분 / 리밸런싱: MDD가 큰 자산군 비중 조정
  • 투자자 심리 분석: 공포 심리와 손실 인내도 측정
