📊 Sterling Ratio (스털링 비율)

스털링 비율(Sterling Ratio)은 포트폴리오의 연간 수익률을 평균 최대 낙폭(Average Maximum Drawdown)으로 나눈 위험-수익 조정 지표입니다.

MDD(Maximum Drawdown)는 자산 가치가 고점 대비 최대로 하락한 폭을 의미하며, 스털링 비율은 "MDD 1%당 얼마의 연 수익을 내는가?"를 측정합니다. 값이 클수록 적은 낙폭으로 높은 수익을 내는 효율적인 전략으로 평가됩니다.

📐 Sterling Ratio 기본 수식

Sterling Ratio = ( Annualized Return ) / Avg. Maximum Drawdown
(단, 분모는 일반적으로 가장 큰 3~5개 MDD의 평균 또는 전체 기간 평균 MDD를 사용)

📐 세부 변형 수식 (일반적 관행)

Sterling Ratio = ( Rannual ) / ( MDD1 + MDD2 + MDD3 ) / 3
※ 최근 3개 MDD의 평균을 사용하는 것이 가장 보편적인 방법입니다. 1개를 사용하면 칼마 비율이 됩니다.

📐 연환산 수익률(Annualized Return) 계산

Rannual = ( 1 + Rtotal ) (1 / Y) − 1
(여기서 Rtotal = 전체 기간 누적 수익률, Y = 투자 기간(년 수))

🔍 변수(Variables) 상세 설명

변수명 기호 상세 설명 및 입력값
스털링 비율 Sterling Ratio 결과값 MDD 대비 연간 수익률. 단위가 없는(무차원) 수치이며, 값이 클수록 낙폭 대비 수익 효율이 우수함을 의미합니다.
연간 수익률 Rannual 입력값 투자 기간 동안의 연평균 복리 수익률(CAGR).
누적 수익률과 투자 기간(년)으로 계산합니다.
평균 최대 낙폭 Avg. MDD 입력값 분석 기간 동안 발생한 최대 낙폭(MDD)들의 평균.
🔹 보편적 방법: 가장 큰 3개 MDD의 평균 (이상치 제거 효과)
🔹 간단한 방법: 단일 최대 MDD (보수적 평가)
🔹 대안: 전체 MDD의 평균 (모든 하락 구간 반영)
개별 MDD MDDi 중간값 각 하락 구간별 고점(Peak) 대비 저점(Trough)까지의 하락률.
MDDi = (Vtrough − Vpeak) / Vpeak
※ 일반적으로 음수(-)로 표시되나, 분모에는 절댓값(양수)을 사용합니다.
누적 총 수익률 Rtotal 입력값 전체 투자 기간 동안의 최종 누적 수익률.
예: 100 → 150이면 0.5 (50%)
투자 기간(년) Y 옵션 분석 기간의 총 연수 (소수점 가능).
예: 3년 6개월 → 3.5년

🧮 계산 예시 (Example)

📌 예시 상황 (3년 투자 기간)

  • 초기 자산: 100 → 최종 자산: 157.6 (누적 수익률 57.6%)
  • 투자 기간: 3년
  • 발생한 MDD 목록 (하락률): -12%, -8%, -15%, -5%, -10%

👉 1) 연간 수익률 (CAGR) 계산
Rannual = (1 + 0.576)(1/3) − 1 = (1.576)0.333 − 1 ≈ 1.164 − 1 = 0.164 (16.4%)

👉 2) 평균 MDD 계산 (상위 3개 사용)
상위 3개 MDD: -15%, -12%, -10% (절댓값: 0.15, 0.12, 0.10)
Avg. MDD = (0.15 + 0.12 + 0.10) / 3 = 0.37 / 3 = 0.1233 (12.33%)

👉 3) Sterling Ratio 계산
Sterling = 0.164 / 0.1233 ≈ 1.33

✅ 해석: 이 포트폴리오는 평균 MDD 1%당 연간 약 1.33%의 수익을 창출하고 있습니다.

📈 Sterling Ratio 해석 가이드

  • 🔴 Sterling < 0.5 : 낙폭 대비 수익률이 낮음 (투자 매력 부족).
  • 🟡 0.5 ≤ Sterling < 1.0 : 보통 수준 (MDD 관리가 평범).
  • 🟢 1.0 ≤ Sterling < 2.0 : 양호한 수준 (낙폭 대비 좋은 수익).
  • ⭐ Sterling ≥ 2.0 : 매우 우수한 수준 (탁월한 MDD 대비 효율).
  • 🚀 Sterling ≥ 3.0 : 최상위 수준 (극도로 안정적인 하락 관리).

⚠️ 칼마 비율(Calmar Ratio)과 유사하지만, 칼마는 단일 최대 MDD를 사용하고, 스털링은 평균 MDD(보통 상위 3개)를 사용하여 이상치에 덜 민감합니다.

⚠️ Sterling Ratio 한계 및 주의사항

  • MDD 정의에 따라 값이 크게 달라짐: 상위 3개 vs 전체 평균 vs 단일 최대값 중 어떤 것을 쓰느냐에 따라 결과가 완전히 달라집니다.
  • 수익률 산출 방식: 산술 평균 수익률을 쓰는 경우 CAGR과 차이가 발생할 수 있습니다.
  • MDD는 과거 기준: 미래의 최대 낙폭을 예측하지 못합니다.
  • 단기 투자에는 부적합: 1년 미만의 단기 성과 평가에는 MDD의 통계적 유의성이 떨어집니다.

📚 Sterling Ratio 주요 활용 분야

  • CTA / 매크로 헤지펀드 평가: 추세 추종 전략의 하락 방어력 측정.
  • 장기 투자 전략 백테스트: MDD가 중요한 전략(예: 레버리지 전략)의 안전성 평가.
  • 연금 / 기관 포트폴리오: 큰 낙폭을 감당할 수 없는 자금의 성과 측정.
  • 칼마 비율(Calmar)과 함께 비교: 단일 MDD vs 평균 MDD의 차이를 통해 이상치 영향을 파악.
