📐 RMSE (Root Mean Square Error) - 평균 제곱근 오차

RMSE (평균 제곱근 오차)는 예측 모델의 오차를 평가하는 가장 보편적인 지표 중 하나로, 예측값(\( \hat{y}_i \))과 실제 관측값(\( y_i \)) 간의 오차를 제곱하여 평균낸 뒤 제곱근을 취한 값입니다. 쉽게 말해, "큰 오차에 특히 엄격한 페널티를 부여한 평균 오차"라고 생각하면 됩니다.

RMSE는 오차를 제곱하기 때문에 이상치(Outlier)에 매우 민감하여, 예측이 완전히 빗나가는 극단적 상황을 놓치지 않도록 도와줍니다. 따라서 실제 금융/퀀트 실무에서는 MAE(평균 절대 오차)와 함께 쌍으로 사용하여, 평균적 정확도(MAE)와 극단적 실패 리스크(RMSE)를 동시에 평가합니다.

📐 RMSE 기본 수식

RMSE = √ ( 1 / N · Σi=1N ( yi − ŷi )² )
(단, yi = 실제값, ŷi = 예측값, N = 샘플 개수)

📐 세부 계산 수식 (풀어쓰기)

RMSE = √( ( (실제₁ − 예측₁)² + (실제₂ − 예측₂)² + ... + (실제N − 예측N)² ) / N )
※ 모든 개별 오차를 제곱하여 평균낸 뒤, 다시 제곱근을 취하여 원래 단위로 복원합니다.

🔍 변수(Variables) 상세 설명

변수명 기호 상세 설명 및 입력값
평균 제곱근 오차 RMSE 결과값 예측 모델의 오차 크기를 제곱근 단위로 환산한 값. 실제값과 동일한 단위(수익률 %, 가격 등)를 가지며, 값이 작을수록 예측 정확도가 높음을 의미합니다. 항상 MAE보다 크거나 같습니다 (RMSE ≥ MAE).
실제 관측값 yi 입력값 i번째 샘플의 실제 관측값 (예: 다음 달 실제 수익률).
예측값 ŷi 입력값 모델이 산출한 i번째 샘플의 예측값 (예: 팩터 점수 기반 예측 수익률).
샘플 개수 N 옵션 평가에 사용된 전체 데이터 포인트(종목/관측치)의 개수. 표본이 충분히 커야 통계적 신뢰도가 확보됩니다.
제곱 오차 ( yi − ŷi )² 중간값 각 샘플별 오차를 제곱한 값. 오차가 클수록 제곱에 의해 기하급수적으로 커지는 것이 RMSE의 핵심 특징입니다.

🧮 계산 예시 (Example)

📌 예시 상황 (5개 종목의 다음 달 수익률 예측) - MAE와 동일한 데이터

  • 종목 A: 실제 +10% / 예측 +8% → 오차 +2%p → 제곱 = 4
  • 종목 B: 실제 -5% / 예측 -4% → 오차 -1%p → 제곱 = 1
  • 종목 C: 실제 +3% / 예측 +4% → 오차 -1%p → 제곱 = 1
  • 종목 D: 실제 +15% / 예측 +12% → 오차 +3%p → 제곱 = 9
  • 종목 E: 실제 -2% / 예측 -1% → 오차 -1%p → 제곱 = 1

👉 RMSE 계산
제곱 오차 합계 = 4 + 1 + 1 + 9 + 1 = 16
평균 제곱 오차 (MSE) = 16 / 5 = 3.2
RMSE = √(3.2) ≈ 1.79 (%p)

✅ 해석: 이 모델의 RMSE는 약 1.79%p입니다.
📌 MAE(1.6%p)와 비교하면 RMSE가 약간 더 큽니다. 이는 오차가 큰 종목 D(3%p)가 제곱(9)되면서 전체 평균에 더 큰 영향을 미쳤기 때문입니다. 두 값의 차이(0.19%p)가 크지 않으므로, 극단적인 이상치는 없는 것으로 판단할 수 있습니다.

📈 RMSE 해석 가이드

  • RMSE의 절대적 크기: RMSE는 예측 대상과 동일한 단위를 가지므로, 해당 자산의 변동성 대비 평가해야 합니다.
  • 🔴 RMSE > 자산 연간 변동성의 50% : 극단적 오차가 너무 커서 실전 활용이 위험.
  • 🟡 RMSE ≈ 자산 연간 변동성의 20~50% : 보통 수준. 큰 오차가 가끔 발생함.
  • 🟢 RMSE < 자산 연간 변동성의 20% : 우수한 정확도. 큰 오차가 드물게 발생.
  • ⭐ RMSE < 자산 연간 변동성의 10% : 매우 뛰어난 정확도. 극단적 실패 리스크가 거의 없음.

💡 RMSE와 MAE의 관계: 두 값의 차이가 클수록 극단적 이상치(Outlier)가 존재함을 의미합니다. (RMSE = MAE이면 모든 오차가 동일, RMSE >> MAE이면 몇 개의 큰 오차가 전체를 지배함)

📊 RMSE vs MAE (평균 절대 오차) 비교

구분 RMSE (평균 제곱근 오차) MAE (평균 절대 오차)
오차 처리 제곱 → 평균 → 제곱근 절댓값 → 평균
이상치 영향 이상치에 매우 민감 (제곱으로 증폭) 이상치에 강건(Robust)하여 영향이 적음
크기 관계 항상 MAE ≥ RMSE (큰 오차에 페널티) 항상 RMSE보다 작거나 같음
실무 선호도 극단적 실패 리스크 평가 시 필수 사용 일반적인 예측 정확도 평가 시 기본 사용

⚠️ RMSE (평균 제곱근 오차) 한계 및 주의사항

  • 이상치에 과도하게 민감: 단 하나의 극단적 오차(예: 예측이 완전히 빗나간 경우)가 RMSE를 크게 왜곡할 수 있습니다. MAE와 함께 사용하여 이상치의 영향을 교차 검증해야 합니다.
  • 해석의 직관성 부족: 제곱과 제곱근 과정을 거치므로, MAE에 비해 오차의 실제 크기를 직관적으로 느끼기 어려울 수 있습니다.
  • 스케일(Scale) 의존성: MAE와 마찬가지로 자산의 가격 단위나 수익률 규모에 따라 값이 달라집니다. 다른 자산군 간 RMSE를 직접 비교할 수 없으므로, 변동성 대비 비율(예: RMSE/Volatility)로 평가해야 합니다.
  • 방향성(부호) 정보 손실: 제곱하는 과정에서 과대예측인지 과소예측인지에 대한 정보가 사라집니다. 바이어스(Bias)를 확인하려면 ME (Mean Error, 평균 오차)를 별도로 계산해야 합니다.

📚 RMSE (평균 제곱근 오차) 주요 활용 분야

  • 변동성 예측 모델 평가 (GARCH, RV 등): 예측 변동성과 실제 변동성 간의 오차를 RMSE로 측정.
  • 옵션 가격 모델 검증 (Black-Scholes, Heston 등): 이론가와 시장가 간의 괴리를 RMSE로 정량화.
  • 머신러닝/딥러닝 회귀 모델 (XGBoost, LSTM 등): 예측 오차의 표준편차 개념으로 모델 성능 평가.
  • 백테스트 전략 오차 분석: 전략이 시장 수익률을 얼마나 정확히 추종하는지 RMSE로 측정 (추적 오차).
