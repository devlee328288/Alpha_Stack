📈 ICIR (Information Coefficient Information Ratio) - 정보 계수 정보 비율

ICIR (정보 계수 정보 비율)은 정보 계수(IC) 시계열의 평균을 표준편차로 나눈 값으로, "팩터의 예측력(IC)이 시간이 지나도 얼마나 일관되게 유지되는가"를 측정합니다. 쉽게 말해, IC의 샤프지수(Sharpe Ratio)라고 생각하면 됩니다.

단순히 평균 IC가 높더라도, 그 값이 매월 극심하게 출렁인다면 전략을 신뢰하기 어렵습니다. ICIR은 이러한 예측력의 변동성(노이즈) 대비 수익률(시그널)의 효율성을 평가하여, 실전 운용에서 가장 신뢰할 수 있는 팩터를 선별하는 핵심 지표로 사용됩니다.

📐 ICIR 기본 수식

ICIR = ( Mean ( IC ) ) / Std ( IC )
(단, Std(IC)는 IC 시계열의 표준편차)

📐 세부 계산 수식

ICIR = (1 / T) · Σt=1T ICt / √( (1 / T) · Σt=1T ( ICt − 평균(IC) )² )
※ ICt = t 시점의 정보 계수, T = 전체 측정 기간(개월/분기 수)

🔍 변수(Variables) 상세 설명

변수명 기호 상세 설명 및 입력값
정보 계수 정보 비율 ICIR 결과값 팩터 예측력의 일관성(안정성)을 나타내는 무차원 수치. 값이 높을수록 예측력이 일정하게 유지됨을 의미합니다.
평균 IC Mean(IC) 또는 μIC 입력값 전체 측정 기간 동안의 IC(정보 계수) 산술 평균. 예측력의 방향과 크기를 나타냅니다.
IC 표준편차 Std(IC) 또는 σIC 입력값 IC 값들이 평균 주변에서 흩어진 정도(변동성). 값이 작을수록 예측력이 안정적(일관성 있음)을 뜻합니다.
정보 계수 시계열 ICt 입력값 각 시점(월/분기)별로 계산된 정보 계수(IC)의 시계열 데이터. (예: 2023년 1월~12월까지의 월간 IC 12개)
측정 기간(개수) T 옵션 IC를 측정한 전체 기간(샘플 수). 보통 24~36개월(2~3년) 이상의 장기 데이터를 사용합니다.

🧮 계산 예시 (Example)

📌 예시 상황 (두 개의 팩터, 12개월 월간 IC 데이터)

  • 팩터 A (평균은 높지만 변동성 큼): IC 시계열 = [0.15, -0.10, 0.20, -0.05, 0.18, -0.08, 0.22, -0.12, 0.16, -0.06, 0.19, -0.09]
  • 팩터 B (평균은 낮지만 변동성 작음): IC 시계열 = [0.06, 0.05, 0.07, 0.04, 0.06, 0.05, 0.07, 0.06, 0.05, 0.04, 0.06, 0.07]

👉 1) 팩터 A 계산
평균 IC (μ) = (합계) / 12 = 0.05
표준편차 (σ) ≈ 0.134
ICIRA = 0.05 / 0.134 ≈ 0.37

👉 2) 팩터 B 계산
평균 IC (μ) = (합계) / 12 = 0.057
표준편차 (σ) ≈ 0.010
ICIRB = 0.057 / 0.010 ≈ 5.7

✅ 해석: 팩터 A는 평균 IC가 0.05로 비슷하지만 변동성이 너무 커서 예측을 신뢰하기 어렵습니다. 반면, 팩터 B는 평균 IC는 미미하게 높지만 변동성이 극도로 낮아 매월 일관된 예측력을 보여주므로 실전 운용에 훨씬 적합합니다.

📈 ICIR 해석 가이드

  • 🔴 ICIR < 0.0 : 평균 IC 자체가 음수 → 전략 폐기.
  • 🟡 0.0 ≤ ICIR < 0.3 : 예측력이 매우 불안정하여 실전 활용이 어려움.
  • 🟢 0.3 ≤ ICIR < 0.5 : 보통 수준의 일관성. 추가 개선 여지가 있음.
  • ⭐ 0.5 ≤ ICIR < 1.0 : 우수한 일관성. 실전에서 충분히 신뢰할 수 있는 수준.
  • 🚀 ICIR ≥ 1.0 : 매우 뛰어난 일관성. 업계 최상위 팩터 수준.

⚠️ ICIR은 과거 데이터 기반이므로 미래를 보장하지 않습니다. 또한, IC 자체가 매우 낮은데 표준편차가 극도로 작아 ICIR이 높게 나오는 경우(예: IC=0.01, σ=0.001 → ICIR=10)가 있을 수 있으므로, 평균 IC의 절대적 크기와 함께 해석해야 합니다.

⚠️ ICIR 한계 및 주의사항

  • 평균 IC의 절대값을 무시한 오판: ICIR이 높더라도 평균 IC가 0.01에 불과하면 의미가 없습니다. 반드시 평균 IC와 ICIR을 함께 봐야 합니다.
  • 비정상성 (Non-stationarity): 시장 환경이 변하면 IC의 평균과 표준편차 자체가 달라집니다. 롤링 윈도우(Rolling ICIR)로 추세를 지속 추적해야 합니다.
  • 표본 수(T)의 중요성: ICIR은 T(샘플 수)에 따라 민감합니다. 12개월 미만의 단기 데이터로 계산한 ICIR은 통계적 유의성이 떨어집니다.
  • 과적합(Overfitting)의 덫: 백테스트에서 ICIR이 높게 나오도록 파라미터를 튜닝하면 오히려 실전 성과가 나빠지는 현상이 발생할 수 있습니다.

📚 ICIR 주요 활용 분야

  • 팩터 포트폴리오 구축: ICIR이 높은 팩터에 더 높은 가중치를 부여하여 전략의 안정성을 확보.
  • 멀티팩터 모델 최적화: 변동성이 큰 팩터를 걸러내고, 꾸준한 팩터만 선별.
  • 퀀트 매니저 성과 평가: 매니저의 예측력이 일정한지, 아니면 운에 의존하는지 평가.
  • 알고리즘 트레이딩 전략 검증: 백테스트에서 높은 CAGR보다 높은 ICIR을 목표로 전략을 개선.
