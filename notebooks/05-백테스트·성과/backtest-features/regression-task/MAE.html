📏 MAE (Mean Absolute Error) - 평균 절대 오차

MAE (평균 절대 오차)는 예측 모델의 성능을 평가하는 가장 직관적인 지표로, 예측값(\( \hat{y}_i \))과 실제 관측값(\( y_i \)) 간의 절대 오차를 평균한 값입니다. 쉽게 말해, "내 모델이 평균적으로 실제값과 얼마나 떨어져 있는지"를 원래 단위(수익률 %, 달러 등) 그대로 보여줍니다.

MAE는 이상치(Outlier)에 강건(Robust)하여, 극단적인 오차 몇 개에 전체 성능이 크게 왜곡되지 않는 장점이 있습니다. 따라서 실제 운용에서는 RMSE와 함께 사용하여 모델의 평균적 정확도와 극단적 오차 발생 가능성을 동시에 평가합니다.

📐 MAE 기본 수식

MAE = ( 1 / N ) · Σi=1N | yi − ŷi |
(단, yi = 실제값, ŷi = 예측값, N = 샘플 개수)

📐 세부 계산 수식 (풀어쓰기)

MAE = ( |실제₁ − 예측₁| + |실제₂ − 예측₂| + ... + |실제N − 예측N| ) / N
※ 모든 개별 오차의 절댓값을 취한 뒤 산술 평균합니다.

🔍 변수(Variables) 상세 설명

변수명 기호 상세 설명 및 입력값
평균 절대 오차 MAE 결과값 예측 모델의 평균적인 오차 크기. 실제값과 동일한 단위(수익률 %, 가격 등)를 가지며, 값이 작을수록 예측 정확도가 높음을 의미합니다.
실제 관측값 yi 입력값 i번째 샘플의 실제 관측값 (예: 다음 달 실제 수익률).
예측값 ŷi 입력값 모델이 산출한 i번째 샘플의 예측값 (예: 팩터 점수 기반 예측 수익률).
샘플 개수 N 옵션 평가에 사용된 전체 데이터 포인트(종목/관측치)의 개수. 표본이 충분히 커야 통계적 신뢰도가 확보됩니다.
절대 오차 | yi − ŷi | 중간값 각 샘플별 오차의 절댓값. 부호(+/-)를 제거하여 크기만 측정합니다.

🧮 계산 예시 (Example)

📌 예시 상황 (5개 종목의 다음 달 수익률 예측)

  • 종목 A: 실제 +10% / 예측 +8% → 오차 |10-8| = 2%p
  • 종목 B: 실제 -5% / 예측 -4% → 오차 |-5-(-4)| = 1%p
  • 종목 C: 실제 +3% / 예측 +4% → 오차 |3-4| = 1%p
  • 종목 D: 실제 +15% / 예측 +12% → 오차 |15-12| = 3%p
  • 종목 E: 실제 -2% / 예측 -1% → 오차 |-2-(-1)| = 1%p

👉 MAE 계산
절대 오차 합계 = 2 + 1 + 1 + 3 + 1 = 8
샘플 수(N) = 5
MAE = 8 / 5 = 1.6 (%p)

✅ 해석: 이 모델은 실제 수익률 대비 평균적으로 ±1.6%p 수준의 오차를 가지고 있습니다. (동일한 데이터로 계산한 RMSE는 1.87%p로, 큰 오차(3%p)의 영향으로 MAE보다 약간 높게 측정됩니다.)

📈 MAE 해석 가이드

  • MAE의 절대적 크기: MAE는 예측 대상과 동일한 단위를 가지므로, 해당 자산의 변동성 대비 평가해야 합니다.
  • 🔴 MAE > 자산 연간 변동성의 50% : 예측 오차가 너무 커서 실전 활용이 어려움.
  • 🟡 MAE ≈ 자산 연간 변동성의 20~50% : 보통 수준. 추가 개선 여지가 있음.
  • 🟢 MAE < 자산 연간 변동성의 20% : 우수한 예측 정확도. 실전에서 충분히 활용 가능.
  • ⭐ MAE < 자산 연간 변동성의 10% : 매우 뛰어난 정확도 (업계 최고 수준).

⚠️ MAE는 이상치에 강건하지만, 극단적인 오차를 간과할 위험이 있습니다. 반드시 RMSE 또는 최대 오차(Max Error)와 함께 확인하여 전체적인 예측 실패 리스크를 평가해야 합니다.

📊 MAE vs RMSE (평균 제곱근 오차) 비교

구분 MAE (평균 절대 오차) RMSE (평균 제곱근 오차)
오차 처리 절댓값을 취하여 평균 제곱한 뒤 평균 내고 루트
이상치 영향 이상치에 강건(Robust)하여 영향이 적음 이상치에 매우 민감 (제곱으로 증폭)
해석 난이도 단위가 동일하여 직관적이고 해석이 용이 단위는 같으나, 제곱의 영향으로 MAE보다 항상 크거나 같음
실무 선호도 일반적인 예측 정확도 평가 시 기본적으로 사용 큰 오차에 페널티를 주고 싶을 때 추가로 사용

⚠️ MAE (평균 절대 오차) 한계 및 주의사항

  • 이상치에 둔감한 단점: 예측이 완전히 틀린 극단적 사례(예: 실제 +30%, 예측 -20%)가 있어도 MAE는 그 영향을 상대적으로 작게 반영합니다. 반드시 RMSE와 함께 확인해야 합니다.
  • 스케일(Scale) 의존성: MAE는 자산의 가격 단위나 수익률 규모에 따라 값이 달라집니다. 다른 자산군 간 MAE를 직접 비교할 수 없으므로, 변동성 대비 비율(예: MAE/Volatility)로 평가해야 합니다.
  • 방향성(부호) 정보 손실: 절댓값을 취하는 과정에서 과대예측인지 과소예측인지에 대한 정보가 사라집니다. 바이어스(Bias)를 확인하려면 ME (Mean Error, 평균 오차)를 별도로 계산해야 합니다.
  • 샘플 수(N)의 영향: N이 너무 작으면 MAE가 우연에 의해 왜곡될 수 있습니다. 최소 30개 이상의 독립적인 샘플로 평가하는 것이 바람직합니다.

📚 MAE (평균 절대 오차) 주요 활용 분야

  • 팩터 수익률 예측 모델 평가: 예측된 팩터 수익률이 실제 수익률과 얼마나 차이나는지 측정.
  • 시계열 예측 (주가, 거래량 등): ARIMA, LSTM 등 시계열 모델의 예측 정확도 평가.
  • 머신러닝 회귀 모델 검증: XGBoost, LightGBM 등의 회귀 성능을 RMSE와 함께 보고.
  • 옵션 가격 모델 (Black-Scholes 등): 이론가와 시장가 간의 괴리율(오차)을 정량화.
