📊 혼동 행렬 (Confusion Matrix) - TP, TN, FP, FN

혼동 행렬(Confusion Matrix)은 분류 모델(Classification Model)의 성능을 평가하는 가장 기본적이고 직관적인 도구로, 실제값(Actual)과 예측값(Predicted)을 2x2 행렬로 교차하여 4가지 경우(TP, TN, FP, FN)로 나눈 표입니다.

이 4가지 요소는 모든 분류 평가 지표(Accuracy, Precision, Recall, F1-Score, MCC, Balanced Accuracy 등)의 기초가 되는 원자재(Atom) 데이터입니다. 특히 금융/퀀트 분야에서는 False Positive(거짓 양성, 허위 매수 신호)와 False Negative(거짓 음성, 놓친 매수 기회) 중 어느 것이 전략에 더 치명적인지 판단하는 출발점이 됩니다.

📐 4가지 요소 (TP, TN, FP, FN) 상세 정의

TP (True Positive) = 실제 양성이고, 예측도 양성 (정답)
TN (True Negative) = 실제 음성이고, 예측도 음성 (정답)
FP (False Positive) = 실제 음성인데, 예측을 양성으로 함 (1종 오류 / 거짓 경보)
FN (False Negative) = 실제 양성인데, 예측을 음성으로 함 (2종 오류 / 놓친 기회)
※ 1종 오류 (FP): "실제는 아닌데 있다고 함" (허위 매수 신호)
※ 2종 오류 (FN): "실제는 있는데 없다고 함" (놓친 매수 기회 / 손실 회피 실패)

🔍 변수(Variables) 상세 설명

변수명 기호 상세 설명 및 금융적 의미
진짜 양성 TP 정답 모델이 상승(또는 이상거래)을 정확히 예측하여 실제로 수익을 낸 경우.
👉 매니저의 핵심 실력
진짜 음성 TN 정답 모델이 하락(또는 정상거래)을 정확히 예측하여 손실을 피한 경우.
👉 방어 능력의 핵심
거짓 양성 (1종 오류) FP 위험 (허위 경보) 실제는 하락장인데, 모델이 상승(매수) 신호를 잘못 내어 손실을 본 경우.
👉 전략의 과매수/거짓 경보 비용
거짓 음성 (2종 오류) FN 위험 (기회 상실) 실제는 상승장인데, 모델이 하락(매도/관망)으로 잘못 예측하여 수익을 놓친 경우.
👉 전략의 놓친 기회 비용 (Opportunity Cost)

🧮 계산 예시 (주식 방향성 예측)

📌 예시 상황 (100개의 거래 신호, 실제 상승장 60개 / 하락장 40개)

  • 모델 예측 결과:
    • TP (상승을 상승으로 맞춤): 50개
    • TN (하락을 하락으로 맞춤): 30개
    • FP (하락을 상승으로 예측 → 손실): 10개
    • FN (상승을 하락으로 예측 → 기회 상실): 10개

👉 해당 혼동 행렬을 기반으로 파생되는 주요 지표
Accuracy = (50+30) / 100 = 0.80 (80%)
Precision = 50 / (50+10) = 0.833 (83.3%) (매수 신호의 정확도)
Recall (TPR) = 50 / (50+10) = 0.833 (83.3%) (실제 상승을 놓치지 않은 비율)
Specificity (TNR) = 30 / (30+10) = 0.75 (75%) (실제 하락을 잘 피한 비율)
Balanced Accuracy = (0.833 + 0.75) / 2 = 0.7915 (약 79.2%)

✅ 해석: FP(10개)는 잘못된 매수로 인한 실제 손실을 의미하고, FN(10개)는 놓친 상승장으로 인한 기회 비용을 의미합니다. 전략의 성격에 따라 FP를 줄일지(보수적), FN을 줄일지(공격적)를 이 혼동 행렬을 보고 결정합니다.

📈 혼동 행렬 해석 가이드 (금융 관점)

  • 🔵 TP (진짜 양성)가 높을수록: 수익 기회를 잘 포착하는 우수한 전략입니다.
  • 🟢 TN (진짜 음성)가 높을수록: 하락장을 잘 방어하는 안정적인 전략입니다.
  • 🔴 FP (거짓 양성)이 높을수록: 잦은 허위 매수 신호로 인해 거래 비용과 손실이 누적됩니다. (과민한 전략)
  • 🟠 FN (거짓 음성)이 높을수록: 큰 상승장을 놓치는 비용이 발생합니다. (지나치게 보수적인 전략)

💡 트레이드 오프(Trade-off): FP를 줄이려고 임계값을 높이면 FN이 증가하고, FN을 줄이려고 임계값을 낮추면 FP가 증가합니다. 자신의 투자 철학(손실 회피 vs 수익 추구)에 따라 어느 오류를 더 용인할지를 혼동 행렬로 정량화해야 합니다.

📊 1종 오류 (FP) vs 2종 오류 (FN) 비교

구분 1종 오류 (FP / False Positive) 2종 오류 (FN / False Negative)
별칭 거짓 경보 (False Alarm) 놓친 발견 (Miss)
금융 예시 하락장인데 "매수" 신호를 냄 → 실제 손실 발생 상승장인데 "매도/관망" 신호를 냄 → 수익 기회 상실
비용 성격 명시적 비용 (실현 손실, 거래 수수료) 암묵적 비용 (기회 비용, 상대 수익률 하락)
대응 전략 임계값(Threshold)을 높여 보수적으로 운영 임계값(Threshold)을 낮춰 공격적으로 운영

⚠️ 혼동 행렬 한계 및 주의사항

  • 이진 분류(Binary) 전용: 다중 클래스(Multi-class) 문제는 2x2가 아닌 더 큰 행렬이 필요하며, 각 클래스 쌍별로 1대1(One-vs-Rest) 방식으로 확장해야 합니다.
  • 임계값(Threshold) 의존성: 혼동 행렬의 숫자는 분류 임계값에 따라 크게 달라집니다. 따라서 고정된 임계값 하나만 보고 판단하지 말고, PR-AUC나 ROC-AUC 같은 곡선 기반 지표와 함께 봐야 합니다.
  • 클래스 불균형 시 왜곡된 해석: 음성이 99%인 데이터에서 FP가 0이고 FN이 100이면 TN은 엄청 많아 보이지만, 실제로는 양성을 전혀 찾지 못한 것입니다. 반드시 비율(Precision, Recall)로 환산하여 해석해야 합니다.
  • 비용(Cost) 정보 부재: FP 1개와 FN 1개의 금전적 비용이 동일하지 않을 수 있습니다. 예를 들어, 레버리지 전략에서 FP(손실)는 FN(기회 상실)보다 훨씬 치명적일 수 있습니다. 이러한 비용 정보는 혼동 행렬 외부에서 별도로 정의해야 합니다.

📚 혼동 행렬 (TP, TN, FP, FN) 주요 활용 분야

  • 모든 분류 모델의 1차 진단 도구: 머신러닝/딥러닝 모델을 개발할 때 가장 먼저 출력하여 오류의 패턴을 분석합니다.
  • 임계값(Threshold) 튜닝: FP와 FN의 비용을 고려하여 최적의 분류 경계선을 찾는 과정의 기초 자료로 사용됩니다.
  • 전략 성과 원인 분석: 퀀트 전략이 손실난 이유가 "잦은 허위 매수(FP)" 때문인지, "상승장을 못 탐(FN)" 때문인지 근본 원인을 추적합니다.
  • 불균형 데이터 처리: 오버샘플링(Over-sampling)이나 언더샘플링(Under-sampling) 전에 현재 데이터의 FP/FN 분포를 파악하는 출발점이 됩니다.
