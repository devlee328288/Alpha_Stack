📊 혼동 행렬 (Confusion Matrix) - TP, TN, FP, FN

혼동 행렬(Confusion Matrix)은 분류 모델(Classification Model)의 성능을 평가하는 가장 기본적이고 직관적인 도구로, 실제값(Actual)과 예측값(Predicted)을 행렬로 교차하여 각 경우의 수를 집계한 표입니다. 이 문서에서는 먼저 2진 분류(Binary)의 기본 개념을 익히고, 이를 3분류(상승/하락/보합)로 확장하는 방법과 해당 3분류에서 MCC, PR-AUC, BA(Balanced Accuracy)가 어떻게 적용되는지 설명합니다.

✅ 초록색 = 모델이 맞춤 ❌ 빨간색 = 모델이 틀림
TP (True Positive) = 실제 양성이고, 예측도 양성 (정답)

FN (False Negative) = 실제 양성인데, 예측을 음성으로 함 (2종 오류 / 놓친 기회)

📊 2. 3분류(상승/하락/보합) 혼동 행렬 (3x3)

🔍 3분류에서 TP, TN, FP, FN 재정의 (One-vs-Rest)

3분류에서는 특정 클래스 하나를 '양성(Positive)'으로, 나머지 두 개 클래스를 모두 '음성(Negative)'으로 묶는 One-vs-Rest (OVR) 방식으로 TP/TN/FP/FN을 계산합니다. 아래는 위 3x3 행렬을 OVR로 변환한 예시입니다.

기준 클래스 (Positive) TP FP FN TN
상승 (상승, 상승) (하락, 상승) + (보합, 상승) (상승, 하락) + (상승, 보합) 전체 샘플 - (TP + FP + FN)
하락 (하락, 하락) (상승, 하락) + (보합, 하락) (하락, 상승) + (하락, 보합) 전체 샘플 - (TP + FP + FN)
보합 (보합, 보합) (상승, 보합) + (하락, 보합) (보합, 상승) + (보합, 하락) 전체 샘플 - (TP + FP + FN)

📈 3. 클래스 비율 (Class Ratio)과 불균형의 함정

클래스 비율은 전체 데이터셋에서 각 클래스(상승/하락/보합)가 차지하는 샘플의 비율을 의미합니다. 금융 데이터는 대부분 불균형(Imbalanced)합니다. 예를 들어, 장기 우상향 시장에서는 '상승'이 50%, '하락'이 20%, '보합'이 30%일 수 있습니다.

📌 가상의 클래스 비율 예시 (전체 1,000개 샘플)

상승 50% (500개)
보합 30% (300개)
하락 20% (200개)
  • 🔴 상승 (50%): 다수 클래스 (Majority)
  • ⚪ 보합 (30%): 중간 클래스
  • 🔵 하락 (20%): 소수 클래스 (Minority)
⚠️ Accuracy(정확도)의 함정: 만약 모델이 모든 샘플을 '상승'으로만 예측해도 Accuracy는 50%가 나옵니다. 이는 전혀 쓸모없는 모델이지만, 성능이 50%인 것으로 오인할 수 있습니다. 따라서 불균형 데이터에서는 BA, MCC, PR-AUC 같은 지표가 필수적입니다.

📐 4. 3분류(상승/하락/보합) 평가 지표 적용법

3분류 모델을 평가할 때는 각 클래스의 성능을 균형 있게 반영해야 합니다. 대표적인 지표인 BA (Balanced Accuracy), MCC, PR-AUC가 3분류에서 어떻게 적용되는지 설명합니다.

✅ BA (Balanced Accuracy, 균형 정확도)

개념: 각 클래스별 Recall(재현율)의 산술 평균입니다. 불균형 데이터에서 Accuracy의 대안으로 사용됩니다.

3분류 수식: BA = ( Recall상승 + Recall하락 + Recall보합 ) / 3
  • 장점: 모든 클래스를 동등하게 취급하여, 소수 클래스(하락)의 성능 저하를 놓치지 않습니다.
  • 단점: 클래스별 샘플 수가 극도로 불균형할 때, 소수 클래스의 변동성에 전체 점수가 크게 영향받을 수 있습니다.
  • 해석: 0~1 사이의 값. 0.5는 무작위 추측 수준, 1.0은 완벽한 분류를 의미합니다.

✅ MCC (Matthews Correlation Coefficient, 매튜스 상관계수)

개념: 혼동 행렬의 모든 요소(TP, TN, FP, FN)를 종합하여 -1 ~ +1 사이의 값을 반환합니다.

3분류 적용 방식 (2가지):
  1. 일반화된 다중 분류 MCC (sklearn 공식 구현): 3x3 행렬 전체를 하나의 공식에 대입하여 단일 값을 계산합니다. (최대값 +1, 최소값은 -1보다 큼)
  2. Macro 평균 MCC (One-vs-Rest): 각 클래스별로 이진 MCC를 계산한 뒤, 세 클래스의 평균을 구합니다.
    → MCCMacro = (MCC상승 + MCC하락 + MCC보합) / 3
  • 장점: 불균형 데이터에서도 가장 신뢰할 수 있는 지표로 평가받습니다.
  • 해석: +1에 가까울수록 완벽한 예측, 0에 가까우면 무작위 추측, 음수면 반대 예측을 의미합니다.

✅ PR-AUC (Precision-Recall AUC)

개념: 임계값(Threshold) 변화에 따른 Precision-Recall 곡선 아래 면적(AUC)입니다. 불균형 데이터에서 ROC-AUC보다 정확한 평가를 제공합니다.

3분류 적용 방식:
  • One-vs-Rest (OVR) 확장: 각 클래스(상승, 하락, 보합)별로 별도의 PR 곡선을 그리고, 각각의 AUC를 계산합니다.
  • 최종 PR-AUC:
    • Macro 평균: (AUC상승 + AUC하락 + AUC보합) / 3 → 모든 클래스를 동등하게 평가
    • Micro 평균: 모든 클래스의 TP/FP/FN을 합산하여 하나의 PR 곡선을 그리고 AUC 계산 → 다수 클래스의 영향이 큼
  • 장점: 소수 클래스(하락)의 탐지 성능을 정밀하게 측정할 수 있습니다.
  • 해석: 0~1 사이의 값. 1에 가까울수록 완벽한 분류, 0.5는 무작위 추측 수준입니다.

🧮 5. 3분류 혼동 행렬 기반 평가 지표 계산 예시

📌 예시: 3x3 혼동 행렬 (총 150개 샘플)

실제 \ 예측 상승 하락 보합 합계
상승 40 (TP) 5 (FN) 5 (FN) 50
하락 8 (FP) 30 (TP) 2 (FN) 40
보합 4 (FP) 6 (FP) 50 (TP) 60
합계 52 41 57 150

👉 Step 1: 각 클래스별 Recall(재현율) 계산

  • Recall상승 = 40 / 50 = 0.800
  • Recall하락 = 30 / 40 = 0.750
  • Recall보합 = 50 / 60 = 0.833

👉 Step 2: BA (Balanced Accuracy) 계산
BA = (0.800 + 0.750 + 0.833) / 3 = 2.383 / 3 ≈ 0.794 (79.4%)

👉 Step 3: Macro MCC 계산 (OVR 방식)
각 클래스별 MCC를 계산하면 (계산 과정 생략):
MCC상승 ≈ 0.673, MCC하락 ≈ 0.650, MCC보합 ≈ 0.763
MCCMacro = (0.673 + 0.650 + 0.763) / 3 ≈ 0.695

👉 Step 4: PR-AUC (Macro 평균) 계산
각 클래스별 PR-AUC를 계산했다고 가정하면 (예시 값):
AUC상승 ≈ 0.85, AUC하락 ≈ 0.78, AUC보합 ≈ 0.88
PR-AUCMacro = (0.85 + 0.78 + 0.88) / 3 ≈ 0.837

✅ 종합 해석: BA(79.4%)와 MCC(0.695)가 모두 양호한 수준이며, PR-AUC(0.837)도 우수합니다. 세 지표 모두 일관되게 해당 3분류 모델이 실무에서 충분히 활용 가능한 수준임을 보여줍니다.

📊 6. 3분류에서의 1종 오류(FP)와 2종 오류(FN)의 의미

구분 1종 오류 (FP / False Positive) 2종 오류 (FN / False Negative)
정의 (OVR 기준) 실제는 타 클래스인데, 특정 클래스(P)로 잘못 예측 실제는 특정 클래스(P)인데, 타 클래스로 잘못 예측
금융 예시 (상승 기준) 하락/보합인데 "상승" 예측 → 손실 또는 기회비용 실제 상승인데 "하락/보합" 예측 → 수익 기회 상실
대응 전략 해당 클래스의 임계값(Threshold)을 높여 보수적으로 운영 해당 클래스의 임계값(Threshold)을 낮춰 공격적으로 운영

💡 3분류에서는 각 클래스마다 FP와 FN의 비용이 다를 수 있습니다. 예를 들어, '하락'을 '상승'으로 잘못 예측(FP)하는 것과 '보합'을 '상승'으로 잘못 예측(FP)하는 것은 손실 규모가 다를 수 있으므로, 클래스별 가중치(Cost-sensitive)를 고려한 전략 설계가 필요합니다.

⚠️ 7. 혼동 행렬 및 3분류 평가 시 주의사항

  • 다중 분류(Multi-class) OVR 해석의 한계: OVR 방식은 각 클래스를 독립적으로 평가하지만, 클래스 간 상호 배타적(Mutually Exclusive)인 특성을 완전히 반영하지는 못합니다. 따라서 Macro 평균과 Micro 평균을 함께 보고 종합적으로 판단해야 합니다.
  • 임계값(Threshold) 의존성: 혼동 행렬의 숫자는 분류 임계값에 따라 크게 달라집니다. 따라서 고정된 임계값 하나만 보고 판단하지 말고, PR-AUC나 ROC-AUC 같은 곡선 기반 지표와 함께 봐야 합니다.
  • 클래스 불균형 시 BA와 MCC의 우위: Accuracy는 불균형 데이터에서 무조건 다수 클래스로 예측해도 높게 나오지만, BA와 MCC는 소수 클래스의 성능 저하를 민감하게 반영하므로, 반드시 이 지표들을 기준으로 모델을 선택해야 합니다.
  • 비용(Cost) 정보 부재: FP 1개와 FN 1개의 금전적 비용이 동일하지 않을 수 있습니다. 예를 들어, 레버리지 전략에서 FP(손실)는 FN(기회 상실)보다 훨씬 치명적일 수 있습니다. 이러한 비용 정보는 혼동 행렬 외부에서 별도로 정의해야 합니다.

📚 8. 3분류 혼동 행렬 및 평가 지표 활용 분야

  • 주가 방향성 예측 (상승/하락/보합): 3가지 시나리오에 대한 모델의 예측 능력을 BA, MCC, PR-AUC로 종합 검증.
  • 신용 평가 (양호/보통/불량): 각 등급별 예측 성능을 OVR 방식으로 분석하여 리스크 관리에 활용.
  • 이상 탐지 (정상/의심/위험): 소수 클래스(위험)에 대한 탐지력을 PR-AUC로 정밀 측정.
  • 멀티 클래스 트레이딩 시그널: 매수/매도/홀드(보유) 신호의 정확도를 Accuracy 대신 BA와 MCC로 엄격하게 평가.
