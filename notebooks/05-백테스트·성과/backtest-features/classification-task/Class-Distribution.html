📊 클래스 비율 (Class Ratio / Imbalance Ratio)

클래스 비율은 분류(Classification) 문제에서 각 클래스(Label)가 전체 데이터셋에서 차지하는 비율을 의미합니다. 이진 분류(Binary Classification)에서는 주로 양성 클래스(Positive, 관심 사건)의 비율과 음성 클래스(Negative)의 비율로 표현됩니다.

이 비율은 혼동 행렬(Confusion Matrix)의 행(Row) 합계에서 직접 파생됩니다. 즉, 양성 비율 = (TP + FN) / 전체, 음성 비율 = (TN + FP) / 전체로, 앞서 정의한 혼동 행렬의 TP, TN, FP, FN 값과 완전히 연동(Interlocked)되어 있습니다.

클래스 비율은 단순한 통계 이상으로, PR-AUC의 무작위 기준선(Base Rate)을 결정하고, Accuracy의 함정을 이해하며, Balanced Accuracy나 MCC 같은 보정 지표를 사용해야 하는지 판단하는 모든 불균형 학습(Imbalanced Learning)의 출발점입니다.

📐 클래스 비율 기본 수식 (혼동 행렬 연동)

양성 비율 (Positive Rate) = ( TP + FN ) / ( TP + FN + TN + FP )
음성 비율 (Negative Rate) = ( TN + FP ) / ( TP + FN + TN + FP )
(단, 양성 비율 + 음성 비율 = 1 (100%))

📐 불균형 비율 (Imbalance Ratio) 계산

불균형 비율 = (음성 개수) / (양성 개수) = (TN + FP) / (TP + FN)
※ 값이 1에 가까울수록 균형, 클수록 불균형(Imbalance)이 심함을 의미합니다.

🔍 변수(Variables) 상세 설명

변수명 기호 상세 설명 및 혼동 행렬 연동
양성 비율 P_rate 또는 Base Rate 연동값 전체 데이터 중 실제 양성(Positive) 클래스가 차지하는 비율.
공식: (TP + FN) / Total
PR-AUC의 무작위 기준선이 바로 이 값입니다.
음성 비율 N_rate 연동값 전체 데이터 중 실제 음성(Negative) 클래스가 차지하는 비율.
공식: (TN + FP) / Total
1 - P_rate와 동일합니다.
불균형 비율 IR 파생값 다수 클래스(음성)가 소수 클래스(양성)보다 몇 배나 많은지를 나타내는 지표.
공식: (TN + FP) / (TP + FN)
예: IR=10이면 음성이 양성보다 10배 많음.
전체 샘플 수 Total 기본값 혼동 행렬의 모든 요소의 합: TP + TN + FP + FN.

🧮 계산 예시 (이전 혼동 행렬 데이터와 동일)

📌 예시 데이터 (총 100개 거래 신호)

  • 혼동 행렬 결과: TP=50, TN=30, FP=10, FN=10 (총 100개)

👉 1) 클래스 비율 계산 (혼동 행렬 행 합계)

  • 실제 양성(Actual Positive) = TP + FN = 50 + 10 = 60개
  • 실제 음성(Actual Negative) = TN + FP = 30 + 10 = 40개
  • 양성 비율 (Base Rate) = 60 / 100 = 0.60 (60%)
  • 음성 비율 = 40 / 100 = 0.40 (40%)
  • 불균형 비율 (IR) = 40 / 60 ≈ 0.67 (오히려 양성이 더 많아 약간 역불균형)

⚠️ 진짜 문제가 되는 극단적 불균형 예시 (사기 탐지)

  • 가정: 총 1,000개, TP=10, FN=5 (양성 15개), TN=850, FP=130 (음성 985개)
  • 양성 비율 = 15 / 1000 = 1.5%
  • 불균형 비율 (IR) = 985 / 15 ≈ 65.7 (음성이 양성보다 65배 많음!)
  • 👉 이 환경에서 Accuracy는 86%로 높게 나오지만, Balanced Accuracy는 52.5%에 불과합니다.
  • 👉 즉, 클래스 비율을 보면 Accuracy를 신뢰할 수 없는 이유를 바로 알 수 있습니다.

✅ 해석: 클래스 비율은 혼동 행렬에서 단순히 행(Row)의 합계를 구하면 바로 산출됩니다. 따라서 혼동 행렬만 있으면 클래스 비율은 부가적인 계산 없이 즉시 파생될 수 있습니다.

📈 클래스 비율 및 불균형 수준 해석 가이드

  • 🟢 0.4 ≤ 양성 비율 ≤ 0.6 : 균형(Balanced) 데이터. Accuracy, ROC-AUC 등 모든 지표를 신뢰할 수 있습니다.
  • 🟡 0.2 ≤ 양성 비율 < 0.4 또는 0.6 < 양성 비율 ≤ 0.8 : 약한 불균형. Accuracy에 주의가 필요하며, F1-Score를 기본으로 봐야 합니다.
  • 🟠 0.05 ≤ 양성 비율 < 0.2 또는 0.8 < 양성 비율 ≤ 0.95 : 심한 불균형(Moderate Imbalance). Accuracy는 절대 사용 금지. PR-AUC, Balanced Accuracy가 필수입니다.
  • 🔴 양성 비율 < 0.05 또는 > 0.95 : 극도로 심한 불균형(Extreme Imbalance). 일반적인 머신러닝이 통하지 않습니다. 오버샘플링(SMOTE)이나 언더샘플링이 선행되어야 합니다.

💡 프로젝트 실무 팁: 데이터 로딩 후 가장 먼저 이 클래스 비율을 체크하세요. 비율이 9:1을 넘어가면, Accuracy는 즉시 무시하고 PR-AUC와 MCC를 메인 지표로 삼아야 합니다.

📊 클래스 비율에 따른 주요 지표 변화 (균형 vs 불균형)

구분 균형 데이터 (양성 50%) 불균형 데이터 (양성 5%)
Accuracy 기준선 50% (무작위) 95% (다수 클래스 찍어도 높음) ⚠️
PR-AUC 기준선 0.50 0.05 (극도로 낮음, 엄격해짐)
Balanced Accuracy 기준선 0.50 0.50 (불변, 신뢰할 수 있음) ✅
추천 지표 Accuracy, ROC-AUC PR-AUC, MCC, Balanced Accuracy (필수)

⚠️ 클래스 비율 해석 시 주의사항

  • 비율 자체는 '잘못'이 아닙니다: 불균형은 데이터의 현실적 특성(예: 사기 발생률 1%)을 반영한 것입니다. 문제는 이 비율을 무시하고 Accuracy 같은 부적합한 지표를 사용하는 것에 있습니다.
  • 샘플링(Sampling) 전에 반드시 확인: 오버샘플링이나 언더샘플링을 적용하기 전에 원본 데이터의 클래스 비율을 기록해 두어야, 샘플링 후의 성능 향상이 실제 모델 개선 때문인지, 단순히 분포를 맞춘 때문인지 판단할 수 있습니다.
  • 비용(Cost)과의 결합: 양성 비율이 1%라도 FP(허위 경보)의 비용이 FN(놓친 탐지)보다 훨씬 크다면, 비율만 보고 "불균형이니 무조건 샘플링하자"고 결정해서는 안 됩니다. 비용 행렬(Cost Matrix)과 함께 고려해야 합니다.
  • 다중 클래스(Multi-class)에서의 확장: 3개 이상의 클래스가 있다면, 각 클래스별 비율을 모두 체크해야 합니다. 이때는 가장 희귀한 클래스(Min 클래스)와 가장 많은 클래스(Maj 클래스)의 비율 차이를 보는 것이 핵심입니다.

📚 클래스 비율 주요 활용 분야 (프로젝트 연동)

  • 데이터 탐색(EDA)의 첫 단계: 프로젝트 시작 시 Target 변수의 분포를 확인하여 불균형 여부를 진단합니다.
  • 평가 지표(Metric) 선정의 기준: 비율이 9:1을 넘으면 PR-AUC와 MCC를 메인으로, 7:3 정도면 F1-Score를 메인으로 선정합니다.
  • 혼동 행렬(Confusion Matrix) 해석의 전제: "TP가 80개"라는 숫자만 보고 좋아하지 말고, "전체 양성이 100개 중 80개"인지, "1000개 중 80개"인지를 클래스 비율로 확인해야 합니다.
  • 샘플링 전략(Sampling Strategy) 수립: 불균형 비율(IR)이 10을 넘으면 SMOTE, 5~10이면 언더샘플링, 5 미만이면 가중치(Class Weight) 조정으로 전략을 차별화합니다.
