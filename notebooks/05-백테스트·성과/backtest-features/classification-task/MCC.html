📊 MCC (Matthews Correlation Coefficient) - 매튜스 상관계수

MCC (매튜스 상관계수)는 이진 분류(Binary Classification) 모델의 성능을 평가하는 가장 균형 잡히고 신뢰할 수 있는 지표 중 하나입니다. 혼동 행렬(Confusion Matrix)의 네 가지 요소(TP, TN, FP, FN)를 모두 활용하여 -1에서 +1 사이의 값을 반환하며, 데이터가 극도로 불균형(Imbalanced)한 상황에서도 정확도(Accuracy)의 함정에 빠지지 않고 모델의 진짜 예측력을 평가할 수 있습니다.

금융 분야에서는 주가 상승/하락 방향성 예측, 부도/도산 예측, 이상 거래 탐지 등에서 클래스 불균형이 심각한 경우가 많기 때문에, MCC는 이러한 모델들의 실전 성능을 검증하는 필수적인 보조 지표로 자리 잡고 있습니다.

📐 MCC 기본 수식 (이진 분류)

MCC = ( TP · TN − FP · FN ) / √( (TP + FP) · (TP + FN) · (TN + FP) · (TN + FN) )
(단, TP = True Positive, TN = True Negative, FP = False Positive, FN = False Negative)

📐 세부 계산 수식 (혼동 행렬 기반)

MCC = ( TP × TN − FP × FN ) / √( ( TP + FP ) · ( TP + FN ) · ( TN + FP ) · ( TN + FN ) )
※ 모든 혼동 행렬 요소(TP, TN, FP, FN)를 동시에 고려하여 단일 점수로 평가합니다.

🔍 변수(Variables) 상세 설명

변수명 기호 상세 설명 및 입력값
매튜스 상관계수 MCC 결과값 -1 ~ +1 범위의 무차원 수치. +1 = 완벽한 예측, 0 = 무작위 추측 수준, -1 = 예측이 실제와 완전히 반대임을 의미합니다.
TP (진짜 양성) TP 입력값 실제 양성(Positive)이고, 모델도 양성으로 맞춘 개수. (예: 실제 상승장을 상승으로 맞춤)
TN (진짜 음성) TN 입력값 실제 음성(Negative)이고, 모델도 음성으로 맞춘 개수. (예: 실제 하락장을 하락으로 맞춤)
FP (거짓 양성) FP 입력값 실제는 음성이지만, 모델이 잘못 양성으로 예측한 개수. (예: 실제 하락장을 상승으로 잘못 예측 - 1종 오류)
FN (거짓 음성) FN 입력값 실제는 양성이지만, 모델이 잘못 음성으로 예측한 개수. (예: 실제 상승장을 하락으로 잘못 예측 - 2종 오류)

🧮 계산 예시 (Example) - 이진 분류

📌 예시 상황 (불균형한 100개의 주가 방향성 예측 데이터)

  • 실제 상승장(양성): 50개, 실제 하락장(음성): 50개 (의도적 균형)
  • 혼동 행렬 결과:
    • TP (상승을 상승으로 맞춤): 45개
    • TN (하락을 하락으로 맞춤): 40개
    • FP (하락을 상승으로 예측): 10개
    • FN (상승을 하락으로 예측): 5개

👉 1) 분자 계산 (TP·TN − FP·FN)
(45 × 40) − (10 × 5) = 1800 − 50 = 1,750

👉 2) 분모 계산 (√((TP+FP)(TP+FN)(TN+FP)(TN+FN)))
(45+10) × (45+5) × (40+10) × (40+5) = 55 × 50 × 50 × 45 = 6,187,500
√6,187,500 ≈ 2,487.5

👉 3) MCC 최종 계산
MCC = 1,750 / 2,487.5 ≈ 0.703

✅ 해석: MCC ≈ 0.70으로, 이 모델은 상승과 하락을 모두 고려했을 때 우수한 수준(Strong)의 예측력을 가지고 있습니다. 동일한 데이터의 정확도(Accuracy)는 (45+40)/100 = 85%로 매우 높아 보이지만, MCC는 양성/음성 모두의 오차를 균형 있게 반영하여 더 엄격하고 신뢰할 수 있는 평가를 제공합니다.

📈 MCC 해석 가이드 (일반적 기준)

  • 🔴 MCC < 0.0 : 예측이 실제와 반대 방향 (모델을 폐기해야 함).
  • 🟡 0.0 ≤ MCC < 0.2 : 무작위 추측 수준 (예측력 없음).
  • 🟡 0.2 ≤ MCC < 0.4 : 약한 예측력 (개선이 필요한 수준).
  • 🟢 0.4 ≤ MCC < 0.6 : 양호한 예측력 (실무에서 활용 가능).
  • ⭐ 0.6 ≤ MCC < 0.8 : 우수한 예측력 (매우 신뢰할 수 있음).
  • 🚀 MCC ≥ 0.8 : 매우 뛰어난 예측력 (완벽에 가까운 분류 성능).

⚠️ MCC는 0.3 이상만 되어도 실무에서 의미 있는 수준으로 간주됩니다. 특히 금융 데이터는 노이즈가 심하기 때문에, 0.2~0.3 수준의 MCC라도 전략적 우위를 제공할 수 있습니다.

🔀 다중 분류(Multi-class)에서의 MCC 확장

MCC는 기본적으로 이진 분류(Binary Classification)를 위해 설계되었습니다. 하지만 3개 이상의 클래스(예: 상승/하락/보합)를 분류해야 하는 경우, Macro 평균과 Micro 평균 방식을 활용하여 MCC를 확장할 수 있습니다.

📌 Macro 평균 MCC (Macro-averaged MCC)

각 클래스를 1대 나머지(One-vs-Rest) 방식으로 이진 분류 문제로 변환한 후, 각 클래스별로 MCC를 계산하고 모든 클래스의 산술 평균을 구합니다.

수식:
MCCMacro = (MCCclass1 + MCCclass2 + ... + MCCclassK) / K
(K = 전체 클래스 개수)
  • 장점: 모든 클래스를 동등하게 취급하므로, 소수 클래스의 성능 저하를 놓치지 않음.
  • 단점: 클래스별 샘플 수가 극도로 불균형할 때, 소수 클래스의 변동성에 전체 점수가 크게 영향받을 수 있음.

📌 Micro 평균 MCC (Micro-averaged MCC)

모든 클래스의 혼동 행렬 요소(TP, TN, FP, FN)를 전체적으로 합산(aggregate)한 뒤, 하나의 통합된 이진 혼동 행렬을 만들고 단일 MCC를 계산합니다.

수식:
TPtotal = Σ TPi,   TNtotal = Σ TNi,   FPtotal = Σ FPi,   FNtotal = Σ FNi
MCCMicro = (TPtotal·TNtotal − FPtotal·FNtotal) / √((TPtotal+FPtotal)·(TPtotal+FNtotal)·(TNtotal+FPtotal)·(TNtotal+FNtotal))
  • 장점: 전체 데이터 샘플을 기준으로 평가하므로, 다수 클래스의 성능이 전체 점수에 반영됨.
  • 단점: 소수 클래스의 오류가 전체 점수에 거의 반영되지 않아 희귀 클래스 탐지 능력을 과대평가할 위험이 있음.

🧮 다중 분류 MCC 계산 예시 (3개 클래스: 상승/하락/보합)

📌 예시: 3x3 혼동 행렬 (총 150개 샘플)

실제 \ 예측 상승 하락 보합 합계
상승 40 (TP) 5 (FN) 5 (FN) 50
하락 8 (FP) 30 (TP) 2 (FN) 40
보합 4 (FP) 6 (FP) 50 (TP) 60
합계 52 41 57 150

👉 Step 1: 각 클래스별 이진 MCC 계산 (One-vs-Rest)

  • 클래스 '상승' (Positive=상승, Negative=하락+보합)
    TP=40, TN=(30+2)+(6+50)=88, FP=8+4=12, FN=5+5=10
    MCC상승 = (40×88 − 12×10) / √((40+12)(40+10)(88+12)(88+10)) = (3520−120) / √(52×50×100×98) = 3400 / √25,480,000 ≈ 3400 / 5048 ≈ 0.673
  • 클래스 '하락' (Positive=하락, Negative=상승+보합)
    TP=30, TN=(40+5)+(4+50)=99, FP=5+2=7, FN=8+6=14
    MCC하락 = (30×99 − 7×14) / √((30+7)(30+14)(99+7)(99+14)) = (2970−98) / √(37×44×106×113) = 2872 / √19,489,784 ≈ 2872 / 4415 ≈ 0.650
  • 클래스 '보합' (Positive=보합, Negative=상승+하락)
    TP=50, TN=(40+5)+(8+30)=83, FP=5+2=7, FN=4+6=10
    MCC보합 = (50×83 − 7×10) / √((50+7)(50+10)(83+7)(83+10)) = (4150−70) / √(57×60×90×93) = 4080 / √28,607,400 ≈ 4080 / 5348 ≈ 0.763

👉 Step 2: Macro 평균 MCC 계산

MCCMacro = (0.673 + 0.650 + 0.763) / 3 = 2.086 / 3 ≈ 0.695

👉 Step 3: Micro 평균 MCC 계산 (전체 합산)

  • TPtotal = 40 + 30 + 50 = 120
  • TNtotal = (30+2+6+50) + (40+5+4+50) + (40+5+8+30) = 88 + 99 + 83 = 270
  • FPtotal = (8+4) + (5+2) + (5+2) = 12 + 7 + 7 = 26
  • FNtotal = (5+5) + (8+6) + (4+6) = 10 + 14 + 10 = 34

MCCMicro = (120×270 − 26×34) / √((120+26)(120+34)(270+26)(270+34))
= (32400 − 884) / √(146 × 154 × 296 × 304)
= 31516 / √(146×154=22,484, 296×304=89,984 → 22,484×89,984 ≈ 2,022,000,000)
= 31516 / √2,022,000,000 ≈ 31516 / 44,966 ≈ 0.701

✅ 해석: 이 모델의 Macro MCC는 0.695, Micro MCC는 0.701로, 두 방식 모두 0.6~0.8 구간(우수한 예측력)에 해당합니다. Macro와 Micro 값이 유사하므로, 클래스 간 성능 편차가 크지 않음을 알 수 있습니다.

🐍 Python으로 Macro/Micro MCC 계산하기

# sklearn을 이용한 Macro/Micro MCC 계산 예제
from sklearn.metrics import matthews_corrcoef
import numpy as np
from sklearn.preprocessing import label_binarize

# 실제 레이블과 예측 레이블 (3개 클래스: 0=상승, 1=하락, 2=보합)
y_true = np.array([0, 1, 2, 0, 1, 2, 0, 1, 2, 0, 1, 2]) # 간단한 예시
y_pred = np.array([0, 1, 2, 0, 0, 2, 1, 1, 2, 0, 1, 2])

# 1) Macro MCC: 각 클래스를 One-vs-Rest로 이진화하여 MCC 계산 후 평균
classes = np.unique(y_true)
mcc_list = []
for cls in classes:
    y_true_bin = (y_true == cls).astype(int)
    y_pred_bin = (y_pred == cls).astype(int)
    mcc_list.append(matthews_corrcoef(y_true_bin, y_pred_bin))
macro_mcc = np.mean(mcc_list)

# 2) Micro MCC: 모든 클래스의 TP/TN/FP/FN을 합산하여 단일 MCC 계산
# → sklearn의 matthews_corrcoef는 이진 분류만 지원하므로, 직접 구현하거나
# 'sklearn.metrics.multilabel_confusion_matrix'와 'confusion_matrix' 활용
from sklearn.metrics import confusion_matrix, multilabel_confusion_matrix

# Micro MCC 직접 계산 함수 (예시)
def micro_mcc(y_true, y_pred):
    classes = np.unique(y_true)
    TP_total = TN_total = FP_total = FN_total = 0
    for cls in classes:
        y_true_bin = (y_true == cls).astype(int)
        y_pred_bin = (y_pred == cls).astype(int)
        tn, fp, fn, tp = confusion_matrix(y_true_bin, y_pred_bin).ravel()
        TP_total += tp; TN_total += tn; FP_total += fp; FN_total += fn
    numerator = TP_total * TN_total - FP_total * FN_total
    denominator = ((TP_total+FP_total)*(TP_total+FN_total)*(TN_total+FP_total)*(TN_total+FN_total)) ** 0.5
    return numerator / denominator if denominator != 0 else 0

micro_mcc_value = micro_mcc(y_true, y_pred)

print(f"Macro MCC: {macro_mcc:.4f}")
print(f"Micro MCC: {micro_mcc_value:.4f}")

📊 MCC vs Accuracy (정확도) 비교

구분 MCC (매튜스 상관계수) Accuracy (정확도)
사용 요소 TP, TN, FP, FN 모두 활용 (균형 잡힘) TP, TN만 사용 (맞춘 것만 봄)
불균형 데이터 불균형에 강건(Robust)하여 속지 않음 불균형에 취약 (예: 99%가 0인 데이터는 99% 찍어도 높음)
결과 범위 -1 ~ +1 (음수 값으로 '반대 예측'까지 알려줌) 0 ~ 1 (음수가 없어 방향성 평가 불가)
실무 활용 신뢰도 높은 최종 검증 지표로 활용 기초 참고용 (MCC와 항상 같이 봄)

⚠️ MCC (매튜스 상관계수) 한계 및 주의사항

  • 다중 분류(Multi-class)에는 직접 적용 불가: MCC는 기본적으로 이진 분류(Binary) 전용입니다. 다중 분류로 확장하려면 위에서 설명한 Macro/Micro 평균 MCC를 별도로 계산해야 하며, 이는 공식 표준이라기보다 널리 통용되는 실무적 관행에 가깝습니다.
  • 분모가 0이 되는 경우: 특정 클래스의 예측이 전혀 없을 때(예: TP+FP=0) 분모가 0이 되어 계산이 불가능합니다. 이 경우 MCC는 정의되지 않음(Undefined)으로 처리해야 합니다.
  • 확률적 해석의 어려움: 0.5가 '보통'이다라는 직관적인 기준이 없어, 도메인 지식(해당 업계의 평균 MCC)과 함께 해석해야 합니다.
  • 임계값(Threshold) 의존성: 분류 임계값을 조정하면 TP/FP/TN/FN이 모두 변하므로, MCC는 임계값에 따라 변동이 심합니다. 다양한 임계값에서의 평균 MCC를 보는 것이 좋습니다.
  • Macro vs Micro 선택 시 주의: Macro는 소수 클래스에 민감하고, Micro는 다수 클래스에 치우칩니다. 두 값을 모두 보고 차이를 분석하거나, 분석 목적에 맞게 하나를 선택해야 합니다.

📚 MCC (매튜스 상관계수) 주요 활용 분야

  • 주가 방향성 예측 모델: 상승/하락 이진 분류 모델의 실전 적합성을 MCC로 최종 검증.
  • 부도/도산 예측 (Credit Scoring): 부도율이 극도로 낮은 데이터에서 모델의 진짜 탐지력을 평가.
  • 이상 거래 탐지 (Fraud Detection): 정상 거래가 99%인 환경에서 이상 거래를 얼마나 잘 찾는지 측정.
  • 바이너리 옵션/차익 거래 시그널: 매수/매도 신호의 정확도를 Accuracy 대신 MCC로 엄격하게 평가.
  • 3분류 이상의 멀티클래스 전략: 상승/하락/보합 등 3개 이상의 클래스에서 Macro/Micro MCC로 종합 성능 평가.
