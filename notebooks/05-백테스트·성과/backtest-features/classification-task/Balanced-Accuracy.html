⚖️ Balanced Accuracy - 밸런스드 정확도

Balanced Accuracy (밸런스드 정확도)는 이진 분류(Binary Classification) 모델의 성능을 평가하는 지표로, 민감도(Sensitivity, True Positive Rate)와 특이도(Specificity, True Negative Rate)의 산술 평균입니다. 즉, 양성(Positive)과 음성(Negative) 클래스 각각에 대한 정확도를 동등한 가중치로 평균내어, 데이터 불균형(Imbalanced Data) 상황에서 발생하는 정확도(Accuracy)의 함정을 보완합니다.

예를 들어, 전체 데이터의 90%가 음성인 경우, 모델이 모든 것을 음성으로 예측해도 정확도는 90%가 나오지만, Balanced Accuracy는 50% (양성은 0%, 음성은 100% → 평균 50%)로 계산되어 모델이 전혀 예측력이 없음을 정확히 지적합니다. 따라서 금융 분야에서는 부도 예측, 사기 탐지, 희귀 상승장 예측 등에서 Accuracy 대신 기본적인 검증 지표로 널리 사용됩니다.

📐 Balanced Accuracy 기본 수식

Balanced Accuracy = ( Sensitivity + Specificity ) / 2
(단, Sensitivity = TP/(TP+FN), Specificity = TN/(TN+FP))

📐 세부 계산 수식 (혼동 행렬 기반)

Balanced Accuracy = [ TP / ( TP + FN ) + TN / ( TN + FP ) ] / 2
※ 초록색은 모델이 맞춘 것, 빨간색은 모델이 틀린 것입니다. 두 클래스 모두 동등하게 50%씩 가중치를 부여합니다.

🔍 변수(Variables) 상세 설명

변수명 기호 상세 설명 및 입력값
밸런스드 정확도 Balanced Accuracy 결과값 0 ~ 1 범위의 무차원 수치. 0.5는 무작위 추측 수준, 1.0은 완벽한 분류를 의미합니다. (데이터 불균형에 관계없이 항상 0.5가 기준선입니다.)
민감도 (Sensitivity / TPR) Recall 또는 TPR 중간값 실제 양성(Positive) 중 모델이 정확히 맞춘 비율.
공식: TP / (TP + FN) — 실제 양성을 놓치지 않았는가를 측정합니다.
특이도 (Specificity / TNR) TNR 중간값 실제 음성(Negative) 중 모델이 정확히 맞춘 비율.
공식: TN / (TN + FP) — 실제 음성을 얼마나 잘 배제(거짓 경보 회피)했는가를 측정합니다.
TP / TN / FP / FN 혼동 행렬 입력값 이전 MCC 페이지에서 정의된 동일한 혼동 행렬 요소들입니다. (TP: 진짜 양성, TN: 진짜 음성, FP: 거짓 양성, FN: 거짓 음성)

🧮 계산 예시 (Example)

📌 예시 상황 (극도로 불균형한 1,000개 데이터, 실제 양성 10% = 100개)

  • 모델 A (무식한 모델): 모든 데이터를 음성(Negative)으로 예측함.
    • TP = 0, FN = 100 (양성을 모두 놓침)
    • TN = 900, FP = 0 (음성은 모두 맞춤)

👉 1) 정확도 (Accuracy) 계산 (함정)
Accuracy = (TP + TN) / 전체 = (0 + 900) / 1000 = 0.90 (90%)
👉 매우 높아 보이지만, 모델은 전혀 예측을 못 하고 있습니다!

👉 2) Balanced Accuracy 계산 (진짜 평가)
Sensitivity (TPR) = TP / (TP + FN) = 0 / (0 + 100) = 0.0
Specificity (TNR) = TN / (TN + FP) = 900 / (900 + 0) = 1.0
Balanced Accuracy = (0.0 + 1.0) / 2 = 0.50 (50%)

✅ 해석: Balanced Accuracy는 0.50으로, 이 모델이 무작위 추측(동전 던지기) 수준임을 정확히 지적합니다. 이처럼 Balanced Accuracy는 데이터 비율에 상관없이 항상 0.5를 무작위 기준선으로 사용하여, 불균형 데이터에서 속지 않도록 도와줍니다.

📈 Balanced Accuracy 해석 가이드

  • 🔴 Balanced Accuracy < 0.5 : 무작위 추측보다 나쁨 (모델이 의도적으로 반대로 예측 중).
  • 🟡 0.5 : 무작위 추측 수준 (전혀 예측력 없음).
  • 🟡 0.5 < BA < 0.7 : 약한 예측력. 다수 클래스만 편향되어 있을 가능성이 큼.
  • 🟢 0.7 ≤ BA < 0.8 : 양호한 예측력. 실무에서 의미 있는 수준.
  • ⭐ 0.8 ≤ BA < 0.9 : 우수한 예측력. 양성과 음성을 모두 훌륭히 구분함.
  • 🚀 BA ≥ 0.9 : 매우 뛰어난 예측력 (거의 완벽한 분류).

💡 핵심 포인트: Balanced Accuracy는 데이터의 양성 비율이 1%이든 99%이든 항상 0.5가 무작위 기준선입니다. 따라서 불균형이 심할수록 Accuracy보다 Balanced Accuracy가 훨씬 더 엄격하고 신뢰할 수 있는 평가를 제공합니다.

📊 Balanced Accuracy vs Accuracy (정확도) 비교

구분 Balanced Accuracy Accuracy (정확도)
계산 방식 (TPR + TNR) / 2 (클래스별 평균) (TP + TN) / 전체 (전체 중 맞춘 비율)
클래스 불균형 강건(Robust) — 양성/음성 모두 동등하게 봄 취약 — 다수 클래스만 잘 맞춰도 높게 나옴
무작위 기준선 항상 0.5 (50%) (데이터와 무관) 데이터의 다수 클래스 비율 (예: 90%)
실무 활용 불균형 데이터의 최종 검증 지표로 필수 사용 클래스 균형이 완벽할 때만 신뢰 가능

⚠️ Balanced Accuracy 한계 및 주의사항

  • 정밀도(Precision)를 직접 고려하지 않음: Balanced Accuracy는 FP(거짓 양성)를 Specificity를 통해 간접적으로만 반영합니다. FP가 매우 많아도 TN이 많으면 Specificity가 높게 유지될 수 있으므로, F1-Score나 MCC와 함께 보는 것이 필수입니다.
  • 임계값(Threshold) 의존성: 다른 분류 지표와 마찬가지로, 확률 출력의 임계값을 어떻게 설정하느냐에 따라 Balanced Accuracy가 크게 변동합니다. 고정된 임계값보다는 PR-AUC 등 곡선 기반 지표와 병행하는 것이 좋습니다.
  • 다중 클래스(Multi-class)로의 확장: 이진 분류 전용입니다. 다중 클래스로 확장하려면 Macro Balanced Accuracy (각 클래스의 Recall 평균)를 별도로 계산해야 합니다.
  • 의미 없는 '0.5' 돌파에 대한 과신: 0.51이 0.5보다 높다고 해서 반드시 실전에서 쓸모 있는 것은 아닙니다. 통계적 유의성 검정(예: McNemar's test)을 통해 0.5와의 차이가 우연인지 검증해야 합니다.

📚 Balanced Accuracy 주요 활용 분야

  • 부도/도산 예측 모델 (Credit Default): 부도율이 1~2%인 환경에서 Accuracy 대신 기본 성능 지표로 사용.
  • 사기 탐지 (Fraud Detection): 정상 거래가 99.9%인 데이터에서 사기 탐지 모델의 최소 성능 기준을 설정.
  • 의료 진단 (희귀 질환): 환자군이 극소수인 경우, 민감도와 특이도를 동시에 만족하는지 평가.
  • 퀀트 상승/하락 방향성 예측: 상승장이 드문 시기에, 단순히 하락만 맞추는 전략을 필터링하는 1차 관문으로 활용.
