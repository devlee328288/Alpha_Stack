📉 PR-AUC (Precision-Recall Area Under the Curve) - 정밀도-재현율 곡선 면적

PR-AUC (정밀도-재현율 곡선 아래 면적)은 이진 분류 모델의 성능을 평가하는 지표로, 정밀도(Precision)와 재현율(Recall)의 관계를 다양한 임계값(Threshold)에서 측정한 곡선(PR Curve)의 아래 면적을 의미합니다.

PR-AUC는 ROC-AUC와 달리 양성(Positive) 클래스의 예측 성능에 집중하기 때문에, 데이터 불균형(Imbalanced Data)이 심각한 금융/퀀트 환경(예: 사기 탐지, 드문 상승장 예측, 부도 예측)에서 모델의 실전 적합성을 평가하는 가장 신뢰할 수 있는 지표로 꼽힙니다. (참고: PR-AUC의 무작위 추측 기준선은 0.5가 아닌 데이터 내 양성(Positive) 클래스의 비율입니다.)

📐 PR-AUC 기본 수식 (정의)

PR-AUC = ∫01 Precision ( Recall ) · d(Recall)
(단, Precision = TP/(TP+FP), Recall = TP/(TP+FN))

📐 세부 계산 수식 (사다리꼴 적분 근사법)

PR-AUC ≈ Σi=2N ( Recalli − Recalli-1 ) × ( Precisioni + Precisioni-1 ) / 2
※ PR 곡선의 각 임계값(Threshold) 지점에서 사다리꼴 넓이를 모두 합산하여 근사합니다.

🔍 변수(Variables) 상세 설명

변수명 기호 상세 설명 및 입력값
PR 곡선 면적 PR-AUC 결과값 0 ~ 1 범위의 무차원 수치. 1에 가까울수록 완벽한 분류 성능을 의미합니다. (단, 데이터의 양성 비율이 10%라면 무작위 추측 기준선은 0.1입니다.)
정밀도 (Precision) Precision 중간값 모델이 양성(Positive)으로 예측한 것 중 실제 양성인 비율.
공식: TP / (TP + FP) — 거짓 경보(FP)를 얼마나 피했는가를 측정합니다.
재현율 (Recall) Recall 중간값 실제 양성(Positive) 중 모델이 맞춘 비율.
공식: TP / (TP + FN) — 실제 양성을 얼마나 놓치지 않고 찾았는가를 측정합니다.
임계값 (Threshold) τ 옵션 모델의 확률 출력값을 0/1로 변환하는 결정 경계(Decision Boundary). 임계값을 낮추면 Recall은 증가하지만 Precision이 감소하는 Trade-off가 발생합니다.
양성 비율 (Base Rate) P / (P+N) 기준선 데이터 내에서 양성 클래스가 차지하는 비율.
PR-AUC의 무작위 추측 기준선이 바로 이 값입니다 (0.5가 아님!).

🧮 계산 예시 (Example)

📌 예시 상황 (극도로 불균형한 1,000개 데이터, 실제 상승장 10% = 100개)

  • 실제 양성(Positive): 100개, 실제 음성(Negative): 900개
  • 모델 예측 결과 (특정 임계값 기준):
    • TP (상승을 상승으로 맞춤): 80개
    • FP (하락을 상승으로 예측): 50개
    • FN (상승을 하락으로 예측): 20개
    • TN (하락을 하락으로 맞춤): 850개
  • 여러 임계값에서의 PR 곡선 적분 결과: 모든 임계값을 고려한 PR-AUC ≈ 0.72

👉 해당 임계값에서의 Precision / Recall 계산
Precision = 80 / (80 + 50) = 80 / 130 ≈ 0.615 (61.5%)
Recall = 80 / (80 + 20) = 80 / 100 = 0.800 (80.0%)

👉 PR-AUC 최종 결과 및 해석
PR-AUC ≈ 0.72

✅ 해석: 이 모델의 PR-AUC는 0.72입니다.
📌 동일한 데이터의 ROC-AUC는 0.93으로 매우 높게 나오지만, PR-AUC는 0.72로 더 엄격하게 평가합니다. 이는 데이터의 양성 비율이 10%이므로 무작위 추측 기준선이 0.1임을 고려할 때, 매우 우수한 성능이라고 판단할 수 있습니다.

📈 PR-AUC 해석 가이드 (불균형 데이터 기준)

  • 🔴 PR-AUC ≤ 양성 비율 (Base Rate) : 무작위 추측 수준 이하 (모델 폐기).
  • 🟡 Base Rate < PR-AUC ≤ 0.5 : 약한 예측력. 양성 클래스 탐지 능력이 부족함.
  • 🟢 0.5 < PR-AUC ≤ 0.7 : 양호한 예측력. 실무에서 어느 정도 활용 가능.
  • ⭐ 0.7 < PR-AUC ≤ 0.9 : 우수한 예측력. 드문 이벤트를 훌륭히 포착함.
  • 🚀 PR-AUC > 0.9 : 매우 뛰어난 예측력 (거의 완벽에 가까운 양성 탐지).

⚠️ 절대 0.5를 기준으로 삼지 마세요! PR-AUC의 하한선은 데이터의 양성 비율입니다. 예를 들어, 양성이 5%인 데이터에서 PR-AUC가 0.4라면 이는 매우 훌륭한 성능입니다 (무작위는 0.05이므로).

📊 PR-AUC vs ROC-AUC (수신자 운영 특성 곡선) 비교

구분 PR-AUC (정밀도-재현율) ROC-AUC
초점 양성(Positive) 클래스의 예측 성능에 집중 양성과 음성 클래스 모두를 균형 있게 평가
불균형 데이터 매우 민감하게 반응하여 진짜 성능을 보여줌 둔감하여 실제보다 높게(낙관적) 평가하는 경향
무작위 기준선 양성 비율 (Base Rate) (예: 0.05, 0.1 등) 항상 0.5 (데이터와 무관)
실무 활용 사기 탐지, 부도 예측, 희귀 상승장 탐색 시 필수 클래스 균형이 맞는 일반 분류 문제에 적합

⚠️ PR-AUC (정밀도-재현율 곡선 면적) 한계 및 주의사항

  • 음성 클래스의 성능을 완전히 무시하지는 않지만 간접적: PR-AUC는 양성 탐지에 집중하므로, 음성 클래스를 잘 분류하는지는 Precision을 통해 간접적으로만 반영됩니다 (FP가 많으면 Precision 하락).
  • 임계값(Threshold)에 대한 의존성: PR 곡선은 임계값 변화에 따라 급격히 변동할 수 있습니다. 평균 정밀도(Average Precision, AP)와 혼용하여 사용하는 경우가 많습니다.
  • 곡선 아래 면적의 직관적 해석 부족: ROC-AUC처럼 "임의의 양성 하나가 음성보다 높을 확률"이라는 직관적인 확률 해석이 불가능합니다. (단순히 성능의 순위 비교로만 사용해야 함).
  • 매우 희귀한 이벤트(예: 0.1%)에서는 값이 극도로 낮게 나옴: 이런 경우 PR-AUC가 0.1~0.2 수준이더라도 실제로는 훌륭한 모델일 수 있으므로, 절대값보다는 다른 모델과의 상대 비교에 중점을 두어야 합니다.

📚 PR-AUC (정밀도-재현율 곡선 면적) 주요 활용 분야

  • 이상 거래 탐지 (Fraud Detection): 정상 거래 99.9% 환경에서 극소수 사기 거래를 얼마나 놓치지 않고 찾는지 평가.
  • 부도/도산 예측 모델: 부도율이 1~2%인 기업 데이터에서 실제 부도 기업을 얼마나 정확히 선별하는지 측정.
  • 퀀트 상승장 예측 (드문 이벤트): 전체 장 중 10~20%만 상승장일 때, 상승 신호의 정밀도와 재현율을 동시에 최적화.
  • 의료/바이오 진단: 희귀 질환 양성 판정의 오탐(FP)과 미탐(FN)의 심각한 비용을 고려한 모델 검증.
