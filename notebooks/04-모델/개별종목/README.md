# 개별종목 모델 실험

KOSPI200의 5거래일 방향 예측과 결합해 같은 방향일 확률이 높은 개별종목을 랭킹합니다.

## 실행 순서

1. T일 정보로 KOSPI200의 T+1 시가→T+6 시가 방향을 3분류로 예측합니다.
2. T일 KOSPI 세부 업종지수 시가총액 상위 10개를 고릅니다.
3. 각 업종에서 KOSPI 보통주 시가총액 상위 5개를 골라 최대 50종목을 만듭니다.
4. 개별종목 모델이 각 후보의 `p_down`, `p_neutral`, `p_up`을 계산합니다.
5. KOSPI200 예측이 상승이면 `p_up`, 보합이면 `p_neutral`, 하락이면 `p_down` 순으로
   종목을 랭킹합니다.

업종 Top 10은 미래 상승 업종을 예측한 결과가 아니라 T일 시가총액 기준 후보 필터입니다.

## 사용 피처

| 피처 | 설명 |
|---|---|
| `sma_gap_5_20` | 5일·20일 수정종가 이동평균의 상대 거리 |
| `sma_gap_20_60` | 20일·60일 수정종가 이동평균의 상대 거리 |
| `rsi_14` | 14일 상승·하락 강도 |
| `macd_hist_ratio` | MACD 히스토그램을 수정종가로 나눈 모멘텀 |
| `bb_bandwidth` | 20일 볼린저밴드 폭 |
| `bb_position` | 볼린저밴드 안에서 수정종가의 위치 |
| `atr_ratio` | 14일 ATR을 수정종가로 나눈 상대 변동성 |
| `hv_20` | 20일 수정종가 로그수익률 표준편차 |
| `vol_ratio_20` | 당일 거래량을 20일 평균 거래량으로 나눈 값 |
| `obv_slope_20` | 20일 OBV 변화를 평균 거래량으로 정규화한 값 |
| `daily_return` | 수정종가 1거래일 수익률 |
| `five_day_return` | 수정종가 5거래일 수익률 |

피처는 후보로 뽑힌 행만 이어 계산하지 않고, 해당 종목의 전체 개발 시계열에서 먼저
계산한 뒤 후보에 붙입니다. 홀드아웃 시작일 `20240901` 이후 행은 읽지 않습니다.

## 실측 결과

| 순위 | 모델 | Accuracy | Macro F1 | 하락 Recall | 조화평균 |
|---:|---|---:|---:|---:|---:|
| 1 | RandomForest ⭐ | 0.3822 | 0.3641 | 0.3388 | **0.3565** |
| 2 | LightGBM | 0.3956 | 0.3675 | 0.3147 | **0.3429** |
| 3 | XGBoost | 0.3990 | 0.3647 | 0.2791 | **0.3240** |
| 4 | LogisticRegression | 0.4018 | 0.3558 | 0.2582 | **0.3094** |

공통 조건은 날짜 그룹 expanding 12폴드, 최초 학습 750거래일, 검증 60거래일,
경계 직전 5거래일 제거입니다. `None`과 `balanced`는 각 외부 폴드의 내부 검증에서
다시 고릅니다.

현재 12개 피처는 **조합A**입니다. 모델별 결과와 비교표는
[실험 README](실험/README.md)에서 확인합니다.

## KOSPI200 예측과 결합한 실측 결과

KOSPI200 최우수 구성인 조합 E + `five_day_return` RandomForest와 개별종목 조합 A
RandomForest를 결합했습니다. 두 모델이 모두 피처 준비기간과 최소 학습 750거래일을
충족하는 공통 거래일에서 동일한 expanding 12폴드·OOS 720거래일을 다시 만들었습니다.

| 범위 | 방향 적중률 | 평균 선택 확률 |
|---|---:|---:|
| 후보 전체 | 0.3452 | - |
| Top 1 | **0.4264** | 0.5901 |
| Top 3 | **0.4181** | 0.5410 |
| Top 5 | **0.4161** | 0.5143 |

방향 적중은 KOSPI200이 예측한 클래스와 실제 개별종목 클래스가 같은지를 뜻합니다.
실제 KOSPI200 정답은 종목 선택에 사용하지 않았습니다. 상세 실측값과 HF 파일 해시는
[`reports/stock_index_ranking.json`](../../../reports/stock_index_ranking.json)에 있습니다.
매매 포지션 규칙은 아직 확정되지 않아 이 표에는 거래비용 수익률을 넣지 않았습니다.
