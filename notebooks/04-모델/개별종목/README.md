# 개별종목 모델 실험

KOSPI200의 5거래일 방향 예측과 결합해 같은 방향일 확률이 높은 개별종목을 랭킹합니다.

## 실행 순서

1. T일 정보로 KOSPI200의 T+1 시가→T+6 시가 방향을 3분류로 예측합니다.
2. T일 KOSPI 세부 업종지수 시가총액 상위 10개를 고릅니다.
3. 각 업종에서 KOSPI 보통주 시가총액 상위 5개를 골라 최대 50종목을 만듭니다.
4. 개별종목 모델이 각 후보의 `p_down`, `p_neutral`, `p_up`을 계산합니다.
5. KOSPI200 예측이 상승이면 `p_up`, 보합이면 `p_neutral`, 하락이면 `p_down` 순으로
   종목을 랭킹합니다.

업종 Top 10은 미래 상승 업종을 예측한 결과가 아니라 T일 시가총액 기준 후보 필터입니다.

## 피처 조합

| 조합 | 관점 | 피처 수 |
|---|---|---:|
| A | 추세·모멘텀·변동성·거래량·수익률 | 12 |
| B | 최근 강세 뒤 5거래일 단기 반전·최근 고점과의 거리 | 7 |
| C | 단기 반전·시가 갭·장중 종가 위치 | 7 |
| D | 변동성·거래회전율·Amihud 비유동성 | 8 |
| E | 종목의 업종·KOSPI200 대비 상대강도 | 7 |
| F | 그날 최대 50개 후보 안의 횡단면 백분위 순위 | 9 |

피처는 후보로 뽑힌 행만 이어 계산하지 않고, 해당 종목의 전체 개발 시계열에서 먼저
계산한 뒤 후보에 붙입니다. 홀드아웃 시작일 `20240901` 이후 행은 읽지 않습니다.

공통 조건은 날짜 그룹 expanding 12폴드, 최초 학습 750거래일, 검증 60거래일,
경계 직전 5거래일 제거입니다. `None`과 `balanced`는 각 외부 폴드의 내부 검증에서
다시 고릅니다.

학습 최빈 기준선은 각 폴드의 학습 라벨에서 가장 많은 클래스를 정한 뒤 검증구간 전체에
적용한 비누수 기준선입니다. 검증구간 정답에서 계산한 최빈 비율은 분포 설명용 `oracle`
통계로만 남기고 모델 우위 판정에는 사용하지 않습니다. 개별종목 중립대 `±2.0%`의 근거와
평가 원칙은 ADR 0006에 기록했습니다.

모델별 24개 결과와 피처 설명은 [실험 README](실험/README.md)와 각 조합 폴더에서
확인합니다. 절대수익률 100% 초과만으로 후보를 자동 제거하지 않습니다. 이슈 #132에 따라
KRX 등락률과 수정주가 수익률이 1%p 넘게 어긋난 `is_adj_suspect`만 제외해 재실행했습니다.
최신 후보 176,705행에서는 의심 행 0건을 제외했고 실제 극단 사건 5건은 보존했습니다.

## KOSPI200 예측과 결합한 실측 결과

아래 표는 개별종목 전체 1위 조합 F LightGBM을 KOSPI200 최우수 구성과 결합한
실측값입니다. 두 모델이 모두 피처 준비기간과 최소 학습 750거래일을

만들었습니다. 날짜만 같고 종목 구성이 다른 표본은 조합 비교에 사용하지 않습니다.

방향 적중은 KOSPI200이 예측한 클래스와 실제 개별종목 클래스가 같은지를 뜻합니다.
실제 KOSPI200 정답은 종목 선택에 사용하지 않았습니다. 상세 실측값과 HF 파일 해시는
[`reports/stock_index_ranking.json`](../../../reports/stock_index_ranking.json)에 있습니다.
무작위 기준선은 전체 기간의 고정 비율이 아니라 같은 공통 OOS 날짜와 KOSPI200 예측
방향 안에서 후보를 무작위로 Top-K만큼 뽑을 때의 기대 적중률입니다.
매매 포지션 규칙은 아직 확정되지 않아 이 표에는 거래비용 수익률을 넣지 않았습니다.
