# 개별종목 모델 실험

KOSPI200의 5거래일 방향 예측과 결합해 같은 방향일 확률이 높은 개별종목을 랭킹합니다.

## 실행 순서

1. T일 정보로 KOSPI200의 T+1 시가→T+6 시가 방향을 3분류로 예측합니다.
2. T일 KOSPI 세부 업종지수 시가총액 상위 10개를 고릅니다.
3. 각 업종에서 KOSPI 보통주 시가총액 상위 5개를 골라 최대 50종목을 만듭니다.
4. 개별종목 모델이 각 후보의 `p_down`, `p_neutral`, `p_up`을 계산합니다.
5. 최대 50종목을 모두 예측하고 업종 순위 → 업종 내 시총 순위 → 종목코드 순으로 표시합니다.
6. 종목 예측과 실제 라벨의 일치 여부, 업종별·날짜 전체 적중률과 상승 Precision을 남깁니다.
7. 실제 매수는 KOSPI200과 개별종목이 모두 상승으로 예측된 종목만 대상으로 합니다.

확률 Top 1·3·5는 기본 50종목을 줄이는 규칙이 아니라 별도 확률 분위 부가 실험입니다.

업종 Top 10은 미래 상승 업종을 예측한 결과가 아니라 T일 시가총액 기준 후보 필터입니다.

경계 직전 5거래일 제거입니다. `None`과 `balanced`는 각 외부 폴드의 내부 검증에서
다시 고릅니다.

최종 조합·모델은 ADR 0007에 따라 `기준선 대비 Accuracy → Macro F1 → 기준선 승리
폴드 수`로 선정합니다. 최신 데이터에서 실측한 44개 후보의 1위는 조합 K
LogisticRegression입니다.
기존 Accuracy·Macro F1·하락 Recall 조화평균은 진단값으로 계속 남기며, class weight의
내부 선택 기준은 기존 조화평균을 유지합니다.

학습 최빈 기준선은 각 폴드의 학습 라벨에서 가장 많은 클래스를 정한 뒤 검증구간 전체에
적용한 비누수 기준선입니다. 검증구간 정답에서 계산한 최빈 비율은 분포 설명용 `oracle`
통계로만 남기고 모델 우위 판정에는 사용하지 않습니다. 개별종목 중립대 `±2.0%`의 근거와
평가 원칙은 ADR 0006에 기록했습니다.

모델별 40개 결과와 피처 설명은 [실험 README](실험/README.md)와 각 조합 폴더에서
확인합니다. 절대수익률 100% 초과만으로 후보를 자동 제거하지 않습니다. 이슈 #132에 따라
KRX 등락률과 수정주가 수익률이 1%p 넘게 어긋난 `is_adj_suspect`만 제외해 재실행했습니다.
최신 후보 176,705행에서 정리매매·거래정지·신규상장 표본 플래그 462행을 후보 선정 후
제외했습니다. 차순위 종목으로 채우지 않았고 이 플래그를 피처로 사용하지 않았습니다.
남은 176,243행에서는 의심 행 0건을 제외했고 실제 극단 사건 4건은 보존했습니다.

## 이슈 #190 반영 기본 출력

최종 산출 코드는 평가 보고서에서 각 트랙의 1위 모델을 읽어 연결합니다. 조합명이나 모델명을
실행 코드에 고정하지 않습니다. 현재 보고서가 선택한 모델은 KOSPI200 조합 E RandomForest와
개별종목 조합 K LogisticRegression입니다.

공통 OOS 720거래일에서 최대 50종목을 자르지 않고 저장한 결과는 34,649행이며, 날짜별 후보는
44~50종목입니다. 종목 예측과 실제 라벨의 전체 적중률은 **0.4216**, 상승 예측 8,328건 중 실제
상승은 3,075건으로 상승 Precision은 **0.3692**입니다. 날짜·업종별 적중률은 기본 출력 각 행에
함께 기록합니다.

기본 출력은 로컬 `data/raw/stock_prediction_output.parquet`, 집계와 실행 계약은
[`reports/stock_index_ranking.json`](../../../reports/stock_index_ranking.json)에 저장합니다.

## Top 1·3·5 확률 분위 부가 실험

아래 표는 현재 두 1위 모델의 최대 50종목 기본 출력에서 지수 예측 방향에 해당하는 확률순
Top 1·3·5만 따로 확인한 결과입니다. 기본 출력이나 최종 후보를 줄이는 규칙으로 사용하지 않습니다.

| 범위 | 방향 적중률 | 무작위 기준선 | 기준선 대비 | 평균 선택 확률 |
|---|---:|---:|---:|---:|

방향 적중은 KOSPI200이 예측한 클래스와 실제 개별종목 클래스가 같은지를 뜻합니다.
실제 KOSPI200 정답은 종목 선택에 사용하지 않았습니다. 상세 실측값과 HF 파일 해시는
[`reports/stock_index_ranking.json`](../../../reports/stock_index_ranking.json)에 있습니다.
무작위 기준선은 전체 기간의 고정 비율이 아니라 같은 공통 OOS 날짜와 KOSPI200 예측
방향 안에서 후보를 무작위로 Top-K만큼 뽑을 때의 기대 적중률입니다.

같은 720거래일에서 KOSPI200 RandomForest의 Accuracy는 `0.3764`였습니다. 학습구간 최빈
클래스 기준선은 `0.3972`, ARIMA 동반 기준선은 `0.4181`로 둘 다 모델보다 높았습니다.
ARIMA는 Balanced Accuracy가 `0.3333`, Macro F1이 `0.1965`여서 세 방향을 고르게 맞힌
결과는 아닙니다. 직전 방향 기준선은 겹치는 5일 라벨의 정답을 예측 시점에 알 수 없으므로
설명용으로만 기록하고 모델 선정에는 사용하지 않습니다.

## 개별종목 5트랙 비용 백테스트

현재 long-only 정책에 따라 KOSPI200과 개별종목이 모두 상승으로 예측된 종목만 매수하고
나머지는 현금으로 둡니다. 각 날짜의 Top-K를 T+1 `adj_open`에 동일 비중으로 매수해 T+6
`adj_open`에 청산하며, 자본은 요일별 5개 슬리브로 나눕니다. 12개 외부 폴드는 빈
포지션에서 각각 시작하고 폴드별 결과를 이어 곱했습니다.

임의로 만들지 않고 실행을 막습니다.
