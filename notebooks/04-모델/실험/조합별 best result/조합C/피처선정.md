# 조합 C best result

## 종속변수

- `label`: 기준일 이후 미래 5거래일 방향 (`-1` 하락, `0` 중립, `1` 상승)

## 기본 입력 피처

- `sma_gap_5_20`: 5일·20일 이동평균의 상대 차이
- `macd_hist_ratio`: 가격 대비 MACD 히스토그램으로 본 모멘텀
- `rsi_14`: 최근 14거래일의 상승·하락 강도
- `bb_position`: 현재 가격의 볼린저밴드 내 상대 위치
- `hv_20`: 최근 20거래일 로그수익률의 표준편차
- `vol_ratio_20`: 현재 거래량과 최근 20거래일 평균 거래량의 비율
- `daily_return` (`Daily_Return`): `당일 종가 / 전일 종가 - 1`. 전일 대비 당일 수익률
- `five_day_return` (`5Day_Return`): `당일 종가 / 5거래일 전 종가 - 1`. 과거 5거래일 누적수익률

두 수익률은 기준일 현재와 과거 가격만 사용한다. 미래 5거래일 수익률인
`fwd_return_5d`와 다르므로 예측 시점 이후의 정보는 포함하지 않는다. 선정 실험에
이름이 표시된 수익률만 기본 피처에 추가된다.

## 선정 결과

| 모델 | 선정 실험 | 핵심지표 조화평균 | 선정 이유 |
|---|---|---:|---|
| Logistic Regression | `+ Daily_Return + 5Day_Return` | 0.2559 | 두 수익률을 함께 넣은 실험의 지표 균형이 가장 좋음 |
| RandomForest | `+ 5Day_Return` | 0.3345 | 과거 5거래일 수익률 추가 시 조화평균이 가장 높음 |
| XGBoost | `+ Daily_Return` | 0.3371 | 당일 수익률 추가 실험이 네 후보 중 가장 높음 |
| ⭐ **LightGBM** | `+ Daily_Return + 5Day_Return` | **0.3800** | 조합 C의 네 모델 중 최종 성능이 가장 높음 |

선정 점수는 OOS `Accuracy`, `Macro F1`, `하락 Recall`의 조화평균이다.
