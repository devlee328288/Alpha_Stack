📊 KOSPI 3분류 동적 기준선 모델 사용 방법 가이드

이 문서는 변동성(ATR)과 거래량(Log Relative Volume)을 반영한 동적 기준선을 통해 KOSPI 1일봉 데이터를 상승(2) / 중립(1) / 하락(0)으로 분류하는 모델의 사용 방법을 설명합니다.

✅ CMA-ES + Walk-Forward 최적화로 튜닝된 최종 파라미터가 함수 내부에 기본값으로 포함되어 있어, 추가 튜닝 없이도 바로 실전 적용이 가능합니다.

🧩 1. 함수 개요

def classify_with_our_model( df: pd.DataFrame, alpha_up: float = 0.497, alpha_down: float = 0.395, beta_up: float = -0.414, beta_down: float = -0.033, vol_period: int = 14, volume_period: int = 20, up_thresh: float = 0.0056, down_thresh: float = -0.0028 ) -> pd.DataFrame:

OHLCV 데이터프레임을 입력받아, 내부적으로 ATR과 Log Relative Volume을 계산한 후 동적 기준선(Upper / Lower)을 생성하고, 종가가 어느 구간에 위치하는지에 따라 상승(2) / 중립(1) / 하락(0) 신호를 반환합니다.

📌 핵심 포인트
• 이 함수는 단독으로도 완전한 분류기로 동작합니다.
• 모든 파라미터는 KOSPI 200 데이터(2010~2024)에 대해 최적화된 최종 실전 값입니다.
• 기본값 그대로 사용해도 좋으며, 다른 종목이나 주기에 맞춰 선택적으로 조정할 수 있습니다.

📥 2. 입력 변수 (Input)

필수 입력 – OHLCV 데이터프레임

컬럼명 데이터 타입 설명
open float 당일 시가
high float 당일 고가
low float 당일 저가
close float 당일 종가
volume float / int 당일 거래량

⚠️ 컬럼명은 반드시 위와 정확히 일치해야 합니다. (대소문자 구분)

선택 입력 – 튜닝 파라미터

아래 파라미터는 함수 호출 시 선택적으로 변경할 수 있습니다. 기본값은 KOSPI에 최적화된 최종 값입니다.

파라미터명 기본값 의미
alpha_up 0.497 상승 기준선의 변동성 민감도 (클수록 기준선이 넓어짐)
alpha_down 0.395 하락 기준선의 변동성 민감도
beta_up -0.414 상승 시 거래량 충격(Shock)에 대한 반응도
beta_down -0.033 하락 시 거래량 충격에 대한 반응도
vol_period 14 ATR 계산 기간 (일봉 기준)
volume_period 20 거래량 평균 계산 기간
up_thresh 0.0056 상승 레이블 기준 수익률 (참고용, 내부 신호 생성에는 영향 없음)
down_thresh -0.0028 하락 레이블 기준 수익률 (참고용)
📈 α_up = 0.497 상승 기준선 1.49배
📉 α_down = 0.395 하락 기준선 1.19배
📊 β_up = -0.414 거래량 ↑ → 상승 기준선 ↓
📊 β_down = -0.033 거래량 영향 거의 없음

📤 3. 출력 변수 (Output)

함수는 원본 데이터프레임에 아래 6개의 컬럼을 추가하여 반환합니다.

컬럼명 값의 범위 설명
base float 중심선 (종가 20일 SMA)
upper float 상승 기준선 (Base + Width_up)
lower float 하락 기준선 (Base - Width_down)
signal 2 (상승)
1 (중립)
0 (하락) 		최종 분류 결과 (가장 중요한 컬럼)
position +1 (매수)
0 (관망)
-1 (매도) 		신호를 포지션으로 변환한 값
🎯 신호 판정 규칙
• close > upper → 상승 (2)
• lower ≤ close ≤ upper → 중립 (1)
• close < lower → 하락 (0)

📐 4. 핵심 수식 (참고용)

# 1) 중심선 Base = SMA(Close, 20) # 2) 변동성 ATR = ATR(High, Low, Close, 14) # 3) 거래량 충격 지수 VolumeEffect = log( Volume / SMA(Volume, 20) ) # 4) 기준선 폭 (선형 구조) Width_up = ATR × max(0.05, α_up + β_up × VolumeEffect) Width_down = ATR × max(0.05, α_down + β_down × VolumeEffect) # 5) 상승 / 하락 기준선 Upper = Base + Width_up Lower = Base - Width_down
💡 exp()를 사용하지 않는 이유
기존 지수(exp) 구조는 α 값이 조금만 커져도 기준선이 기하급수적으로 벌어져 신호가 전멸했습니다. 반면, 현재의 선형 구조는 α=0.25일 때 약 10포인트(KOSPI 기준)로 현실적인 움직임을 포착할 수 있습니다.

📋 5. 데이터 요구 사항

  • 주기: 일봉(Daily) 데이터를 기본으로 설계되었습니다. (다른 주기 사용 시 파라미터 재튜닝 필요)
  • 최소 데이터 길이: 20일 이상 (SMA20, ATR14 계산을 위해)
  • 컬럼: open, high, low, close, volume (이름 정확히 일치)
  • 결측치: 함수 내부에서 rolling 계산 시 발생하는 초반 NaN은 자동으로 처리되나, 데이터 중간에 NaN이 있으면 결과가 왜곡될 수 있습니다.

❓ 6. 자주 묻는 질문

Q1. 다른 종목(예: 삼성전자, 비트코인)에 바로 사용할 수 있나요?
네, OHLCV 데이터만 있으면 즉시 사용할 수 있습니다. 다만, 종목별 변동성(ATR)과 거래량 패턴이 다르므로 최적의 성능을 원한다면 α, β, Threshold를 해당 종목에 맞춰 재튜닝하는 것을 권장합니다.

Q2. 기본 파라미터(α=0.497, β=-0.414)는 어떻게 도출되었나요?
KOSPI 200 지수(2010년 3월 ~ 2024년 8월, 총 3,553일)를 대상으로 CMA-ES 알고리즘과 143개의 Walk-Forward 폴드를 통해 Macro-F1을 최대화하는 방향으로 최적화되었습니다.

Q3. 출력된 signal을 어떻게 매매에 활용하나요?
signal이 2(상승)이면 매수, 0(하락)이면 매도, 1(중립)이면 관망(포지션 0)으로 활용하면 됩니다. 단, Look-ahead Bias를 방지하기 위해 당일 종가 기준 생성된 신호는 익일 시가 또는 종가에 매매하는 것이 권장됩니다.

Q4. 수익률이 나오지 않으면 파라미터를 어떻게 조정해야 하나요?
α는 기준선의 너비를 결정합니다. 변동성이 큰 종목이라면 α를 더 높게(예: 0.6~0.8), 변동성이 작다면 낮게(예: 0.2~0.3) 조정해보세요. β는 거래량의 영향을 조절합니다.
